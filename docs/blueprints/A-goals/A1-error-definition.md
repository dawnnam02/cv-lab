## 1. 목적

"G코드와 다르다"는 말 하나에는 서로 다른 여러 종류의 차이가 섞여 있습니다. 이 요소의 목적은 다음 세 가지를 **문서로 확정**하는 것입니다.

1. **오차의 종류**를 나누고, 이 연구에서 **주요 결과로 보고할 종류**를 고른다 (권장: 높이 · 윤곽(IoU) · 치수 · 위치 4가지).
2. 모든 종류에 공통으로 쓰는 **부호 규칙**을 고정한다: `오차 = 측정값 − 기준값`, **+ 는 재료 과다, − 는 재료 부족**.
3. 각 종류마다 **어떤 통계량으로 요약할지**(치우침 + 흩어짐 + 최악값)를 정한다.

이 정의가 흔들리면 이후의 시편 설계(E3), 지표 코드(H5–H7), 불확도 예산(I1), 논문 결과표가 모두 다시 작성되어야 합니다. 그래서 W1에 가장 먼저 끝냅니다.

## 2. 배경 지식 (초보자용)

### 2.1 "기준값"과 "측정값"
- **기준값(reference)**: 있어야 할 값. 이 과제에서는 **G코드에 비드 폭·층 높이를 입혀 만든 기준 형상**(G2, G3)입니다. CAD가 아니라 G코드가 기준이라는 점이 중요합니다(G5 참고).
- **측정값(measured)**: 레이저 삼각측량 센서로 실제 출력물을 측정한 값(높이맵).
- **오차(error, 편차)**: 두 값의 차이. 이 프로젝트에서는 항상 `측정값 − 기준값` 입니다.

### 2.2 부호 규칙이 왜 중요한가
`기준 − 측정` 으로 계산하는 사람과 `측정 − 기준` 으로 계산하는 사람이 섞이면, 같은 "재료 과다"가 어떤 그림에서는 빨간색(+), 어떤 그림에서는 파란색(−)으로 표시됩니다. 결과 해석이 정반대가 됩니다. 그래서 **한 가지 규칙만** 씁니다.

| 상황 | 측정 | 기준 | 오차 | 해석 |
|---|---|---|---|---|
| 윗면이 높게 나옴 | 2.05 mm | 2.00 mm | **+0.05 mm** | 재료 과다 |
| 윗면이 낮게 나옴 | 1.95 mm | 2.00 mm | **−0.05 mm** | 재료 부족 |
| 구멍 지름이 작음 | Ø 9.8 mm | Ø 10.0 mm | 지름 −0.2 mm | **구멍은 주의**: 지름이 작다 = 재료가 **과다**. 치수 오차는 "치수 기준"으로 부호를 쓰고, 재료 관점 해석은 별도 열에 적는다 |
| 외곽 폭이 큼 | 10.08 mm | 10.00 mm | +0.08 mm | 재료 과다 |

> **구멍·홈(내부 형상) 규칙**: 치수 오차 열에는 `측정 치수 − 설계 치수`를 그대로 적고, "재료 관점" 열을 하나 더 두어 과다/부족을 명시합니다. 이 규칙도 오차 정의서에 적어 둡니다.

### 2.3 하나의 숫자로 요약하면 안 되는 이유
오차는 격자 수십만 칸에서 각각 계산됩니다. 이것을 요약할 때 **평균 하나만** 쓰면, +0.1 mm 와 −0.1 mm 가 서로 상쇄되어 평균 0 이 됩니다. 그래서 세 가지를 항상 함께 봅니다.

| 묶음 | 통계량 | 질문 |
|---|---|---|
| **치우침(bias)** | 평균 | 전체적으로 높은가, 낮은가? |
| **흩어짐(spread)** | 표준편차, RMS | 얼마나 들쭉날쭉한가? (`RMS² = 평균² + 표준편차²`, 표본 수가 클 때 근사) |
| **최악(worst)** | P95(절댓값의 95번째 백분위수), 최댓값 | 가장 나쁜 곳은 얼마나 나쁜가? |

### 2.4 오차 종류 7가지 (청사진 A1 표를 확장)

| 오차 종류 | 의미 | 예시 | 측정 지표 | 계산 위치 | 단위 |
|---|---|---|---|---|---|
| **높이 오차** | 있어야 할 높이와 실제 높이의 차이 | 윗면이 0.05 mm 낮음 | 부호 있는 높이 편차의 평균·표준편차·RMS·P95 | H5 | mm (µm 병기) |
| **윤곽(형상) 오차** | 위에서 본 경계 모양의 차이 | 모서리 뭉개짐, 과충진 | IoU, Dice, 과/미충진 면적, 평균 윤곽 거리, HD95 | H6 | 무차원, mm², mm |
| **치수 오차** | 길이·폭·지름이 설계값과 다름 | Ø 10 mm 구멍이 Ø 9.8 mm | 치수 차이 mm 및 % | H7 | mm, % |
| **위치 오차** | 형상 전체가 밀리거나 회전 | 전체가 X로 0.2 mm 이동 | 기준마커 정합 후 이동량(ΔX, ΔY)·회전각 | H4, H7 | mm, ° |
| **배율 오차** | 전체가 균일하게 줄거나 늘어남 | 수축으로 0.4 % 작음 | 닮음 변환의 배율 s → (s − 1)×100 % | H4 | % |
| **선(비드) 단위 오차** | 한 줄 한 줄의 폭과 경로 이탈 | 선폭 0.40 → 0.47 mm | 수직 단면 프로파일 폭(FWHM), 중심 이탈 | H7 | mm |
| **표면 오차** | 평평해야 할 면의 굴곡 | 윗면 평면도 0.08 mm | 평면도(P-V), 거칠기 | H7 | mm, µm |

**종류끼리 섞이는 관계** (초보자가 가장 헷갈리는 부분)
- **위치 오차 ↔ 윤곽 오차**: 형상이 0.2 mm 밀리면 IoU도 떨어집니다. 그래서 IoU는 **어떤 정합을 한 뒤의 값인지** 반드시 명시합니다(마커 기준 정합 / 최적맞춤 정합, H4).
- **배율 오차 ↔ 치수 오차**: 0.4 % 수축은 50 mm 길이에서 0.2 mm 치수 오차로 보입니다. 치수 오차 보고 시 배율 보정 전/후를 구분합니다.
- **높이 오차 ↔ 바닥 기준화**: 베드 기울기가 남아 있으면 높이 오차에 기울기 성분이 섞입니다(H3).

## 6. Python 구현

목적: (1) 부호 규칙을 코드로 고정하고, (2) 평균만 보면 왜 안 되는지, (3) 오차 종류 4가지(위치·치수·윤곽·높이)가 서로 어떻게 다른 숫자로 나오는지를 **합성 데이터**로 직접 확인합니다. 하드웨어 없이 실행됩니다.

파일: `a1_error_types.py`

```python
# a1_error_types.py — 오차 종류별 지표를 합성 데이터로 계산해 보는 예제
import numpy as np

RES = 0.02                      # 격자 간격 [mm] (A2/G3 권장값)
rng = np.random.default_rng(42) # 난수 시드 고정 → 매번 같은 결과


def signed_error(measured, reference):
    """부호 규칙: 오차 = 측정값 − 기준값 (+ 재료 과다, − 재료 부족)"""
    return np.asarray(measured, float) - np.asarray(reference, float)


def summarize(e, tol=0.1):
    """치우침 + 흩어짐 + 최악값을 항상 함께 계산"""
    e = np.asarray(e, float)
    e = e[~np.isnan(e)]                     # 측정 누락(NaN) 제외
    a = np.abs(e)
    return {
        "n": int(e.size),
        "mean": e.mean(),                   # 치우침(bias)
        "std": e.std(ddof=1),               # 흩어짐
        "rms": np.sqrt((e ** 2).mean()),    # 종합 크기
        "p95_abs": np.percentile(a, 95),    # 대부분의 최대
        "max_abs": a.max(),                 # 최악
        "within_tol_pct": 100 * (a <= tol).mean(),
    }


def square_mask(cx, cy, size, n=1000):
    """n×n 격자 위에 중심 (cx, cy), 한 변 size [mm] 정사각형 마스크"""
    x = (np.arange(n) + 0.5) * RES
    X, Y = np.meshgrid(x, x)
    return (np.abs(X - cx) <= size / 2) & (np.abs(Y - cy) <= size / 2)


def centroid(mask):
    ys, xs = np.nonzero(mask)
    return (xs.mean() + 0.5) * RES, (ys.mean() + 0.5) * RES


# --- 예제 1: 평균만 보면 안 되는 이유 -------------------------------
e1 = np.r_[np.full(500, +0.1), np.full(500, -0.1)]
s1 = summarize(e1)
print("[예제1] 평균 = %.3f mm, RMS = %.3f mm, 최대 = %.3f mm"
      % (s1["mean"], s1["rms"], s1["max_abs"]))

# --- 예제 2: 기준 사각 블록 vs 측정 블록 ----------------------------
# 기준: 중심 (10,10) mm, 10×10 mm, 높이 2.00 mm
# 측정: X로 +0.20 mm 밀림(위치), 한 변 10.08 mm(과충진/치수), 높이 1.95 mm + 노이즈
M_ref = square_mask(10.0, 10.0, 10.0)
M_meas = square_mask(10.2, 10.0, 10.08)
H_ref = np.where(M_ref, 2.00, 0.0)
H_meas = np.where(M_meas, 1.95, 0.0) + rng.normal(0, 0.005, M_ref.shape)

# (1) 위치 오차: 무게중심 이동
(cxr, cyr), (cxm, cym) = centroid(M_ref), centroid(M_meas)
print("[위치] dX = %+.3f mm, dY = %+.3f mm" % (cxm - cxr, cym - cyr))

# (2) 치수 오차: X 방향 폭
w_ref = M_ref.any(axis=0).sum() * RES
w_meas = M_meas.any(axis=0).sum() * RES
print("[치수] 폭 기준 %.2f mm, 측정 %.2f mm, 오차 %+.2f mm (%+.1f %%)"
      % (w_ref, w_meas, w_meas - w_ref, 100 * (w_meas - w_ref) / w_ref))

# (3) 윤곽 오차: IoU
inter, union = (M_ref & M_meas).sum(), (M_ref | M_meas).sum()
print("[윤곽] IoU = %.4f" % (inter / union))

# (4) 높이 오차: 두 윗면이 겹치고 경계에서 0.25 mm 이상 떨어진 곳만
core = square_mask(10.0, 10.0, 10.0 - 2 * 0.25) & square_mask(10.2, 10.0, 10.08 - 2 * 0.25)
s2 = summarize(signed_error(H_meas, H_ref)[core], tol=0.1)
print("[높이] n=%d, 평균 %+.4f, 표준편차 %.4f, RMS %.4f, P95 %.4f mm"
      % (s2["n"], s2["mean"], s2["std"], s2["rms"], s2["p95_abs"]))
```

**줄별 핵심 설명**
- `signed_error`: 프로젝트 전체에서 **이 함수 하나만** 오차를 계산하도록 합니다. 다른 곳에서 `ref - meas` 를 직접 쓰지 않습니다.
- `summarize`: 평균(치우침), 표준편차·RMS(흩어짐), P95·최댓값(최악)을 **항상 묶어서** 돌려줍니다. `ddof=1` 은 표본 표준편차(n−1로 나눔)입니다.
- `square_mask`: 격자 칸의 **중심 좌표** `(i + 0.5) × RES` 로 판단합니다. 칸 모서리로 판단하면 0.5칸(0.01 mm)씩 어긋납니다.
- 예제 2의 `core`: 높이 오차는 경계 0.25 mm 띠를 **빼고** 계산합니다. 경계에는 위치·윤곽 오차가 섞여 높이 오차가 수 mm로 튀기 때문입니다(G4 평가 마스크의 축소판).

**해석 연습**
- 예제 1: 평균은 0이지만 RMS·최댓값은 0.1 mm → "평균만 보고하면 오차가 없다고 착각한다."
- 예제 2: 넣은 오차(위치 +0.20 mm, 폭 +0.08 mm, 높이 −0.05 mm, 노이즈 5 µm)가 각각 **다른 지표에서 정확히** 복원됩니다. IoU 0.9534 는 위치 이동과 폭 증가가 **합쳐진** 결과라서, IoU 하나만 보면 원인을 구분할 수 없습니다 → 위치는 마커 정합(H4)으로 따로 보고해야 합니다.

```python
# tests/test_sign_convention.py — 부호 규칙이 깨지면 바로 실패하는 테스트
import numpy as np


def signed_error(measured, reference):
    return np.asarray(measured, float) - np.asarray(reference, float)


def test_excess_material_is_positive():
    # 측정 윗면 2.05 mm, 기준 2.00 mm → 재료 과다 → 양수
    assert signed_error(2.05, 2.00) > 0


def test_missing_material_is_negative():
    assert signed_error(1.95, 2.00) < 0


def test_array_shape_preserved():
    e = signed_error(np.ones((3, 4)), np.zeros((3, 4)))
    assert e.shape == (3, 4) and np.all(e == 1)
```

## 8. 흔한 실수와 대응

| 실수 | 증상 | 대응 |
|---|---|---|
| 평균 오차 하나만 보고 | "평균 0.001 mm, 거의 완벽" 이라는 결론인데 사진으로 보면 울퉁불퉁함 | 평균 + 표준편차/RMS + P95/최댓값 3묶음을 항상 함께 보고 |
| 부호 규칙이 사람마다 다름 | 오차 지도 색이 그림마다 반대, 토의 중 "높다/낮다" 혼동 | `signed_error()` 단일 함수 사용, 부호 테스트, 컬러바에 "+ 과다" 라벨 |
| 구멍 지름 오차를 재료 관점과 혼동 | "구멍 −0.2 mm → 재료 부족" 이라는 잘못된 해석 | 치수 열과 재료 관점 열을 분리 |
| IoU 하나로 모든 것을 설명 | IoU가 낮은 원인이 위치인지 형상인지 모름 | 위치는 마커 정합으로 분리 후 IoU 계산, 윤곽 거리(mm) 병행 |
| 최적맞춤(ICP) 후 위치 오차 측정 | 위치 오차가 항상 거의 0 | 위치 오차는 **마커 기준 정합에서만** 계산 (H4) |
| 경계까지 포함해 높이 오차 계산 | 높이 RMS가 수백 µm ~ mm로 튐 | 경계 띠 0.25 mm 제외한 평가 마스크(G4) 사용 |
| 단위 혼용 (mm/µm) | 0.05 와 50 이 같은 표에 섞임 | 저장·계산은 mm, 보고표 열 제목에 단위 명시 |
| 측정 누락(NaN)을 0으로 채움 | 가림 영역이 "−2 mm 재료 부족"으로 나타남 | NaN은 지표 계산에서 제외하고, 유효 점 비율을 별도 보고 |
| 정의서를 조용히 수정 | 이전 결과와 이후 결과가 다른 정의로 계산됨 | 버전 번호 + 변경 이력 표, 결과 폴더에 정의서 버전 기록 |
