## 1. 목적

- 레이저 파장만 통과시키는 **대역통과 필터**를 골라 주변광(형광등, 햇빛, 프린터 LED)을 차단합니다. 효과 대비 저렴해서 **필수급**입니다 (BLUEPRINT B7).
- 필터 통과대역이 레이저 파장 공차·온도 변화·입사각을 모두 견디는지 **계산으로 확인**합니다.
- 장착 후 **주변광 비율 시험**으로 C5 완료 기준(레이저 끈 영상 최대 밝기 < 레이저 신호의 5 %)을 확인합니다.
- 편광 필터가 필요한지(광택면) 판단 기준을 정합니다.

## 2. 배경 지식 (초보자용)

### 2.1 대역통과 필터 용어

| 용어 | 뜻 | 권장 |
|---|---|---|
| 중심파장 CWL | 가장 잘 통과하는 파장 | 레이저 파장 (예: 450 nm) |
| 반치폭 FWHM | 투과율이 최대의 절반 이상인 파장 폭 | 10~25 nm (6.1절 계산으로 결정) |
| 최대 투과율 | 통과대역에서의 투과율 | ≥ 85~90 % |
| 차단 OD (광학 밀도) | 통과대역 밖 차단 정도. OD 4 = 1/10,000 만 통과 | OD ≥ 3~4 |
| 입사각 의존성 | 비스듬히 들어오면 통과 파장이 **짧은 쪽으로** 이동 | 렌즈 앞 장착 시 화각에 따른 이동 확인 |

예: "450 ± 10 nm" 처럼 표기는 제조사마다 다릅니다. **±10 이 반치폭의 절반인지, 중심파장 공차인지** 사양서에서 확인합니다.

### 2.2 왜 통과대역을 너무 좁게 하면 안 되나

필터가 좁을수록 주변광은 더 많이 막지만, 아래 요인이 겹치면 레이저 빛 자체가 대역 밖으로 밀려납니다.

```
최악 어긋남 = 레이저 파장 공차 + 레이저 온도 변화 × 온도 폭 + 필터 중심파장 공차 + 입사각에 의한 이동
판정: 최악 어긋남 ≤ 반치폭 / 2
```

- 입사각 θ 에서 중심파장: `λ(θ) = λ0 · √(1 − (sinθ / n_eff)²)` (n_eff: 필터 유효 굴절률, 사양서 값 또는 대략 1.5~2.2).
- 기준안에서 화각이 작아(최대 약 4.6°) 입사각 이동은 0.4 nm 정도로 작지만, **레이저 파장 공차(±5 nm 수준)가 지배적**입니다.
- 반치폭 10 nm 로 하려면 레이저의 **실제 파장을 측정**해서(분광기, 또는 공급사의 개별 측정 성적서) 필터를 맞춰야 합니다. 그렇지 않으면 **20~25 nm** 가 안전합니다.

### 2.3 필터의 다른 효과

- **캘리브레이션에 영향**: 필터는 빛이 지나는 유리판이라 초점 위치와 광경로를 미세하게 바꿉니다. 그래서 **필터를 붙인 상태에서 초점을 맞추고 캘리브레이션**해야 합니다 (BLUEPRINT B7). 필터를 떼거나 바꾸면 D1·D2 를 다시 합니다.
- **D1 타깃이 어두워짐**: 대역통과 필터를 끼우면 일반 조명 아래의 체커보드가 거의 안 보입니다. → 레이저와 같은 색(같은 파장 대역)의 LED 조명을 씁니다 (BLUEPRINT D1).
- **편광 필터 (선택)**: 금속·광택면의 정반사(거울 반사)는 편광 상태를 유지하는 성질이 있어, 편광 필터로 줄일 수 있습니다. 단점: 빛이 절반 이하로 줄고, 회전 각도가 바뀌면 밝기가 바뀝니다(각도 잠금 필요). 회색 불투명 무광 PLA(E1 기본 재료)에는 보통 불필요합니다.

### 2.4 필터 vs 배경 차감

| 방법 | 원리 | 장점 | 단점 |
|---|---|---|---|
| 대역통과 필터 | 광학적으로 주변광 차단 | 항상 동작, 노이즈 추가 없음 | 비용(대략 10만~30만 원, **견적 필요**) |
| 배경 차감 | 레이저 끈 영상을 빼기 | 추가 부품 없음 | 촬영 2배, 노이즈가 √2 배, 주변광이 변하면 실패 |
| 차광막·인클로저 | 빛 자체를 막음 | 가장 확실 | 작업성 저하 |

6.2절 시뮬레이션처럼 **필터만으로 충분한 경우 배경 차감은 오히려 노이즈를 조금 늘립니다.** 필터 + 차광막을 기본으로 하고, 배경 차감은 C5 기준을 못 맞출 때 추가합니다.

## 6. Python 구현

### 6.1 필터 통과대역 점검 (`b7_filter_spec.py`)

```python
# b7_filter_spec.py — 대역통과 필터 사양 점검: 입사각에 따른 중심파장 이동, 통과 대역 여유 (B7)
# 실행: python b7_filter_spec.py
import numpy as np

laser_nm = 450.0            # 레이저 공칭 파장
laser_tol_nm = 5.0          # 레이저 파장 공차 (사양서 값, 예: ±5 nm)
laser_temp_coef = 0.06      # 온도에 따른 파장 변화 [nm/°C] (대략값, 사양서 확인 필요)
temp_span_C = 10.0          # 운용 온도 변화 폭
n_eff = 2.0                 # 필터 유효 굴절률 (사양서, 대략 1.5~2.2)
cwl_tol_nm = 2.0            # 필터 중심파장 공차
fwhm_nm = 10.0              # 필터 반치폭 후보

# 1) 입사각 θ 에서 중심파장: λ(θ) = λ0 · sqrt(1 − (sinθ / n_eff)²)  (간섭 필터의 짧은 파장 쪽 이동)
half_fov_mm, wd_mm = 10.0, 125.0
field_deg = np.degrees(np.arctan(half_fov_mm / wd_mm))     # 렌즈 앞 필터에 들어오는 최대 각 (근사)
for ang in (0.0, field_deg, 10.0, 20.0):
    shift = laser_nm * (1 - np.sqrt(1 - (np.sin(np.radians(ang)) / n_eff) ** 2))
    print(f"입사각 {ang:5.2f}° → 중심파장 {shift:5.2f} nm 짧아짐")

# 2) 대역 여유: 최악의 레이저 파장 이동 합이 반치폭 절반 안에 들어오는가
worst = laser_tol_nm + laser_temp_coef * temp_span_C + cwl_tol_nm \
        + laser_nm * (1 - np.sqrt(1 - (np.sin(np.radians(field_deg)) / n_eff) ** 2))
print(f"\n최악 파장 어긋남 합계 ≈ {worst:.1f} nm, 반치폭 절반 = {fwhm_nm / 2:.1f} nm")
print("판정:", "OK" if worst <= fwhm_nm / 2 else "반치폭을 넓히거나(예: 20~25 nm) 실제 파장을 측정해 맞출 것")

# 3) 주변광 차단 효과 (광대역 백색광을 400~700 nm 균일 분포로 단순화)
for bw in (10, 25, 50):
    frac = bw / 300 * 0.9          # 통과대역 비율 × 최대 투과율 90 % 가정
    print(f"반치폭 {bw:2d} nm → 주변광 약 {frac * 100:4.1f} % 만 통과 (약 1/{1 / frac:.0f})")
```

실행 예시와 기대 출력:

```
$ python b7_filter_spec.py
입사각  0.00° → 중심파장  0.00 nm 짧아짐
입사각  4.57° → 중심파장  0.36 nm 짧아짐
입사각 10.00° → 중심파장  1.70 nm 짧아짐
입사각 20.00° → 중심파장  6.63 nm 짧아짐

최악 파장 어긋남 합계 ≈ 8.0 nm, 반치폭 절반 = 5.0 nm
판정: 반치폭을 넓히거나(예: 20~25 nm) 실제 파장을 측정해 맞출 것
반치폭 10 nm → 주변광 약  3.0 % 만 통과 (약 1/33)
반치폭 25 nm → 주변광 약  7.5 % 만 통과 (약 1/13)
반치폭 50 nm → 주변광 약 15.0 % 만 통과 (약 1/7)
```

읽는 법: 기준안 화각(4.57°)에서 입사각 이동은 0.36 nm 로 작습니다. 그러나 레이저 공차(±5 nm)·온도 변화·필터 공차를 합치면 약 8 nm 로, 반치폭 10 nm 필터의 절반(5 nm)을 넘습니다. 그래서 **25 nm 필터를 권장**하거나, 레이저 실제 파장을 측정해서 10 nm 필터를 맞춥니다. 주변광 차단은 25 nm 에서도 약 1/13 이고, 차광막과 함께 쓰면 충분합니다. (계산은 백색광을 단순화한 대략값이며, 형광등·LED 처럼 특정 파장에 강한 빛이 있으면 실제 차단율은 다릅니다. 5단계 실측이 최종 판정입니다.)

### 6.2 주변광이 선 중심에 주는 영향 (`b7_ambient_test.py`)

```python
# b7_ambient_test.py — 주변광이 선 중심 추출에 주는 오차와 필터·배경차감 효과 (B7, C5 연계)
# 합성 이미지: 기울어진 레이저 선 + 한쪽이 밝은 주변광(그라디언트) + 노이즈
# 실행: python b7_ambient_test.py
import numpy as np

rng = np.random.default_rng(3)
H, W = 200, 400
rows = np.arange(H)[:, None]
true_v = 100 + 0.02 * np.arange(W)                         # 참 선 중심 (열마다 조금씩 기울어짐)
laser = 180 * np.exp(-0.5 * ((rows - true_v[None, :]) / 1.5) ** 2)
ambient_full = np.tile(np.linspace(20, 120, H)[:, None], (1, W))   # 위→아래로 밝아지는 주변광


def centroid(img, thr, half_win=6):
    """열마다 최대점 주변 창에서 (밝기 − thr) 가중 무게중심 → v [px]"""
    peak = img.argmax(axis=0)
    v = np.full(img.shape[1], np.nan)
    for u in range(img.shape[1]):
        r0, r1 = max(peak[u] - half_win, 0), min(peak[u] + half_win + 1, img.shape[0])
        w = np.clip(img[r0:r1, u] - thr, 0, None)
        if w.sum() > 0:
            v[u] = r0 + (w * np.arange(r1 - r0)).sum() / w.sum()
    return v


def snap(ambient_gain):
    """레이저 켠 영상과 끈 영상(배경) 한 쌍을 8bit로 '촬영'"""
    amb = ambient_full * ambient_gain
    on = np.clip(laser + amb + rng.normal(0, 1, (H, W)), 0, 255)
    off = np.clip(amb + rng.normal(0, 1, (H, W)), 0, 255)
    return on, off


print("조건                         | 주변광/신호 비 | 중심 치우침[px] | 중심 오차 RMS[px]")
for name, gain, subtract in (("필터 없음, 차감 없음", 1.0, False),
                             ("필터 없음, 배경 차감", 1.0, True),
                             ("필터 있음(주변광 1/30)", 1 / 30, False),
                             ("필터 + 배경 차감", 1 / 30, True)):
    on, off = snap(gain)
    img = np.clip(on - off, 0, None) if subtract else on
    ratio = off.max() / on.max()                    # C5 완료 기준: < 5 %
    err = centroid(img, thr=10) - true_v
    print(f"{name:<24} |    {ratio * 100:5.1f} %    |   {np.nanmean(err):+.3f}      |   {np.sqrt(np.nanmean(err**2)):.3f}")
```

실행 예시와 기대 출력:

```
$ python b7_ambient_test.py
조건                         | 주변광/신호 비 | 중심 치우침[px] | 중심 오차 RMS[px]
필터 없음, 차감 없음             |     48.3 %    |   +0.061      |   0.169
필터 없음, 배경 차감             |     48.0 %    |   +0.001      |   0.014
필터 있음(주변광 1/30)          |      4.3 %    |   +0.001      |   0.011
필터 + 배경 차감               |      4.0 %    |   +0.000      |   0.013
```

읽는 법:
- 필터 없이 주변광이 레이저의 약 48 % 이면, 선 중심이 밝은 쪽으로 평균 +0.06 px 치우치고 흔들림(RMS)이 0.17 px 입니다. 기준안에서 0.17 px ≈ 4.7 µm 높이 오차입니다.
- 필터(주변광 1/30)만으로 비율이 4.3 % 가 되어 **C5 기준(< 5 %)을 통과**하고 오차도 0.011 px 로 작아집니다.
- 필터가 있는데 배경 차감까지 하면 오히려 0.011 → 0.013 px 로 조금 나빠집니다 (빼는 영상의 노이즈가 더해짐).
- 실제 시험(5단계 5번)에서는 `on`, `off` 를 실제 영상으로 바꾸고 `ratio`, `centroid` 부분만 그대로 씁니다.

## 9. 위험 요소

- **파장 불일치**: 레이저(B6)를 나중에 바꾸면 필터도 바꿔야 하고, 그러면 D1·D2 재교정이 필요합니다. 파장은 M0 에서 고정합니다.
- **주변광 변화**: 낮·밤, 커튼, 다른 장비 조명에 따라 주변광이 바뀝니다. 측정 세션마다 레이저 끈 영상 1장을 찍어 비율을 기록하면(F3 메타데이터) 문제를 나중에 추적할 수 있습니다.
- **간섭 필터의 온도 의존성**: 필터 중심파장도 온도에 따라 미세하게 이동합니다(보통 레이저보다 작음). 실내 온도 기록(C6)과 함께 관리합니다.
- **납기**: 특정 파장·규격 필터는 주문 제작으로 납기가 길 수 있습니다. 재고품 우선, 필요 시 어댑터 링 사용.
