## 1. 목적

- 측정 센서를 **사서 쓸지(상용 레이저 프로파일러)**, **만들어 쓸지(산업용 카메라 + 라인 레이저 자작)** 를 W2 말(2026-10-19)까지 결정합니다.
- 이 결정은 이후 일정 전체를 바꿉니다. 자작이면 B4~B7 부품 선정과 D 영역 캘리브레이션(W7~W12)이 모두 필요하고, 상용이면 그 부분이 "사양 확인·검증"으로 줄어듭니다 (BLUEPRINT B3).
- 감(感)이 아니라 **기준·가중치·점수·근거 자료가 남는 결정 기록**을 만듭니다. 나중에 논문 "측정 시스템" 절과 지도교수 보고의 근거가 됩니다.

## 2. 배경 지식 (초보자용)

### 2.1 두 선택지는 무엇이 다른가

| 기준 | 상용 2D/3D 레이저 프로파일러 | 자작 (산업용 카메라 + 라인 레이저) |
|---|---|---|
| 구성 | 카메라·레이저·렌즈·처리기가 한 상자에 들어 있음 | B4~B7 부품을 따로 사서 브래킷에 조립 |
| 출력 | 보통 **mm 단위 프로파일**(x, z)이 바로 나옴 | 이미지 → 선 중심 추출(F1) → 삼각측량(D2) 을 직접 구현 |
| 비용 (대략, **견적 필요**) | 수백만~수천만 원 | 수십만~수백만 원 (K3 합계 약 200만~750만 원, 스테이지 포함) |
| 캘리브레이션 | 공장에서 완료 | **직접 해야 함** (D 영역 전체, 약 6주) |
| 정밀도 | 사양서로 제시 (단, 시험 조건 확인 필요) | 직접 검증해야 함 |
| 연구 기여 | 분석 방법론(G·H·I)에 집중 | 측정 시스템 자체도 연구 결과 |
| 유연성 | 각도·배율·파장 고정 | 자유롭게 변경 |
| 초보 난이도 | 쉬움 | 어려움 |

(BLUEPRINT B3 표를 확장)

### 2.2 상용 사양서를 읽을 때 꼭 확인할 것

사양서 숫자는 **제조사가 고른 가장 좋은 조건**에서 측정된 경우가 많습니다. 같은 이름의 숫자라도 정의가 다를 수 있습니다.

| 사양서 항목 | 확인할 점 | 우리 목표와 비교하는 법 |
|---|---|---|
| Z 반복성 (repeatability) | **평균 횟수**(예: 16회 평균), **타깃 재질**(백색 세라믹 등), 1σ 인지 | 우리 조건(회색 PLA, 평균 없음)에서는 더 나빠질 수 있음. 데모 측정 요청 |
| Z 직선성 (linearity) | 보통 **±% of F.S.**(측정 범위 전체 대비 %) | `% × 측정범위` 로 µm 환산 (6.2절) |
| 측정 범위 (Z range) | 기준 거리(Reference distance)와 근거리~원거리 범위 | 시편 높이 + 여유 ≥ 범위인지 |
| FOV / 프로파일당 점 수 | FOV 가 **사다리꼴**(근거리는 좁고 원거리는 넓음) | 가장 성긴 X 간격(원거리) = FOV_far / 점 수 ≤ 0.02 mm 인지 |
| 프로파일 속도 | 최대 속도가 ROI 축소 조건인지 | 필요 속도 = 스캔 속도 / 간격 (예: 100 Hz) |
| 레이저 | 파장(청색/적색), **안전 등급** | C8 기준 Class 2 권장. 3R 이상이면 교육·관리 필요 |
| 인터페이스 | Ethernet/USB, **Python 에서 쓸 수 있는 SDK·예제**, 엔코더 입력 | Python 사용 가능 여부가 초보 팀에서는 결정적 |
| 원시 데이터 | 이미지·강도(intensity) 값 접근 가능 여부 | 품질 필터링(F1 신뢰도)에 필요 |

### 2.3 결정 방법: 가중 점수표 (decision matrix)

1. 평가 기준을 정하고 **가중치**(합 = 1)를 줍니다. 가중치는 연구 목표를 숫자로 표현한 것입니다.
2. 각 선택지에 기준별 **1~5점**을 줍니다. 점수마다 근거(견적서, 사양서, 일정 계산)를 붙입니다.
3. `총점 = Σ(가중치 × 점수)` 를 비교합니다.
4. **민감도 분석**: 가중치를 흔들어도 1위가 유지되는지 확인합니다. 결과가 자주 뒤집히면 "점수표로 결정할 수 없는 상황"이므로, 연구 목표(2.4절)로 결정합니다.

### 2.4 한 줄 원칙 (BLUEPRINT B3 권장)

- 예산이 있고 목적이 **"공정 오차 분석"** → **상용 프로파일러**. B4~B7, D1~D2 는 "사양 확인"으로 대체.
- 예산이 적거나 **"저비용 측정 시스템 개발"** 도 연구 목표 → **자작**. 이 문서 묶음(B4~B7, D)은 자작 기준으로 가장 자세히 씁니다.

## 6. Python 구현

### 6.1 가중 점수표 + 민감도 분석 (`b3_decision.py`)

```python
# b3_decision.py — 상용 vs 자작 가중 점수표와 가중치 민감도 분석 (B3)
# 실행: python b3_decision.py
import numpy as np
import pandas as pd

# 1) 평가 기준과 가중치 (합 = 1.0). 연구실 회의에서 숫자를 정해 바꿔 넣는다.
weights = {
    "예산 적합성": 0.25,
    "정밀도 확보 확실성": 0.20,
    "일정 위험(M2 통과 가능성)": 0.20,
    "연구 기여(시스템 자체)": 0.15,
    "유연성(각도·파장 변경)": 0.10,
    "초보 난이도": 0.10,
}
# 2) 각 선택지 점수 (1 = 나쁨 ~ 5 = 좋음). 아래 값은 '예시'이며 실제 견적·사양을 보고 채운다.
scores = pd.DataFrame({
    "상용 프로파일러": [2, 5, 5, 2, 2, 5],
    "자작(DIY)":     [4, 3, 2, 5, 5, 2],
}, index=list(weights))

w = pd.Series(weights)
assert abs(w.sum() - 1.0) < 1e-9, "가중치 합은 1이어야 합니다"

total = scores.mul(w, axis=0).sum()
print("== 가중 점수 (5점 만점) ==")
print(total.round(2).to_string())

# 3) 민감도: 가중치를 무작위로 ±50 % 흔들어 1000번 다시 계산 → 결론이 뒤집히는 비율
rng = np.random.default_rng(42)
wins = {c: 0 for c in scores.columns}
for _ in range(1000):
    w_rand = w * rng.uniform(0.5, 1.5, size=len(w))
    w_rand /= w_rand.sum()
    t = scores.mul(w_rand, axis=0).sum()
    wins[t.idxmax()] += 1
print("\n== 가중치 ±50 % 흔들었을 때 1위 비율 ==")
for c, n in wins.items():
    print(f"{c}: {n / 10:.1f} %")

# 4) 기준별 차이 (어떤 기준이 결론을 끌고 가는지)
contrib = scores.mul(w, axis=0)
contrib["차이(상용-자작)"] = contrib["상용 프로파일러"] - contrib["자작(DIY)"]
print("\n== 기준별 기여 ==")
print(contrib.round(2).to_string())
```

읽는 법: 예시 점수에서는 3.50 대 3.45 로 거의 같고, 가중치를 흔들면 1위가 54 % 대 46 % 로 갈립니다. 이는 **점수표만으로는 결정할 수 없다**는 뜻이며, 실제로 흔한 상황입니다. 기준별 기여를 보면 상용은 "일정 위험·정밀도 확실성"에서, 자작은 "예산·연구 기여"에서 이깁니다. 결국 2.4절의 연구 목표(무엇이 기여인가)가 결정 요인입니다. 숫자를 실제 견적과 팀 가중치로 바꿔 다시 돌립니다.

```python
# b3_spec_check.py — 상용 프로파일러 사양서 값을 A2 목표와 같은 단위로 바꿔 비교 (B3)
# 아래 두 후보의 숫자는 '가상의 예시'이다. 실제 제품 사양서 값으로 바꿔 넣는다.
# 실행: python b3_spec_check.py
import pandas as pd

TARGET = {"z_rep_um": 5.0, "xy_pitch_mm": 0.02, "fov_mm": 20.0, "z_range_mm": 12.0}

datasheets = [
    {"후보": "가상 상용 A", "z_range_mm": 25.0, "linearity_pctFS": 0.02,
     "z_rep_um": 1.0, "points_per_profile": 1280, "fov_near_mm": 18.0, "fov_far_mm": 26.0,
     "profile_rate_hz": 2000, "rep_condition": "평균 16회, 백색 세라믹 타깃"},
    {"후보": "가상 상용 B", "z_range_mm": 60.0, "linearity_pctFS": 0.05,
     "z_rep_um": 4.0, "points_per_profile": 640, "fov_near_mm": 40.0, "fov_far_mm": 70.0,
     "profile_rate_hz": 1000, "rep_condition": "평균 없음, 확산 금속 타깃"},
]


def evaluate(d):
    lin_um = d["linearity_pctFS"] / 100 * d["z_range_mm"] * 1000   # %FS → µm
    pitch_near = d["fov_near_mm"] / d["points_per_profile"]          # 가장 촘촘한 X 간격
    pitch_far = d["fov_far_mm"] / d["points_per_profile"]            # 가장 성긴 X 간격
    return {
        "후보": d["후보"],
        "직선성 [um]": round(lin_um, 1),
        "반복성 [um]": d["z_rep_um"],
        "X 간격 근거리 [mm]": round(pitch_near, 4),
        "X 간격 원거리 [mm]": round(pitch_far, 4),
        "Z 반복성 OK": d["z_rep_um"] <= TARGET["z_rep_um"],
        "X 간격 OK(원거리)": pitch_far <= TARGET["xy_pitch_mm"],
        "FOV OK(근거리)": d["fov_near_mm"] >= TARGET["fov_mm"] * 0.9,
        "Z 범위 OK": d["z_range_mm"] >= TARGET["z_range_mm"],
        "반복성 조건": d["rep_condition"],
    }


if __name__ == "__main__":
    df = pd.DataFrame([evaluate(d) for d in datasheets]).set_index("후보")
    print(df.T.to_string())
```

```
X 간격 근거리 [mm]             0.0141           0.0625
X 간격 원거리 [mm]             0.0203           0.1094
Z 반복성 OK                    True             True
X 간격 OK(원거리)               False            False
FOV OK(근거리)                 True             True
Z 범위 OK                     True             True

```

읽는 법: "가상 상용 A" 는 반복성 1 µm 로 매우 좋아 보이지만 **16회 평균, 백색 세라믹 타깃** 조건입니다. 또 원거리에서 X 간격이 0.0203 mm 로 목표(0.02 mm)를 아주 조금 넘습니다. 이런 경우 측정 거리를 근거리 쪽으로 쓰면 해결될 수 있으므로, 자동 판정 결과를 그대로 믿지 말고 사람이 해석을 적습니다.

## 9. 위험 요소

- **결정 지연**: 이 요소는 "긴급"입니다. 2026-10-16 까지 결정하지 못하면 B4~B7 주문이 밀리고 D 영역(W7~)이 늦어집니다. 정보가 부족해도 **잠정 결정 + 재검토 조건**으로 진행합니다.
- **자작 선택 시 성능 미달**: M2(2026-12-14) 에서 게이지 블록 단차 오차 < 10 µm 를 통과하지 못할 수 있습니다. 대응: 상용 대여·공동기기 활용 조건을 결정 기록서에 미리 적어 둡니다 ([K4](../K-management/K4-risks.md)).
- **상용 선택 시 연구 기여 약화**: 측정 시스템 개발 부분이 빠집니다. 대응: G·H 의 마스킹·지표 방법론과 I 의 신뢰성 검증을 기여의 중심으로 재정의합니다 ([K5](../K-management/K5-deliverables-paper.md)).
- **가격 정보 불확실**: 이 문서의 비용 범위는 대략값입니다. 결정은 반드시 실제 견적서로 합니다.
