## 1. 목적

- 측정 정밀도·안전·비용을 함께 고려해 **라인 레이저 모듈 1종**(파장, 라인 광학, 팬각, 선 두께, 출력)을 고릅니다.
- 선 두께가 측정 깊이 범위에서 얼마나 변하는지, 스펙클 노이즈가 파장에 따라 얼마인지, 1 mW 로 빛이 충분한지를 **계산으로 확인**합니다.
- 도착 후 **수입 검사**(선 균일도, 선 두께, 직진성)와 **워밍업 시간 측정**을 해서 운용 규칙(예: 켠 뒤 30분 대기)을 정합니다.

## 2. 배경 지식 (초보자용)

### 2.1 라인 레이저 모듈의 구성

```
 [레이저 다이오드] → [초점 렌즈(조절형)] → [라인 생성 렌즈] → 부채꼴 빛의 면(레이저 평면)
                                            · 원통 렌즈: 가운데 밝고 양 끝 어두움
                                            · 파월 렌즈: 선 전체 밝기가 거의 균일 (권장)
```

- **팬각**: 부채꼴이 펼쳐지는 각도. `선 길이 = 2 · WD_laser · tan(팬각/2)` (BLUEPRINT B6).
- **선 두께**: 물체 위에서 선의 폭. 초점 조절형 모듈은 특정 거리에서 가장 가늘게 맞출 수 있습니다.
- **TTL/아날로그 변조 입력**: 전기 신호로 레이저를 켜고 끄거나 밝기를 바꾸는 기능. "레이저 끈 배경 영상"(C5, B7)을 자동으로 찍으려면 있으면 편리합니다.

### 2.2 파장 선택

| 파장 | 색 | 장점 | 단점 |
|---|---|---|---|
| 405 nm | 청자색 | 플라스틱 속으로 덜 파고듦, 스펙클 가장 작음 | 카메라 감도(QE)·렌즈 투과율이 낮을 수 있음, **눈에 어둡게 보여 출력을 과소평가하기 쉬움**(C8) |
| 450 nm | 청색 | 405 nm 와 비슷한 장점, 카메라 감도가 더 좋은 경우가 많음 | 적색보다 비쌀 수 있음 (견적 필요) |
| 520 nm | 녹색 | 눈에 잘 보여 정렬 쉬움 | 중간 |
| 650 nm | 적색 | 저렴하고 흔함 | 반투명 플라스틱 속으로 깊이 파고들어 **계통 오차 큼**, 스펙클 큼 |

(BLUEPRINT B6: 405~450 nm 청색 권장)

### 2.3 스펙클 — 레이저 측정의 근본 노이즈

레이저 빛은 결이 매우 고른(가간섭성) 빛이라서, 거친 표면에서 반사되면 **반짝이는 얼룩 무늬(스펙클)** 를 만듭니다. 이 얼룩이 선 단면 모양을 무작위로 비틀어 **중심이 흔들립니다**. 같은 위치를 여러 번 찍어도 얼룩이 같아서 **프레임 평균으로 줄지 않습니다** (BLUEPRINT F2).

단일 점 높이 불확도의 대략적인 크기 (Dorsch·Häusler 계열 공식):

```
δz_speckle ≈ C · λ / (2π · sin(u) · sinθ)
   C: 스펙클 대비 (0~1, 최악 1), λ: 파장, sin(u) ≈ (f/N) / (2·WD): 관측 개구, θ: 삼각측량 각
```

- 파장이 짧을수록(λ ↓), 조리개가 클수록(N ↓), 각도가 클수록(θ ↑) 작아집니다.
- 기준안(450 nm, f/8, θ 30°)에서 약 **11.5 µm**. 점 여러 개를 평균하는 지표(평면 중앙값, 단차)에서는 이보다 훨씬 작아집니다.
- 실제 C 는 표면·움직임에 따라 1 보다 작을 수 있습니다. 연속 스캔 중 노출 시간 동안 시편이 움직이면 얼룩이 일부 평균됩니다.

### 2.4 선 두께와 깊이

레이저 빛은 초점에서 가장 가늘고, 멀어질수록 두꺼워집니다 (가우시안 빔). 두꺼워지는 정도는 **레일리 거리 z_R = π w0² / (λ · M²)** 으로 정해집니다 (w0: 초점의 반지름, M²: 빔 품질, 1 이 이상적). 초점을 너무 가늘게 만들면 z_R 이 짧아져서 측정 깊이 끝에서 오히려 두꺼워집니다. **선 두께 목표: 이미지에서 3~7 px** (BLUEPRINT B6) → 기준안에서 물체 위 약 50~110 µm.

### 2.5 출력과 안전

- 출력 1 mW 이하 가시광 = 보통 **Class 2** (눈 깜빡임 반사로 보호). 이 과제에 권장 (BLUEPRINT C8).
- 6.2절 광량 계산상 1 mW 로도 밝은 표면은 800 µs 노출에서 포화될 만큼 빛이 충분합니다. **출력을 올리기 전에 노출 시간을 먼저 늘립니다.**
- 안전 등급은 **제품 라벨과 사양서의 등급 표기**로 확인합니다. 등급 없는 모듈(출처 불명)은 구매하지 않습니다.

### 2.6 워밍업

레이저 다이오드는 켠 직후 온도가 오르면서 출력과 빛의 방향이 조금씩 변합니다. 선이 0.6 px 만 움직여도 기준안에서 약 16 µm 높이 오차입니다. 그래서 **안정될 때까지 기다린 뒤 측정**합니다 (BLUEPRINT: 15~30분).

## 6. Python 구현

### 6.1 팬각·선 두께·스펙클 계산 (`b6_laser_calc.py`)

```python
# b6_laser_calc.py — 라인 레이저 사양 계산: 팬각, 선 두께와 깊이 변화, 이미지 두께, 스펙클 (B6)
# 실행: python b6_laser_calc.py
import numpy as np

# ---- 배치 입력 (B1, B2) ----
FOV_mm = 20.0          # 덮어야 할 측정 폭
margin = 1.2           # 선 길이 여유 (양 끝 어두운 부분 제외용 20 %)
WD_laser = 100.0       # 레이저 출사구 ~ 측정면 거리 [mm]
M, p_um, theta = 0.25, 3.45, np.radians(30)
N_f, f_mm, WD_cam = 8, 25.0, 125.0

# 1) 팬각: 선 길이 = 2 · WD_laser · tan(팬각/2)  →  팬각 = 2·atan(L / (2·WD_laser))
L_need = FOV_mm * margin
fan_need = np.degrees(2 * np.arctan(L_need / (2 * WD_laser)))
print(f"필요 선 길이 {L_need:.0f} mm → 필요 팬각 ≥ {fan_need:.1f}°")
for fan in (10, 20, 30, 45):
    L = 2 * WD_laser * np.tan(np.radians(fan / 2))
    print(f"  팬각 {fan:2d}° → 선 길이 {L:5.1f} mm (FOV 대비 {L / FOV_mm:4.1f} 배)")

# 2) 선 두께의 깊이 방향 변화 (가우시안 빔 근사, M2 = 빔 품질 계수, 1 = 이상적)
print("\n선 두께(1/e² 지름) [um] : 초점에서 떨어진 거리별")
dz_list = (0, 3, 6, 10)
print("  λ[nm] 초점두께  M2  z_R[mm] | " + " ".join(f"{d:>4d}mm" for d in dz_list))
for lam_nm in (405, 450, 650):
    for t0_um, m2 in ((50, 1.0), (50, 2.0), (100, 2.0)):
        w0 = t0_um / 2 / 1000                         # 허리 반지름 [mm]
        zR = np.pi * w0**2 / (lam_nm * 1e-6 * m2)     # 레일리 거리 [mm]
        t = [t0_um * np.sqrt(1 + (d / zR) ** 2) for d in dz_list]
        print(f"  {lam_nm:4d}  {t0_um:5d}   {m2:3.1f}  {zR:6.2f} | " + " ".join(f"{x:6.0f}" for x in t))

# 3) 물체 위 선 두께 → 이미지 두께 [px] (카메라에서 y 방향 길이는 M·cosθ 배로 보임)
print("\n물체 위 두께 → 이미지 두께 (권장 3~7 px)")
for t_um in (30, 50, 80, 100, 150):
    print(f"  {t_um:3d} um → {t_um * M * np.cos(theta) / p_um:4.1f} px")

# 4) 파장별 스펙클 한계 (Dorsch·Häusler 계열 공식, 대비 C=1 가정한 단일 점 최악값)
sin_u = f_mm / (2 * N_f * WD_cam)
print(f"\n스펙클 높이 불확도 (f/{N_f}, θ=30°, 단일 점, C=1)")
for lam_nm in (405, 450, 520, 650):
    dz = lam_nm / 1000 / (2 * np.pi * sin_u * np.sin(theta))
    print(f"  {lam_nm} nm → {dz:5.1f} um")
```

```
$ python b6_laser_calc.py
필요 선 길이 24 mm → 필요 팬각 ≥ 13.7°
```

읽는 법:
- 팬각 20° 면 선 길이 35 mm 로 FOV 20 mm 를 넉넉히 덮습니다. 10° 는 부족합니다.
- 450 nm, 초점 두께 50 µm, M² = 2 이면 초점에서 6 mm 떨어진 곳에서 146 µm(이미지 약 9 px)로 두꺼워집니다. 초점 두께를 약간 두껍게(예: 80~100 µm) 잡으면 깊이 방향 변화가 작아집니다 (100 µm, M² 2: 6 mm 에서 121 µm). **너무 가늘게 맞추는 것이 항상 좋은 것은 아닙니다.**
- 적색(650 nm)은 스펙클이 16.6 µm 로 청색보다 약 45 % 큽니다.

### 6.2 광량 예산 (`b6_photon_budget.py`)

```python
# b6_photon_budget.py — 광량 예산: 레이저 출력 1 mW 로 픽셀에 전자가 몇 개 모이나 (B6, B4·F2 연계)
# 가정: 램버트(완전 확산) 표면, 선 안에서 밝기 균일(파월 렌즈), 대략적 크기 확인용 계산
# 실행: python b6_photon_budget.py
import numpy as np

h, c = 6.626e-34, 2.998e8          # 플랑크 상수, 빛의 속도

P_laser_W = 1.0e-3                 # 레이저 출력 (Class 2 상한 수준)
line_len_mm, line_thick_mm = 35.0, 0.05   # 팬각 20°, WD_laser 100 mm, 선 두께 50 µm
f_mm, N, WD_mm, M = 25.0, 8, 125.0, 0.25
pixel_um = 3.45
T_optics = 0.9 * 0.9               # 렌즈 투과 × 필터 투과 (대략)
QE = {405: 0.45, 450: 0.60, 650: 0.45}     # 예시 값 → 실제는 카메라 EMVA 1288 데이터 사용
FULL_WELL_E = 10000
exposure_s = 800e-6

E_irr = P_laser_W / (line_len_mm * line_thick_mm)           # 조도 [W/mm²]
D = f_mm / N                                                # 입사동 지름 [mm]
omega = np.pi * (D / 2) ** 2 / WD_mm ** 2                   # 렌즈가 보는 입체각 [sr]
A_pix_obj = (pixel_um / 1000 / M) ** 2                      # 픽셀 하나가 물체에서 보는 면적 [mm²]

print(f"조도 {E_irr * 1e3:.2f} mW/mm², 렌즈 입체각 {omega:.2e} sr")
print("반사율 | 파장 | 전자 수/픽셀 (800 us) | 포화 대비")
for rho in (0.8, 0.3, 0.05):                                # 흰색 무광 / 회색 / 검정
    L = rho * E_irr / np.pi                                 # 휘도 [W/(mm²·sr)]
    P_pix = L * A_pix_obj * omega * T_optics                # 픽셀에 들어오는 빛 [W]
    for lam in (405, 450, 650):
        n_e = P_pix * exposure_s / (h * c / (lam * 1e-9)) * QE[lam]
        print(f"  {rho:4.2f} | {lam} | {n_e:10.0f}            | {100 * n_e / FULL_WELL_E:6.1f} %")
```

읽는 법: 흰 무광 표면(반사율 0.8)은 1 mW, 800 µs 에서 이미 포화(100 % 초과)되므로 노출을 약 500 µs 이하로 줄여야 합니다. 회색(0.3)은 30~49 % 로 적당하고, 검정(0.05)은 5~8 % 로 어두우므로 노출을 5~10배 늘리거나(연속 스캔이면 2.5 ms 노출 상한 주의, B4) 회색 재료를 씁니다 (E1 권장: 회색 불투명 PLA). 이 값은 **크기 가늠용**이며 반투명 재료의 내부 산란은 반영하지 않습니다.

### 6.3 워밍업 안정화 판정 (`b6_warmup.py`)

```python
# b6_warmup.py — 레이저 워밍업(안정화) 시간 판정 (B6)
# 실제 실험: 레이저를 켠 직후부터 30초마다 정지된 평판의 선 중심 평균 v 와 피크 밝기를 기록 (60분)
# 여기서는 같은 형태의 합성 데이터를 만들어 판정 함수를 검증한다.
# 실행: python b6_warmup.py
import numpy as np
import pandas as pd


def make_synthetic(seed=1):
    """지수함수형 드리프트 + 노이즈를 가진 가짜 워밍업 기록 (정답: 시정수 8분)"""
    rng = np.random.default_rng(seed)
    t_min = np.arange(0, 60.01, 0.5)                               # 0.5분(30초) 간격
    v_mean = 540.0 + 0.6 * np.exp(-t_min / 8.0) + rng.normal(0, 0.005, t_min.size)
    peak = 200 * (1 - 0.08 * np.exp(-t_min / 5.0)) + rng.normal(0, 0.5, t_min.size)
    return pd.DataFrame({"t_min": t_min, "v_mean_px": v_mean, "peak_dn": peak})


def warmup_time(df, window_min=5.0, v_tol_px=0.02, peak_tol_pct=1.0):
    """'이후 window_min 분 동안 v 변화폭 ≤ v_tol_px 이고 밝기 변화폭 ≤ peak_tol_pct %' 를
    처음 만족하는 시각을 안정화 시간으로 본다."""
    dt = df["t_min"].iloc[1] - df["t_min"].iloc[0]
    n = int(round(window_min / dt)) + 1
    for i in range(len(df) - n + 1):
        win = df.iloc[i:i + n]
        v_span = win["v_mean_px"].max() - win["v_mean_px"].min()
        p_span = 100 * (win["peak_dn"].max() - win["peak_dn"].min()) / win["peak_dn"].mean()
        if v_span <= v_tol_px and p_span <= peak_tol_pct:
            return win["t_min"].iloc[0], v_span, p_span
    return None, None, None


if __name__ == "__main__":
    df = make_synthetic()
    t, v_span, p_span = warmup_time(df)
    print(f"안정화 시각: {t:.1f} 분 (창 안 v 변화 {v_span:.3f} px, 밝기 변화 {p_span:.2f} %)")
    dz_um_per_px = 27.6                                 # B1 기준안의 1px 높이
    drift = df["v_mean_px"].iloc[0] - df["v_mean_px"].iloc[-1]
    print(f"켠 직후~60분 총 드리프트: {drift:.2f} px ≈ {drift * dz_um_per_px:.0f} um 높이 오차")
```

실행 예시와 기대 출력 (합성 데이터 정답: 시정수 8분 → 약 20분 뒤 안정):

```
$ python b6_warmup.py
안정화 시각: 20.0 분 (창 안 v 변화 0.015 px, 밝기 변화 0.69 %)
켠 직후~60분 총 드리프트: 0.59 px ≈ 16 um 높이 오차
```

실제 데이터에서는 `df = pd.read_csv("data/raw/acceptance/laser/2026-10-29/warmup.csv")` 로 읽고(열 이름 `t_min, v_mean_px, peak_dn`) `warmup_time(df)` 를 호출합니다. 이 예에서 운용 워밍업 시간은 20 + 10 = 30분입니다.

## 9. 위험 요소

- **안전**: 가시광 레이저라도 반사·직접 응시는 위험합니다. 등급 확인, 빔 높이·방향 관리, 교육은 [C8](../C-mechanics/C8-laser-safety.md) 에서 W5~6 에 완료해야 합니다. 그 전에는 **차광 상태에서 짧게만** 켭니다.
- **파장 공차와 필터 불일치**: 레이저 실제 파장이 필터 통과대역에서 벗어나면 신호가 크게 줄어듭니다. B7 6.1절의 "최악 어긋남" 계산을 반드시 통과시킵니다.
- **스펙클 한계**: 단일 점 약 11.5 µm 는 A2 목표(5 µm)보다 큽니다. 면 평균 지표로 목표를 달성하는지 M2 에서 판정합니다. 부족하면 조리개 개방(초점 범위 감소와 맞교환, B2), 각도 증가, 또는 목표 재정의(A2)를 검토합니다.
- **모듈 품질 편차**: 같은 모델이라도 선 두께·균일도가 다를 수 있습니다. 수입 검사로 확인하고, 불합격이면 교환을 요청합니다.
