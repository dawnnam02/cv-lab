## 1. 목적

측정 시스템을 만들고 검증하는 데 필요한 돈을 **품목별 범위(최소~최대)** 로 정리하고, 예산 한도 안에서 **무엇을 사고 무엇을 빌리거나 대체할지** 결정합니다.

- 모든 금액은 **대략적인 시세이며 실제 견적이 필요**합니다. 이 문서의 숫자를 그대로 예산 신청서에 쓰지 말고, 견적서를 받아 갱신합니다.
- 결정의 핵심은 두 가지입니다: ① **상용 프로파일러 vs 자작** (B3) ② **전동 스테이지 구매 vs 3D프린터 축 활용** (C1).

## 2. 배경 지식 (초보자용)

| 용어 | 뜻 |
|---|---|
| 견적서 | 판매처가 품목·수량·가격·납기·부가세 포함 여부를 적어 주는 문서. 연구비 집행에 보통 필요 |
| 범위 예산 | 정확한 가격을 모를 때 최솟값~최댓값으로 적는 방법. 합계도 범위로 나옴 |
| 예비비 (contingency) | 예상 못 한 지출(파손, 추가 부품, 환율)을 위한 여유. 보통 10~20 % |
| 납기 (lead time) | 주문부터 받을 때까지 걸리는 시간. 해외 주문은 수 주가 걸릴 수 있음 |
| 필수 / 선택 | 필수가 없으면 과제 진행 불가, 선택은 품질 향상용 |
| 간접비·부가세 | 연구비 규정에 따라 실제 집행액이 달라짐 → 행정 담당자에게 확인 |

**왜 범위로 쓰나**: 같은 "산업용 카메라"라도 해상도·인터페이스·제조사에 따라 가격 차이가 큽니다. 처음부터 한 숫자로 쓰면 틀린 숫자에 계획이 묶입니다.

## 3. 입력과 산출물

| 산출물 | 구매 기록 | 10절 양식 |

## 4. 결정 사항

| 결정 항목 | 선택지 | 권장 | 근거 |
|---|---|---|---|
| 측정 센서 | 상용 레이저 프로파일러 / 자작 | **목적에 따라** (B3). 이 문서는 자작 기준 | 상용은 대략 수백만~수천만 원, 캘리브레이션 포함. 자작은 측정 시스템 자체가 연구 결과 |
| 스캔 이동 | 전동 스테이지 / 프린터 축 / 수동 | **예산이 빠듯하면 프린터 축으로 시작**, 정밀도 미달 시 스테이지 추가 | 스테이지가 단일 품목 중 불확실성이 가장 큼 (대략 50~300만 원) |
| 캘리브레이션 타깃 | 인쇄 종이 + 평판 / 유리·세라믹 인쇄품 | 초기 **알루미늄 복합판 부착**, D1 재투영이 0.2 px를 못 넘으면 고급품 | 대략 5~50만 원 차이 |
| 게이지 블록 | 구매 / 공동기기원·타 연구실 대여 | **대여 가능 여부 먼저 확인** | 검증 기준물이므로 인증서(교정 성적서) 필요 |
| 교차검증 장비 | 구매 / 공동기기원 이용 | **공동기기원 이용** (대표 시편 몇 개) | 장비 구매는 과제 규모에 비해 과도 |
| 예비비 | 0 / 10 / 15 / 20 % | **15 %** | 초보 연구실은 파손·재구매 확률이 높음 |
| 견적 수 | 1곳 / 2곳 이상 | **2곳 이상** (고가 품목은 3곳) | 가격·납기 비교, 행정 규정 대응 |

### 4.2 자작 vs 상용 결정 기준

| 질문 | "예"이면 | "아니오"이면 |
|---|---|---|
| 연구 목표에 "저비용 측정 시스템 개발"이 포함되는가? | 자작 | 다음 질문 |
| 확보 가능 예산이 상용 프로파일러 견적 이상인가? | 상용 검토 | 자작 |
| 광학·캘리브레이션을 배울 시간(약 8주, W3~W10)이 있는가? | 자작 가능 | 상용 또는 대여 |
| 목표 Z 반복성(≤ 5 µm)을 상용 사양서가 보증하는가? | 상용 | 자작으로 배율·각도 최적화 |

상용을 선택하면 B4~B7, D1~D2는 "사양 확인"으로 대체되지만, **D5 검증·I2 MSA·I3 교차검증 품목(게이지 블록, 마이크로미터 등)은 그대로 필요**합니다.

```python
"""K3 예산 계산기: budget.csv -> 시나리오별 최소/최대 합계 (+ 예비비)

금액 단위는 '만 원'. 모든 금액은 대략 범위이며 실제 견적이 필요합니다.
사용법:  python k3_budget.py budget.csv --scenario stage --contingency 0.15
  --scenario stage   : 전동 스테이지 구매 (scenario 열이 all 또는 stage 인 행)
  --scenario printer : 3D프린터 축으로 스캔 (scenario=stage 행 제외 = 0원)
  --optional         : 선택 품목도 포함
"""
import argparse
import pandas as pd


def select(df, scenario, optional):
    keep = df["scenario"].isin(["all", scenario])          # 시나리오에 해당하는 행만
    if not optional:
        keep &= df["required"] == "필수"                    # 기본은 필수 품목만
    return df[keep]


def summarize(df, contingency):
    by_cat = df.groupby("category")[["min_manwon", "max_manwon"]].sum()
    lo, hi = df["min_manwon"].sum(), df["max_manwon"].sum()
    return by_cat, lo, hi, lo * (1 + contingency), hi * (1 + contingency)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("csv")
    ap.add_argument("--scenario", choices=["stage", "printer"], default="stage")
    ap.add_argument("--optional", action="store_true")
    ap.add_argument("--contingency", type=float, default=0.15)   # 예비비 비율
    a = ap.parse_args()

    df = pd.read_csv(a.csv)
    bad = df[df["min_manwon"] > df["max_manwon"]]               # 입력 오류 검사
    if len(bad):
        raise SystemExit(f"최소 > 최대인 행: {list(bad['id'])}")
    sel = select(df, a.scenario, a.optional)
    by_cat, lo, hi, lo_c, hi_c = summarize(sel, a.contingency)
    label = "필수+선택" if a.optional else "필수"
    print(f"[시나리오: {a.scenario}, {label}] 품목 {len(sel)}개 (단위: 만 원, 대략·견적 필요)")
    print(by_cat.to_string())
    print(f"합계: {lo:.0f} ~ {hi:.0f}")
    print(f"예비비 {a.contingency:.0%} 포함: {lo_c:.0f} ~ {hi_c:.0f}")
    top = sel.assign(span=sel["max_manwon"] - sel["min_manwon"]).nlargest(3, "span")
    print("불확실성 큰 품목(최대-최소):",
          ", ".join(f"{r.id} {r.item}({r.span})" for r in top.itertuples()))


if __name__ == "__main__":
    main()
```

`--optional` 을 붙이면 선택 품목까지 포함합니다 (스테이지 시나리오: 257 ~ 1070, 예비비 포함 296 ~ 1230).

**활용 팁**: "불확실성 큰 품목"이 **견적을 가장 먼저 받아야 할 품목**입니다. 견적을 받으면 그 행의 최소·최대를 같은 값으로 바꾸고 다시 실행합니다.

## 9. 위험 요소

- **납기 지연** → 임계 경로(B7 → C5 → D1)가 밀림. 대응: W2 견적 단계에서 납기를 비교 기준에 포함 ([K4](K4-risks.md) 위험 등록부).
- **환율·가격 변동** → 예비비 15 %로 흡수.
- **예산 부족** → 시나리오 B(프린터 축)로 시작하고, M2에서 스캔축 정밀도(D3)가 부족할 때만 스테이지 추가 구매.
- **연구비 집행 규정** (구매 가능 시기, 해외 결제 제한) → 행정 담당자와 W1에 확인.
