## 1. 목적

과제를 실패하게 만들 수 있는 일을 **미리 목록으로 만들고**, 각각에 대해 **가능성·영향 점수, 담당자, 발생 신호(트리거), 예방책, 발생 시 대책**을 정해 둡니다.

- 문제가 터진 뒤 당황하지 않고, "신호가 보이면 이 대책을 실행한다"를 미리 약속합니다.
- 측정 연구에서 가장 치명적인 위험은 **측정 장비의 오차를 가공 오차로 잘못 보고하는 것**입니다. 이 위험을 기술 위험 목록의 중심에 둡니다.
- 청사진 K4 표의 10개 위험을 그대로 포함하고, 다른 요소에서 드러난 위험 11개를 추가했습니다 (총 21개).

## 2. 배경 지식 (초보자용)

| 용어 | 뜻 | 예 |
|---|---|---|
| 위험 (risk) | 아직 일어나지 않았지만 일어나면 목표에 영향을 주는 사건 | 레이저 평면 교정이 목표 정밀도 미달 |
| 이슈 (issue) | 이미 일어난 위험 | 렌즈가 풀려 캘리브레이션이 틀어짐 |
| 가능성 P (1~5) | 일어날 확률 | 1 거의 없음 (< 10 %), 2 낮음, 3 중간 (~50 %), 4 높음, 5 거의 확실 (> 90 %) |
| 영향 I (1~5) | 일어났을 때 피해 | 1 무시 가능, 2 며칠 지연, 3 1~2주 지연·일부 결과 품질 저하, 4 마일스톤 실패·주요 결과 신뢰성 손상, 5 인명 피해·과제 중단 |
| 점수 | P × I (1~25) | 15 이상 높음, 8~14 중간, 7 이하 낮음 |
| 트리거 | "위험이 현실이 되고 있다"는 관측 가능한 신호. **숫자로** | D5 단차 오차 > 10 µm |
| 예방 (mitigation) | 가능성이나 영향을 줄이려고 **미리** 하는 일 | 잠금 나사, 일일 점검 |
| 대책 (contingency) | 트리거가 발생하면 **실행**할 계획 | 재교정 후 새 CAL-ID |
| 위험 등록부 | 위 내용을 모은 표. 살아 있는 문서 | 4.1 표 |

**청사진 등급 → 점수 변환**: 가능성 낮음 = 2, 중 = 3, 높음 = 4 / 영향 중 = 3, 높음 = 4, 매우 높음 = 5.

**영향 5 규칙**: 레이저 안전사고처럼 영향이 5인 위험은 가능성이 낮아도 점수와 관계없이 **'높음'으로 관리**합니다.

## 4. 결정 사항

| 결정 항목 | 선택지 | 권장 | 근거 |
|---|---|---|---|
| 점수 척도 | 3단계 / 5단계 | **5 × 5** | 변화(3 → 4)를 기록하기 좋음 |
| 등급 경계 | – | **≥ 15 높음, 8~14 중간, ≤ 7 낮음, 영향 5는 항상 높음** | 소규모 과제에서 '높음'이 너무 많지 않게 |
| 검토 주기 | 수시 / 주간 / 월간 | **주간: 상위 5개 + 트리거 확인 (5분), 월간: 전체 재평가 (30분), 마일스톤: 전체 재평가 + 신규 위험 발굴** | 짧고 자주 |
| 위험 담당 | 총괄 / 관련자 | **트리거를 가장 먼저 볼 사람** | 측정값을 보는 사람이 신호를 가장 빨리 앎 |
| 대응 전략 | 회피 / 완화 / 전가 / 수용 | 높음 = 회피·완화 필수, 중간 = 완화, 낮음 = 수용 + 감시 | 표준 위험 대응 분류 |
| 기록 방식 | 문서 / 스프레드시트 / CSV | **CSV + 스크립트** | 버전 관리, 그림 자동 생성 |

**분류별 핵심 위험**
- **측정 신뢰성** (R01, R02, R03, R14): 측정 장비의 오차가 가공 오차로 둔갑할 수 있는 위험입니다. M2·M5 판정과 직결됩니다.
- **분석 방법** (R04, R06, R08, R17): 코드는 돌아가지만 숫자가 틀리는 위험입니다. 합성 데이터 테스트(J3)가 주 방어선입니다.
- **일정·자원** (R10~R13, R15, R21): 초보 연구실에서 가능성이 높습니다.
- **안전** (R09): 가능성은 낮지만 영향이 5라서 항상 최우선입니다.

## 5. 수행 절차

1. **위험 식별 (W1)**
   - [ ] 청사진 K4의 10개 위험을 등록부로 옮기기
   - [ ] 각 요소 문서의 "위험 요소" 절을 훑어 추가 위험 찾기
   - [ ] 참여자 각자 "이 과제가 실패한다면 이유는?" 3개씩 적기 (브레인스토밍)
2. **평가 (W1~W2)**
   - [ ] 각 위험에 P, I 점수 부여 (2절 기준표 사용, 의견이 다르면 높은 쪽)
   - [ ] 트리거를 **측정 가능한 숫자**로 적기 ("문제가 생기면" 금지)
   - [ ] 담당자 지정 (K2 역할 코드)
3. **대응 계획 (W2)**
   - [ ] 높음·중간 위험마다 예방책과 대책 작성
   - [ ] 예방책을 K1 일정에 작업으로 반영 (예: W14 교차검증 장비 예약)
   - [ ] 스크립트로 히트맵 생성, M0 회의에서 공유
4. **감시 (W1~W24 매주)**
   - [ ] 주간 회의 끝 5분: 상위 5개 위험의 트리거 값 확인
   - [ ] 트리거 발생 시 즉시 이슈로 전환하고 대책 실행, 회의록에 기록
5. **재평가 (월 1회 + 마일스톤마다)**
   - [ ] 전체 위험 P, I 재평가, 점수 변화 기록 (10절)
   - [ ] 지난 위험은 "종료"로 표시 (삭제하지 않음)
   - [ ] 새 위험 추가
6. **마무리 (W22~W24)**
   - [ ] 실제로 발생한 위험과 대응 결과를 정리해 논문의 "한계·고찰" 절과 다음 과제 인수인계 자료로 사용 ([K5](K5-deliverables-paper.md))

**`scripts/risks.py`**

```python
"""K4 위험 등록부 도구: risks.csv -> 점수 계산, 우선순위 표, 위험 행렬 히트맵 PNG

점수 = 가능성(1~5) x 영향(1~5).  15 이상 = 높음, 8~14 = 중간, 7 이하 = 낮음
단, 영향 5(인명·치명적)는 점수와 관계없이 '높음'으로 관리
사용법:  python k4_risks.py risks.csv --out results/risk_matrix.png
"""
import argparse
from collections import defaultdict

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def level(score, impact):
    if score >= 15 or impact == 5:                         # 영향 5는 항상 높음
        return "높음"
    return "중간" if score >= 8 else "낮음"


def load(path):
    df = pd.read_csv(path)
    for c in ("prob", "impact"):
        if not df[c].between(1, 5).all():                 # 입력 범위 검사
            raise SystemExit(f"{c} 값은 1~5 정수여야 합니다")
    df["score"] = df["prob"] * df["impact"]
    df["level"] = [level(s, i) for s, i in zip(df["score"], df["impact"])]
    return df.sort_values(["score", "impact"], ascending=False)


def heatmap(df, out_png):
    grid = np.fromfunction(lambda i, j: (i + 1) * (j + 1), (5, 5))  # 행=영향, 열=가능성
    grid[4, :] = np.maximum(grid[4, :], 15)              # 영향 5 행은 모두 '높음' 색
    cells = defaultdict(list)
    for r in df.itertuples():
        cells[(r.impact, r.prob)].append(r.id)
    fig, ax = plt.subplots(figsize=(7, 6))
    cmap = matplotlib.colors.ListedColormap(["#c7e9c0", "#fdd49e", "#fc8d59"])
    norm = matplotlib.colors.BoundaryNorm([0, 7.5, 14.5, 25], cmap.N)  # 낮음/중간/높음
    ax.imshow(grid, origin="lower", cmap=cmap, norm=norm,
              extent=(0.5, 5.5, 0.5, 5.5))
    for (imp, prob), ids in cells.items():
        text = "\n".join(", ".join(ids[i:i + 2]) for i in range(0, len(ids), 2))
        ax.text(prob, imp, text, ha="center", va="center", fontsize=8)
    ax.set_xticks(range(1, 6))
    ax.set_yticks(range(1, 6))
    ax.set_xlabel("Probability (1 = rare, 5 = almost certain)")
    ax.set_ylabel("Impact (1 = negligible, 5 = critical)")
    ax.set_title("Risk matrix (score = P x I)")
    for v in np.arange(1.5, 5.5):
        ax.axhline(v, color="white", lw=1)
        ax.axvline(v, color="white", lw=1)
    fig.tight_layout()
    fig.savefig(out_png, dpi=150)
    plt.close(fig)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("csv")
    ap.add_argument("--out", default="results/risk_matrix.png")
    ap.add_argument("--top", type=int, default=5)
    a = ap.parse_args()
    df = load(a.csv)
    print("등급별 개수:", df["level"].value_counts().reindex(["높음", "중간", "낮음"]).to_dict())
    print(f"상위 {a.top}개 위험:")
    for r in df.head(a.top).itertuples():
        print(f"  {r.id} [{r.score:2d}={r.prob}x{r.impact}] {r.risk} (담당 {r.owner}) / 신호: {r.trigger}")
    print("담당별 위험 수:", df["owner"].value_counts().to_dict())
    heatmap(df, a.out)
    print("저장:", a.out)


if __name__ == "__main__":
    main()
```

**히트맵 읽는 법**: 가로축이 가능성, 세로축이 영향입니다. 칸 안에 위험 ID가 적힙니다. 주황(높음) 칸의 위험은 즉시 대응, 연주황(중간)은 예방책 실행, 초록(낮음)은 감시만 합니다. '높음'은 R02(점수 16)와 R09(영향 5 규칙) 두 개입니다. 영향 5 행은 점수와 관계없이 모두 주황으로 칠해집니다.
