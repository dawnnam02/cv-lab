## 1. 목적

24주(2026-10-06 ~ 2027-03-22) 동안 55개 요소를 **언제, 어떤 순서로, 무엇을 통과해야 다음으로 넘어가는지** 정합니다.

- 하드웨어 트랙과 소프트웨어 트랙을 **병행**해서 기다리는 시간을 없앱니다.
- 마일스톤 M0~M6마다 **숫자로 된 통과 기준**을 두고, 통과하지 못했을 때 할 일을 미리 정합니다.
- 특히 **M2(2026-12-14) 진행/중단 판단**에서 센서가 목표 정밀도를 내지 못하면 본 실험으로 넘어가지 않습니다 (청사진 K1 규칙).
- 일정표는 한 번 만들고 끝나는 문서가 아닙니다. **매주 회의 때 실제 진행과 비교해서 갱신**합니다.

## 2. 배경 지식 (초보자용)

| 용어 | 뜻 | 이 과제에서의 예 |
|---|---|---|
| 마일스톤 | "여기까지 됐다"를 확인하는 점검 지점. 기간이 아니라 **날짜 + 통과 기준** | M1: 재투영 오차 < 0.2 px |
| 간트 차트 | 가로축이 시간, 세로축이 작업인 막대 그림 | 아래 코드로 `.meta.txt` 에서 자동 생성 |
| 선행 관계 (FS) | 앞 작업이 **끝나야(Finish)** 뒤 작업을 **시작(Start)** 할 수 있음 | D2 레이저 평면이 끝나야 D3 스캔축 교정 가능 |
| 임계 경로 (Critical path) | 처음부터 끝까지 이어지는 선행 관계 사슬 중 **가장 긴 것**. 이 경로의 작업이 1주 늦으면 프로젝트 전체가 1주 늦어짐 | A3 → B7 → C5 → D1 → D5 → C3 → E3 → I2 → I3 → K5 |
| 여유 (float, slack) | 전체 일정을 늦추지 않고 그 작업이 늦어져도 되는 시간 | K3 예산은 여유가 많음, D1은 여유 0 |
| 버퍼 | 일부러 비워 둔 예비 기간 | 현재 계획은 버퍼 0주 → 6절의 대책 참고 |
| 진행/중단(go/no-go) | 다음 단계에 자원을 쓸지 결정하는 공식 판단 | M2 |

**임계 경로법(CPM) 계산 원리** (코드가 하는 일)
1. 앞으로 계산: 각 작업의 가장 빠른 시작(ES) = 선행 작업들의 가장 빠른 끝(EF) 중 최댓값. EF = ES + 기간.
2. 뒤로 계산: 가장 늦은 끝(LF) = 후행 작업들의 가장 늦은 시작(LS) 중 최솟값. LS = LF − 기간.
3. 여유 = LS − ES. **여유가 0인 작업들이 임계 경로**입니다.

| D1 | B4, B5, B7, C5 | J3 | G3, G4, H1 |
| D2 | B6, C4, C8 | E1 / E2 | D5, F2 / G4, D5 |
| F1 | B4 | E3 | A1, G4, C3 |
| H5, H6 | H4, G4 | H7 / J4 | H4 / H1, J3 |
| H8 | H5, H6, H7 | I1 | D5, H5 |
| I2 | E3, H5, D4 | I3 | I2, E3 |

같은 주에 겹쳐 진행되는 "느슨한" 관계(예: A2 사양이 확정되기 전에 B4 카메라 후보 조사 시작, G3와 G4 동시 진행)는 표에 넣지 않았습니다. 겹침은 허용하되 **결정(발주, 확정)은 선행 요소가 끝난 뒤** 합니다.

## 6. Python 구현

`.meta.txt` 를 읽어 ① 선행 관계 위반 검사 ② 임계 경로(CPM) ③ 주차별 부하표 ④ 간트 차트 PNG를 만듭니다. 그림의 한글이 깨지지 않도록 그림 속 글자는 영어로 썼습니다 (한글을 쓰려면 `plt.rcParams["font.family"] = "NanumGothic"` 처럼 설치된 한글 글꼴을 지정).

```python
"""K1 일정 도구: .meta.txt -> 간트 차트 PNG + 주차별 부하 + 임계 경로(CPM)

사용법 (저장소 루트에서):
    python k1_schedule.py docs/blueprints/.meta.txt --out results/schedule
"""
import argparse
from datetime import date, timedelta
from pathlib import Path

import matplotlib
matplotlib.use("Agg")                      # 화면 없이 PNG 파일로만 저장
import matplotlib.pyplot as plt
import pandas as pd

WEEK1 = date(2026, 10, 6)                  # 1주차 시작일 (화요일)
N_WEEKS = 24
CONTINUOUS = {"K4", "K6"}                  # 전 기간 상시 활동 -> 임계 경로 계산에서 제외

# 선행 관계 (끝-시작, FS): "키 요소는 값 목록이 모두 끝나야 시작"
DEPS = {
    "B4": ["A3"], "B5": ["A3"], "B6": ["A3"], "B7": ["A3"],
    "C1": ["A2", "B3"], "C2": ["A3"], "G1": ["A3", "J1"],
    "C4": ["B2", "C1"], "C5": ["B7"], "C6": ["C1"], "C7": ["C1"], "C8": ["B6"],
    "G2": ["G1"], "G3": ["G1"], "G4": ["G1"], "G5": ["G1"],
    "D1": ["B4", "B5", "B7", "C5"], "D2": ["B6", "C4", "C8"], "F1": ["B4"],
    "D3": ["C1", "D2"], "D5": ["D1", "D2"], "F2": ["F1", "C5"], "F3": ["F1", "J2"],
    "H1": ["F1", "D2"], "H2": ["F1"], "H3": ["D2"],
    "C3": ["C4", "D5"], "D4": ["D3", "D5"], "H4": ["H1", "G3"], "J3": ["G3", "G4", "H1"],
    "E1": ["D5", "F2"], "E2": ["G4", "D5"], "E3": ["A1", "G4", "C3"],
    "H5": ["H4", "G4"], "H6": ["H4", "G4"], "H7": ["H4"], "J4": ["H1", "J3"],
    "H8": ["H5", "H6", "H7"], "I1": ["D5", "H5"], "I2": ["E3", "H5", "D4"],
    "I3": ["I2", "E3"], "K5": ["I3", "H8", "I1"],
}
TRACK_COLOR = {"관리·기획": "#7f7f7f", "하드웨어": "#1f77b4",
               "소프트웨어": "#2ca02c", "실험·품질": "#d62728"}
TRACK_EN = {"관리·기획": "Mgmt", "하드웨어": "HW", "소프트웨어": "SW", "실험·품질": "Exp/QA"}


def load_meta(path):
    df = pd.read_csv(path, sep="|")
    df["start"] = pd.to_datetime(df["start"]).dt.date
    df["end"] = pd.to_datetime(df["end"]).dt.date
    # 주차 번호: (시작일 - 1주차 시작일) // 7 + 1
    df["w0"] = df["start"].map(lambda d: (d - WEEK1).days // 7 + 1)
    df["w1"] = df["end"].map(lambda d: (d - WEEK1).days // 7 + 1)
    df["dur"] = df["w1"] - df["w0"] + 1
    return df.set_index("key")


def check_deps(df):
    """계획 날짜가 선행 관계를 어기는지 검사 (선행 요소가 끝나기 전에 시작하면 위반)"""
    bad = []
    for k, preds in DEPS.items():
        for p in preds:
            if df.loc[p, "end"] >= df.loc[k, "start"]:
                bad.append(f"{p}->{k}")
    return bad


def cpm(df):
    """임계 경로법: 기간(주)만으로 가장 빠른/늦은 시작을 계산해 여유(float)를 구함"""
    keys = [k for k in df.index if k not in CONTINUOUS]
    order, seen = [], set()

    def visit(k):                            # 위상 정렬 (선행 요소를 먼저)
        if k in seen:
            return
        seen.add(k)
        for p in DEPS.get(k, []):
            visit(p)
        order.append(k)
    for k in keys:
        visit(k)

    es, ef = {}, {}
    for k in order:                          # 앞으로 계산: 가장 빠른 시작/끝
        es[k] = max([ef[p] for p in DEPS.get(k, [])], default=0)
        ef[k] = es[k] + df.loc[k, "dur"]
    length = max(ef.values())
    succ = {k: [s for s, ps in DEPS.items() if k in ps] for k in keys}
    lf, ls = {}, {}
    for k in reversed(order):                # 뒤로 계산: 가장 늦은 끝/시작
        lf[k] = min([ls[s] for s in succ[k]], default=length)
        ls[k] = lf[k] - df.loc[k, "dur"]
    slack = {k: ls[k] - es[k] for k in keys}

    path, k = [], max(ef, key=ef.get)        # 끝에서부터 여유 0인 선행 요소를 따라감
    while True:
        path.append(k)
        preds = [p for p in DEPS.get(k, []) if slack[p] == 0 and ef[p] == es[k]]
        if not preds:
            break
        k = max(preds, key=lambda p: df.loc[p, "dur"])
    return length, slack, path[::-1]


def weekly_load(df):
    """주차별 트랙별로 진행 중인 요소 수"""
    rows = []
    for w in range(1, N_WEEKS + 1):
        act = df[(df["w0"] <= w) & (df["w1"] >= w)]
        row = {"week": w, "start": WEEK1 + timedelta(weeks=w - 1)}
        row.update(act["track"].value_counts().to_dict())
        row["total"] = len(act)
        rows.append(row)
    cols = ["week", "start", *TRACK_COLOR, "total"]  # 열 순서 고정
    return pd.DataFrame(rows).reindex(columns=cols).fillna(0).astype({t: int for t in TRACK_COLOR})


def gantt(df, critical, out_png):
    fig, ax = plt.subplots(figsize=(13, 15))
    for i, (k, r) in enumerate(df.iterrows()):
        ax.barh(i, r["dur"], left=r["w0"] - 0.5, color=TRACK_COLOR[r["track"]],
                edgecolor="black" if k in critical else "none",
                linewidth=2 if k in critical else 0, alpha=0.85)
    ax.set_yticks(range(len(df)))
    ax.set_yticklabels([f"{k} {s}" for k, s in zip(df.index, df["slug"])], fontsize=8)
    ax.invert_yaxis()
    ax.set_xticks(range(1, N_WEEKS + 1))
    ax.set_xlim(0.5, N_WEEKS + 0.5)
    ax.set_xlabel("Week (W1 = 2026-10-06)")
    ms = {"M0": 2, "M1": 8, "M2": 10, "M3": 12, "M4": 14, "M5": 17, "M6": 24}
    for m, w in ms.items():                  # 마일스톤 = 해당 주 끝의 세로선
        ax.axvline(w + 0.5, color="orange", ls="--", lw=1)
        ax.text(w + 0.5, -1, m, ha="center", color="darkorange", fontsize=9)
    handles = [plt.Rectangle((0, 0), 1, 1, color=c) for c in TRACK_COLOR.values()]
    ax.legend(handles, [TRACK_EN[t] for t in TRACK_COLOR], loc="upper right")
    ax.set_title("cv-lab schedule (black outline = critical path)")
    ax.grid(axis="x", alpha=0.3)
    fig.tight_layout()
    fig.savefig(out_png, dpi=150)
    plt.close(fig)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("meta", nargs="?", default="docs/blueprints/.meta.txt")
    ap.add_argument("--out", default="results/schedule")
    a = ap.parse_args()
    out = Path(a.out)
    out.mkdir(parents=True, exist_ok=True)

    df = load_meta(a.meta)
    print(f"요소 수: {len(df)}")
    bad = check_deps(df)
    print("선행 관계 위반:", bad if bad else "없음")
    length, slack, path = cpm(df)
    print(f"CPM 최소 소요 기간: {length}주 (계획 {N_WEEKS}주, 버퍼 {N_WEEKS - length}주)")
    print("임계 경로:", " -> ".join(path))
    zero = sorted(k for k, s in slack.items() if s == 0)
    print(f"여유 0주 요소 ({len(zero)}개):", ", ".join(zero))
    big = sorted(((s, k) for k, s in slack.items() if s >= 8), reverse=True)
    print("여유 8주 이상:", ", ".join(f"{k}({s})" for s, k in big))

    load = weekly_load(df)
    load.to_csv(out / "weekly_load.csv", index=False)
    peak = load.loc[load["total"].idxmax()]
    print(f"최대 부하: W{int(peak['week'])} ({peak['start']}) 동시 {int(peak['total'])}개")
    gantt(df, set(path), out / "gantt.png")
    print("저장:", out / "gantt.png", ",", out / "weekly_load.csv")


if __name__ == "__main__":
    main()
```
