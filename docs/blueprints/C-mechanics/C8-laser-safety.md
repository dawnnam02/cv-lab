## 1. 목적

레이저는 눈에 영구적인 손상을 줄 수 있습니다. 이 요소는 **레이저를 처음 켜기 전(W5-6)에 반드시 끝나야 하는** 안전 체계를 만듭니다.

1. 사용할 레이저의 **안전 등급(IEC 60825-1)** 을 제조사 표기로 확인하고 연구실 정책(권장: Class 2)과 대조한다.
2. 빔 경로, 차광, 표지, 전원 차단 방법을 설치·문서화한다.
3. 모든 사용자의 **안전교육 이수**를 확인하고, 학교 연구실 안전 규정에 따른 절차(장비 등록, 위험성 평가 등)를 밟는다.
4. 매 사용 전 점검표를 운영한다.

우선순위가 "긴급"인 이유: 안전 절차가 끝나지 않으면 W7-8 캘리브레이션(M1)을 시작할 수 없습니다.

## 2. 배경 지식 (초보자용)

**왜 레이저가 위험한가?** 레이저 빛은 한 점(또는 한 선)에 에너지가 모여 있습니다. 눈의 수정체는 들어온 빛을 망막의 아주 작은 점으로 다시 모으기 때문에, 몇 mW만 되어도 망막의 한 점에는 햇빛을 정면으로 볼 때보다 강한 빛이 닿을 수 있습니다. 망막 손상은 통증 없이 생기고 회복되지 않을 수 있습니다.

**레이저 안전 등급 (IEC 60825-1 기준 요약)**

| 등급 | 출력(가시광 연속파, 대략) | 의미 | 이 과제 |
|---|---|---|---|
| Class 1 | 매우 낮음 | 일반적 사용 조건에서 안전 | 허용 |
| Class 1M | – | 맨눈은 안전, **확대경·쌍안경 등 광학계로 보면 위험** | 조건부 |
| **Class 2** | ≤ 1 mW | 가시광. 눈 깜빡임 반사(약 0.25 s)로 보호됨. 일부러 들여다보면 안 됨 | **권장** |
| Class 2M | – | Class 2와 같되 광학계로 보면 위험 | 조건부 |
| Class 3R | ≤ 5 mW | 직접 보면 위험. 취급 교육 필요 | 조건부 (승인) |
| Class 3B | > 5 mW ~ 500 mW | 직접 빔·정반사 위험. **보안경 필수, 통제 구역** | 비권장 |
| Class 4 | > 500 mW | 산란광도 위험, 화재 위험 | 금지 |

**중요한 주의 3가지**

1. **등급은 직접 판정하지 않습니다.** 등급은 제조사가 표준 측정 조건에 따라 정해 라벨과 사양서에 표기합니다. 라인 레이저는 빛이 넓게 퍼지므로 총 출력이 1 mW보다 커도 Class 2로 분류될 수 있고, 반대로 렌즈를 바꾸거나 빔을 모으면 등급이 달라질 수 있습니다. **모듈을 분해·개조하거나 광학계를 추가하면 표기 등급을 믿을 수 없습니다.**
2. **405 nm 청자색은 눈에 어둡게 보입니다.** 사람 눈의 감도가 낮은 파장이라 실제 출력보다 약해 보여 방심하기 쉽습니다. 눈 깜빡임 반사도 밝기를 느껴야 일어나므로 보호 효과에 기대지 않습니다.
3. **반사가 직접 빔만큼 위험할 수 있습니다.** 금속 공구, 시계, 반지, 광택 시편, 유리판(캘리브레이션 타깃)이 빔을 엉뚱한 방향(눈높이)으로 튕길 수 있습니다.

**법규·규정**: 레이저 제품 안전에 관한 국제 표준은 IEC 60825-1이고, 국내에도 이에 대응하는 KS 표준이 있습니다. 대학 연구실은 연구실 안전 관련 법령과 학교 자체 안전관리 규정을 따라야 하며, 구체적인 의무(교육 시간, 장비 등록, 보호구 등)는 **학교 연구실안전 담당 부서**에 확인합니다. 이 문서는 법령 조항을 대신하지 않습니다.

## 5. 수행 절차

1. **등급 확인과 등록 (W5 월)**
   - [ ] 레이저 모듈 라벨을 사진으로 찍고, 사양서의 등급·파장·출력을 등록 대장에 적는다.
   - [ ] 6절 `check_laser`로 연구실 정책과 대조한다. "금지"면 사용하지 않고 B6 담당과 다른 모듈을 선정한다.
   - [ ] 라벨이 없거나 사양이 불분명한 저가 모듈은 **사용하지 않는다**.

2. **학교 절차 확인 (W5 월~화)**
   - [ ] 학교 연구실안전 담당 부서에 레이저 장비 사용 시 필요한 절차(장비 등록, 위험성 평가, 교육)를 문의하고 기록한다.
   - [ ] 사용자 전원의 안전교육 이수 여부를 확인해 `training_records.csv`에 적는다. 미이수자는 레이저 작업에서 제외한다.

3. **빔 경로 설계와 설치 (W5 수~W6 월, C5 인클로저와 동시)**
   - [ ] 레이저는 수직 아래로, 빔 끝은 시편·베드·무광 흑색 판에서 끝나게 한다(빔 종단).
   - [ ] 빔이 지나는 높이가 서 있거나 앉은 사람의 눈높이(대략 바닥에서 1.2~1.8 m)를 지나지 않음을 확인한다.
   - [ ] 빔 경로 주변의 반사면(금속 클램프, 광택 판)을 무광 처리하거나 가린다.
   - [ ] 인클로저 앞면이 열린 상태에서도 빔이 사람 쪽으로 직접 나가지 않는지 확인한다.

4. **표지·차단 장치 (W6 화)**
   - [ ] 측정대와 출입문에 레이저 경고 표지(등급, 파장 표기)를 붙인다.
   - [ ] 레이저 전원 스위치를 손이 닿는 곳에 두고 "레이저 ON" 표시등(LED 등)을 단다. 405 nm 빛이 잘 보이지 않으므로 표시등이 중요하다.
   - [ ] (가능하면) 인클로저 문 스위치로 레이저 전원을 끊는 인터록을 단다.

5. **절차서·위험성 평가 작성 (W6 수~목)**
   - [ ] `SOP_laser_safety.md`: 켜기 전 점검, 사용 중 규칙(빔 들여다보지 않기, 반사물 제거, 인클로저 안을 볼 때 레이저 끄기), 끄기, 사고 시 대응(즉시 전원 차단 → 보고 → 안과 진료).
   - [ ] 위험성 평가서: 위험(직접 빔, 반사, 정렬 작업, 전기), 가능성·영향, 대책을 표로 작성. 학교 양식이 있으면 그것을 쓴다.
   - [ ] 지도교수 검토·서명.

6. **첫 점등과 일일 점검 시작 (W6 금)**
   - [ ] 사용자 전원 앞에서 SOP 시연 후 첫 점등. 6절 스크립트로 첫 점검 기록을 남긴다.
   - [ ] 이후 매 사용 전 점검표를 기록한다. 한 항목이라도 "N"이면 사용하지 않는다.

## 6. Python 구현

이 코드는 **레이저 등급을 계산하거나 판정하지 않습니다.** 제조사가 표기한 등급을 입력받아 연구실 정책과 대조하고, 매 사용 전 점검표를 CSV로 남기는 기록용 도구입니다.

```python
"""C8 레이저 안전: (1) 제조사 표기 등급을 연구실 정책과 대조, (2) 작업 전 점검표 기록.
※ 이 코드는 레이저 등급을 '판정'하지 않는다. 등급은 제조사가 IEC 60825-1에 따라
   표기한 라벨·사양서의 값을 그대로 입력한다."""
import csv
import datetime as dt
from pathlib import Path

# 연구실 정책 (예시 — 실제 정책은 지도교수·학교 안전 담당 부서와 확정)
POLICY = {
    "1":  "허용",
    "1M": "조건부: 광학계(렌즈·확대경)로 빔을 보지 말 것",
    "2":  "허용 (권장)",
    "2M": "조건부: 광학계로 빔을 보지 말 것",
    "3R": "조건부: 안전교육 이수 기록 + 지도교수 승인 필요",
    "3B": "금지 (소규모 연구실 비권장)",
    "4":  "금지",
}

CHECKLIST = [
    "레이저 라벨의 등급·파장이 등록 대장과 일치",
    "빔이 눈높이를 지나지 않고 아래(시편)로 향함",
    "빔 경로에 반사면(금속 공구·시계·반지) 없음",
    "인클로저/차광막 설치 상태 정상",
    "레이저 사용 중 경고 표지 게시",
    "작업자 안전교육 이수 확인",
    "레이저 전원 차단 방법(스위치·키) 확인",
]

def check_laser(label_class, wavelength_nm):
    """라벨 등급을 정책과 대조하고 주의 문구를 돌려준다"""
    cls = label_class.strip().upper().replace("CLASS", "").strip()
    if cls not in POLICY:
        return "알 수 없음", ["라벨 등급을 확인할 수 없음 → 사용 전 제조사 사양서 확인"]
    notes = []
    if 380 <= wavelength_nm <= 460:
        notes.append("청자색/청색: 눈에 어둡게 보여 출력을 과소평가하기 쉬움")
    if not 400 <= wavelength_nm <= 700:
        notes.append("가시광 범위 밖일 수 있음: 눈 깜빡임 반사로 보호되지 않음")
    return POLICY[cls], notes

def log_checklist(path, operator, laser_id, answers):
    """answers: 점검 항목별 True/False. 하나라도 False면 '사용 불가'로 기록"""
    ok = all(answers)
    path = Path(path)
    new = not path.exists()
    with path.open("a", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        if new:
            w.writerow(["datetime", "operator", "laser_id", *CHECKLIST, "result"])
        w.writerow([dt.datetime.now().isoformat(timespec="minutes"), operator, laser_id,
                    *["Y" if a else "N" for a in answers], "사용 가능" if ok else "사용 불가"])
    return ok

if __name__ == "__main__":
    for label, wl in [("Class 2", 405), ("Class 3R", 450), ("Class 3B", 520), ("2M", 650)]:
        verdict, notes = check_laser(label, wl)
        print(f"{label:9s} {wl} nm → {verdict}" + ("".join(f"\n    · {n}" for n in notes)))

    log = Path("C8_daily_checklist_demo.csv")
    log.unlink(missing_ok=True)                     # 데모용: 매번 새 파일
    print("1차 점검:", "사용 가능" if log_checklist(log, "student_A", "LASER-01", [True]*7) else "사용 불가")
    ans = [True]*7
    ans[2] = False                                  # 빔 경로에 반사면 있음
    print("2차 점검:", "사용 가능" if log_checklist(log, "student_B", "LASER-01", ans) else "사용 불가")
    print("기록된 줄 수(머리글 포함):", len(log.read_text(encoding="utf-8").splitlines()))
```

**실행 방법**: `python scripts/hw/c8_safety.py`

```
기록된 줄 수(머리글 포함): 3
```

**실제 운용**: 실제 점검 기록은 `docs/safety/daily_checklist.csv`에 남기고, `log_checklist`의 `answers`는 점검자가 직접 하나씩 확인한 결과로 채웁니다. 점검을 코드로 "자동 통과"시키지 않습니다. 정책 표(`POLICY`)는 예시이므로 지도교수·학교 안전 담당 부서와 확정한 내용으로 바꿉니다.

## 7. 검증 방법과 완료 기준

| 항목 | 방법 | 합격 기준 |
|---|---|---|
| 등급 확인 | 라벨 사진 + 사양서 + 등록 대장 | 모든 레이저가 등록됨, 정책상 "허용/조건부 충족" |
| 교육 이수 | `training_records.csv` | 레이저 사용자 100 % 이수 |
| 학교 절차 | 담당 부서 확인 기록 | 필요한 등록·평가 절차 완료 |
| 빔 경로 | 설치 사진 + 현장 확인 | 빔이 눈높이를 지나지 않음, 빔 종단 확인, 반사면 0개 |
| 표지·표시등 | 현장 확인 | 경고 표지 2곳 이상(측정대, 출입문), ON 표시등 작동 |
| 전원 차단 | 시연 | 2초 이내 차단 가능 |
| 절차서·위험성 평가 | 문서 | 지도교수 검토 완료 |
| 일일 점검 운영 | 점검 기록 | 레이저 사용일마다 기록 존재 (누락 0) |
| 사고·아차사고 | 기록 | 발생 시 24시간 이내 기록·보고 |

## 8. 흔한 실수와 대응

| 실수 | 증상 / 위험 | 대응 |
|---|---|---|
| 정렬하면서 빔을 직접 들여다봄 | 눈 손상 위험 | 카메라 화면·형광 카드로 확인, 보안경 비치 |
| 405 nm가 어두워 보여 약하다고 판단 | 방심 → 노출 | 표기 등급 기준으로만 판단 |
| 캘리브레이션 유리 타깃을 기울이다 반사 | 빔이 눈높이로 튐 | 타깃 조작 시 레이저 끔 또는 각도 제한, 무광 타깃 우선 |
| 시계·반지 착용 | 예상 못한 반사 | 작업 전 금속 장신구 제거 (점검표 항목) |
| 라벨 없는 저가 모듈 사용 | 실제 등급 불명 | 라벨·사양서 있는 제품만 |
| 모듈 렌즈를 바꾸거나 빔을 모음 | 등급이 바뀌어 위험 증가 | 개조 금지, 필요하면 안전 담당과 재평가 |
| 인클로저 문 열고 안을 들여다봄 | 반사광 노출 | 문 열 때 레이저 끔 규칙, 가능하면 인터록 |
| 점검표를 몰아서 작성 | 기록이 실제와 다름 | 사용 직전 작성, 시각 자동 기록 |

## 9. 위험 요소

- **눈 손상 (가능성 낮음, 영향 매우 높음)**: K4 위험표의 "레이저 안전사고"에 해당합니다. 대책은 Class 2 사용, 교육, 빔 경로 관리, 일일 점검입니다.
- **등급 상향 유혹**: 어두운 시편(E1)이나 짧은 노출(F2) 때문에 더 강한 레이저를 쓰고 싶어질 수 있습니다. 출력을 올리기 전에 노출·게인·필터·무광 처리로 해결하고, 등급이 바뀌는 변경은 지도교수와 학교 안전 담당 부서의 승인을 받습니다.
- **방문자**: 연구실에 처음 온 사람은 위험을 모릅니다. 경고 표지와 "레이저 사용 중" 표시를 출입문에 둡니다.
- **전기·열**: 레이저 드라이버 배선 단락, 장시간 사용 시 모듈 과열에 주의합니다.
- **일정 위험**: 학교 절차(등록, 교육)에 시간이 걸리면 M1이 밀립니다. W5 첫날 문의를 시작합니다.
