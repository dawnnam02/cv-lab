## 1. 목적

측정 데이터({M} 좌표계)와 G코드({G} 좌표계)를 **절대 위치 기준**으로 연결하는 기준점을 만듭니다.

- 기준 마커가 없으면 "모양을 최대한 겹치는" 최적맞춤 정합(ICP 등)만 가능하고, 그러면 **시편 전체가 밀린 위치 오차가 사라집니다** (H4).
- 이 요소의 산출물은 ① 베드(또는 지그)에 고정된 무광 구 3~4개, ② 그 구들의 **G코드 좌표에서의 위치**(좌표 교정 판으로 구함), ③ 그 결과의 버전 ID입니다.

## 2. 배경 지식 (초보자용)

**기준 마커(fiducial)란?** 지도에서 "삼각점"과 같습니다. 위치를 정확히 아는 점이 여러 개 있으면, 새로 찍은 사진(측정 데이터)을 그 점들에 맞춰 지도(G코드 좌표) 위에 정확히 올려놓을 수 있습니다.

**왜 구(공)인가?**
- 어느 방향에서 봐도 **중심이 같은 점**입니다. 센서가 위에서 윗부분만 봐도 표면 점들에 구를 맞추면 중심을 계산할 수 있습니다.
- 수천 개의 표면 점을 써서 중심 하나를 구하므로 노이즈가 평균되어, 개별 점 노이즈(수 µm)보다 훨씬 정확한 중심을 얻습니다.
- 반지름을 **알려진 값으로 고정**하면 윗부분만 보일 때도 안정적입니다. 반지름까지 같이 추정하면 반지름 오차가 중심 높이(Z) 오차로 넘어갑니다.

**왜 무광이어야 하나?** 반짝이는 강구는 레이저를 거울처럼 한 방향으로 튕겨 카메라에 거의 들어오지 않거나(데이터 없음), 너무 강하게 들어와 포화됩니다. **샌드블라스트한 지르코니아 세라믹 구** 또는 무광 도장 구를 씁니다.

**최소 몇 개?** 2D 강체 변환(X 이동, Y 이동, 회전)은 이론상 점 2개로 풀리지만, 잔차를 보고 이상을 감지하려면 **3개 이상**, 권장 **4개**입니다. 세 점 이상이 **일직선이면 안 됩니다** (회전 추정이 불안정해짐).

**배치 원칙 — "시편을 둘러싸라"**: 마커가 한쪽에 몰려 있으면, 마커에서 먼 곳일수록 회전 추정 오차가 지렛대처럼 커집니다. 6절의 시뮬레이션에서 마커 중심 오차가 같아도 둘러싼 배치는 3.8 µm, 일직선 배치는 9.4 µm의 변환 오차가 시편 위에 생깁니다.

**G코드 좌표에서 마커 위치를 아는 방법 (핵심 난제)**: 구를 베드에 붙이는 순간에는 그 구가 G코드 좌표로 어디에 있는지 모릅니다. 그래서 **좌표 교정 판**을 출력합니다.
1. 알려진 G코드 좌표(예: 5×5 격자, 간격 10 mm)에 작은 원기둥을 출력합니다.
2. 원기둥과 마커를 **같은 스캔**으로 측정합니다 → 둘 다 {M} 좌표로 얻습니다.
3. 원기둥 25개의 (측정 중심 ↔ G코드 중심)으로 변환 `T_G_M`을 최소제곱으로 구합니다. 25개를 평균하므로 프린터의 랜덤 위치 오차가 줄어듭니다.
4. 이 변환으로 마커 중심을 {G} 좌표로 옮겨 **마커의 G코드 좌표**를 저장합니다. 이후 측정에서는 마커만 보면 됩니다.

**키네마틱 마운트**: 탈착식 베드를 쓰면 다시 끼울 때마다 위치가 달라집니다. 볼 3개 + V홈 3개 구조(키네마틱 커플링)는 6자유도를 정확히 한 번씩 구속해서 다시 장착해도 µm 수준으로 같은 위치에 앉습니다.

## 5. 수행 절차

1. **배치 설계 (W11 월~화)**
   - [ ] 시편 영역(예: 30×30 mm)과 스캔 범위(C1)를 그린 뒤, 마커 4개를 영역 바깥 귀퉁이에서 5~8 mm 떨어진 곳에 둔다. 4개가 **직사각형이 아닌 약간 비대칭**이 되도록 한 개를 2~3 mm 옮긴다(대응 순서를 혼동하지 않게).

   - [ ] 구 꼭대기와 시편 윗면이 측정 깊이 범위 안에 같이 들어오는지 확인한다 (받침 높이 결정).

   - [ ] 받침을 베드에 나사로 고정하고 페인트 마커로 위치 표시(움직임 감지용).
   - [ ] 설치 사진을 찍어 `docs/hardware/photos/`에 저장.

3. **구 중심 반복성 시험 (W11 목)**
   - [ ] 마커 4개를 같은 조건으로 **20회** 연속 스캔한다 (C6 워밍업 30분 이후).
   - [ ] 각 스캔에서 구 주변 점을 잘라 내고 `fit_sphere_fixed_r`로 중심을 구한다. 맞춤 잔차 RMS도 기록한다.
   - [ ] 중심의 표준편차(x, y, z)를 계산한다. 합격: 각 축 σ ≤ 5 µm.
   - [ ] 마커 간 거리(6쌍)의 20회 표준편차도 계산한다. 이 값은 Y 배율(D3)과 X 배율의 안정성을 보여 준다.

4. **좌표 교정 판 출력과 측정 (W11 금 ~ W12 화)**
   - [ ] 5×5 원기둥(Ø3 mm, 높이 2 mm, 간격 10 mm)을 CAD로 만들고 슬라이싱한다. 원기둥 중심의 G코드 좌표는 **G코드 파일에서 직접** 외벽 경로 중심으로 계산한다(G1 파서 사용).
   - [ ] 마커가 붙은 베드에 출력 → 떼지 않고 실온까지 냉각(C2) → 마커와 함께 스캔.
   - [ ] 원기둥 윗면 경계에 원 맞춤 → 25개 중심 {M} 좌표.
   - [ ] 2D 강체 변환(Kabsch)으로 `T_G_M`을 구하고 잔차 RMS를 기록한다. 합격: ≤ 50 µm, 어떤 원기둥도 잔차 > 3×RMS 아님.
   - [ ] 마커 중심을 `T_G_M`으로 {G} 좌표로 옮겨 `FID-YYYY-MM-DD-A.yaml`에 저장한다.

5. **반복과 확인 (W12 수~목)**
   - [ ] 교정 판을 **2회 더** 출력·측정해 마커 G좌표를 3번 구한다. 3회 값의 범위가 ≤ 20 µm인지 확인하고, 평균을 최종값으로 쓴다.

   - [ ] (탈착식 베드일 때) 베드를 10회 떼었다 붙이며 마커 중심 변화를 측정한다. 합격: 재장착 반복성 σ ≤ 5 µm.

6. **인계 (W12 금)**

## 6. Python 구현

세 가지를 합성 데이터로 시험합니다. (1) Ø8 mm 구의 윗부분(꼭대기에서 50°까지)만 보이는 점 3000개 + 높이 노이즈 5 µm에서 **반지름 고정 구 맞춤**의 반복성, (2) 마커 배치에 따른 변환 오차, (3) 5×5 좌표 교정 판(프린터 랜덤 오차 20 µm + 측정 노이즈 5 µm)으로 마커의 G좌표를 구했을 때의 오차.

```python
"""C3 기준 마커: (1) 구 중심 맞춤(반지름 고정) 반복성, (2) 마커 배치 평가(몬테카를로),
(3) 좌표 교정 판으로 G코드 좌표에서의 마커 위치 구하기. 모두 합성 데이터."""
import numpy as np
from scipy.optimize import least_squares

rng = np.random.default_rng(1)

# ---------- (1) 구 중심 맞춤 ----------
def sphere_cap_points(center, R, max_polar_deg=50, n=3000, noise_um=5.0):
    """센서가 위에서 보는 구의 윗부분(극각 < max_polar_deg) 점을 만든다 [mm]"""
    th = np.radians(rng.uniform(0, max_polar_deg, n))   # 꼭대기로부터의 각도
    ph = rng.uniform(0, 2 * np.pi, n)
    P = np.c_[R*np.sin(th)*np.cos(ph), R*np.sin(th)*np.sin(ph), R*np.cos(th)] + center
    P[:, 2] += rng.normal(0, noise_um / 1000, n)          # 높이 방향 노이즈
    return P

def fit_sphere_linear(P):
    """반지름까지 추정하는 선형 구 맞춤 → 초깃값용"""
    A = np.hstack([2 * P, np.ones((len(P), 1))])
    b = (P ** 2).sum(axis=1)
    sol, *_ = np.linalg.lstsq(A, b, rcond=None)
    c = sol[:3]
    return c, np.sqrt(sol[3] + c @ c)

def fit_sphere_fixed_r(P, R):
    """알려진 반지름 R을 고정하고 중심만 추정 (윗부분만 보일 때 안정적)"""
    c0, _ = fit_sphere_linear(P)
    res = least_squares(lambda c: np.linalg.norm(P - c, axis=1) - R, c0)
    return res.x, np.sqrt(np.mean(res.fun ** 2))

# ---------- (2) 2D 강체 변환 (Kabsch) ----------
def rigid_2d(A, B):
    """B ≈ R @ A + t 인 2D 회전 R, 이동 t (A, B: (N,2))"""
    ca, cb = A.mean(0), B.mean(0)
    U, _, Vt = np.linalg.svd((A - ca).T @ (B - cb))
    D = np.diag([1, np.sign(np.linalg.det(Vt.T @ U.T))])
    R = Vt.T @ D @ U.T
    return R, cb - R @ ca

def layout_tre(markers, targets, sigma_mm, trials=2000):
    """마커 중심에 sigma 오차가 있을 때, 시편 위치(targets)에서 생기는 변환 오차 RMS [µm]"""
    errs = []
    for _ in range(trials):
        noisy = markers + rng.normal(0, sigma_mm, markers.shape)
        R, t = rigid_2d(noisy, markers)          # 참 변환은 항등(I, 0)
        errs.append(np.linalg.norm(targets @ R.T + t - targets, axis=1))
    return 1000 * np.sqrt(np.mean(np.square(errs)))

if __name__ == "__main__":
    R_TRUE = 4.0                                  # Ø8 mm 구 (config: fiducial_radius_mm)
    c_true = np.array([10.0, 20.0, 0.0])
    centers = np.array([fit_sphere_fixed_r(sphere_cap_points(c_true, R_TRUE), R_TRUE)[0]
                        for _ in range(20)])
    print("구 중심 반복성 σ [µm] (x, y, z):", np.round(1000 * centers.std(0, ddof=1), 2))
    print("중심 평균 오차 [µm]:", np.round(1000 * (centers.mean(0) - c_true), 2) + 0.0)
    _, r_lin = fit_sphere_linear(sphere_cap_points(c_true, R_TRUE))
    print(f"(참고) 반지름 자유 추정 시 R = {r_lin:.4f} mm (참값 4.0000)")

    # 마커 배치 비교: 시편 영역(30×30 mm) 네 귀퉁이 + 중앙에서의 오차
    targets = np.array([[0, 0], [30, 0], [0, 30], [30, 30], [15, 15]], float)
    good = np.array([[-8, -8], [38, -8], [-8, 38], [38, 38]], float)   # 시편을 둘러쌈
    bad = np.array([[-8, -8], [0, -8], [8, -8], [16, -6]], float)      # 거의 일직선
    for name, m in [("둘러싼 배치", good), ("일직선 배치", bad)]:
        print(f"{name}: 시편 위 변환 오차 RMS = {layout_tre(m, targets, 0.005):.1f} µm")

    # ---------- (3) 좌표 교정 판 ----------
    gx, gy = np.meshgrid(np.arange(5) * 10.0 + 80, np.arange(5) * 10.0 + 80)
    G = np.c_[gx.ravel(), gy.ravel()]             # G코드 좌표의 원기둥 중심 25개
    ang = np.radians(0.8)                         # 참 회전 0.8°, 참 이동 (-95.3, -72.1)
    R_true = np.array([[np.cos(ang), -np.sin(ang)], [np.sin(ang), np.cos(ang)]])
    t_true = np.array([-95.3, -72.1])
    # 측정 좌표 {M}의 원기둥 중심 = 변환 + 프린터 랜덤 오차(20 µm) + 측정 노이즈(5 µm)
    Mpts = (G @ R_true.T + t_true) + rng.normal(0, 0.020, G.shape) + rng.normal(0, 0.005, G.shape)
    R_GM, t_GM = rigid_2d(Mpts, G)                # T_G_M: {M} → {G}
    resid = Mpts @ R_GM.T + t_GM - G
    print(f"교정 판 잔차 RMS = {1000*np.sqrt((resid**2).sum(1).mean()):.1f} µm")
    marker_M = np.array([[-20.0, -15.0], [30.0, -15.0], [-20.0, 40.0], [30.0, 40.0]])
    marker_G = marker_M @ R_GM.T + t_GM
    marker_G_true = (marker_M - t_true) @ R_true   # 참 변환의 역
    err = 1000 * np.linalg.norm(marker_G - marker_G_true, axis=1)
    print("G좌표 마커 위치 오차 [µm]:", np.round(err, 1))
```

**실행 방법**: `python scripts/hw/c3_fiducials.py`

**기대 출력**

```
구 중심 반복성 σ [µm] (x, y, z): [0.22 0.25 0.08]
중심 평균 오차 [µm]: [ 0.04 -0.11  0.  ]
(참고) 반지름 자유 추정 시 R = 4.0010 mm (참값 4.0000)
둘러싼 배치: 시편 위 변환 오차 RMS = 3.8 µm
일직선 배치: 시편 위 변환 오차 RMS = 9.4 µm
교정 판 잔차 RMS = 26.3 µm
G좌표 마커 위치 오차 [µm]: [15.6 14.6  7.3  5. ]
```

**해석**
- 합성 데이터의 구 중심 반복성(0.1~0.3 µm)은 **이상적인 값**입니다. 실제로는 스펙클, 표면 산란, 가장자리 점, 스캔 위치 오차 때문에 대략 1~5 µm가 예상됩니다. 그래서 합격 기준을 5 µm로 둡니다.
- 반지름을 자유롭게 추정하면 1 µm 정도 어긋납니다. 노이즈가 커지거나 보이는 부분이 작아지면 이 차이가 커져 중심 Z로 넘어가므로, **반지름은 인증값으로 고정**합니다.
- 일직선 배치는 같은 마커 정밀도에서도 시편 위 오차가 약 2.5배입니다.
- 교정 판 잔차(26 µm)는 대부분 **프린터의 랜덤 위치 오차**입니다. 25개를 평균하므로 마커 G좌표 오차는 5~16 µm로 줄어듭니다. 마커가 교정 판 격자 **바깥**에 있을수록 오차가 커지므로(외삽), 교정 판 격자를 마커 근처까지 넓게 배치하는 것이 좋습니다.

## 9. 위험 요소

- **마커 이동**: 출력물을 떼어 낼 때 스크레이퍼가 마커를 칠 수 있습니다. 마커 주변에 보호 턱을 두고, 매 세션 시작 시 FRE로 이동 여부를 확인합니다(D5, I2 안정성).
- **베드 열변형**: 가열 베드를 쓰면 마커 간 거리도 변합니다. 알루미늄 베드는 23 µm/(m·°C) 수준이라 100 mm 거리에서 40 °C 차이면 약 90 µm입니다. 측정은 실온에서만 합니다(C6).
- **교정 판의 계통 오차**: 프린터의 배율 오차(수축)가 교정 판에도 들어 있습니다. 강체 변환은 배율을 흡수하지 못하므로 잔차에 남습니다. 배율은 따로 추정해서 보고합니다(H4). 교정 판 잔차가 50 µm를 넘고 위치에 따라 체계적 패턴이 보이면 닮음 변환(배율 포함) 결과도 같이 기록합니다.
- **구 인증값 없음**: 반지름 인증서가 없으면 마이크로미터로 지름을 3방향 측정해 평균을 씁니다.
- **일정**: W11-12는 H4·J3과 같은 시기입니다. 교정 판 출력(각 1~2시간)은 미리 예약합니다.
