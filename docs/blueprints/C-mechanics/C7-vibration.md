## 1. 목적

측정 중 센서와 시편이 서로 흔들리면 그 흔들림이 그대로 높이 노이즈가 됩니다. 목표 Z 반복성이 5 µm(A2)인데, 프린터 팬이나 건물 진동은 수 µm를 쉽게 만듭니다. 이 요소의 목적은

1. 측정대를 진동이 적은 받침 위에 설치하고,
2. **정지 평판 100장 연속 촬영**으로 "진동 + 센서 노이즈" 크기를 측정해 둘을 분리하며,
3. 진동원(팬, 모터, 주변 장비)을 주파수로 찾아 제거하고,
4. 스텝 & 촬영 방식의 **정지 후 대기시간**을 실측으로 정하는 것입니다(C1 연계).

## 2. 배경 지식 (초보자용)

**진동이 높이 오차가 되는 원리**: 레이저 삼각측량은 "센서와 표면 사이 거리"를 잽니다. 센서가 위아래로 3 µm 흔들리면, 표면이 가만히 있어도 측정 높이가 3 µm 흔들립니다. 카메라가 미세하게 기울어지는 진동(rocking)은 레이저 선 위치를 옮겨 더 큰 오차를 만들 수 있습니다.

**두 가지 흔들림 구분하기**

| 성분 | 특징 | 원인 |
|---|---|---|
| **공통 성분 (진동)** | 한 프레임 안의 모든 열이 **함께** 오르내림 | 센서·시편의 기계적 진동 |
| **독립 성분 (노이즈)** | 열마다 **제각각** 흔들림 | 카메라 노이즈, 스펙클, 중심 추출 오차 |

정지 평판을 100장 찍어 높이 배열 `z[프레임, 열]`을 만들면, **프레임마다 모든 열의 평균**을 구했을 때 독립 노이즈는 평균되어 사라지고 공통 진동만 남습니다. 이렇게 두 성분을 나눌 수 있습니다. (기울어지는 진동은 열 위치에 비례하는 성분이라, 필요하면 프레임마다 직선을 맞춰 기울기 성분도 따로 봅니다.)

```
열별 시간 표준편차²  ≈  진동²  +  노이즈²        (서로 독립이면 제곱해서 더함)
```

**주파수와 에일리어싱**: 팬은 일정한 회전수로 돌아 특정 주파수(예: 30 Hz)의 진동을 만듭니다. 높이의 시간 변화를 푸리에 변환(FFT)하면 그 주파수에 봉우리가 생겨 원인을 찾을 수 있습니다. 단, 카메라 프레임 속도의 절반(나이퀴스트 주파수, 100 fps면 50 Hz)보다 빠른 진동은 **다른 주파수로 접혀** 보입니다(에일리어싱). 70 Hz 진동을 100 fps로 찍으면 30 Hz처럼 보입니다. 그래서 원인 추적은 ROI를 줄여 fps를 최대로 올리거나, 의심 장비를 하나씩 끄며 확인합니다.

**정지 후 감쇠**: 스테이지가 멈추면 관성 때문에 잠깐 출렁이다가 가라앉습니다. 이 "안정 시간"이 지나기 전에 찍으면 프로파일마다 높이가 다릅니다. 고속(≥ 500 fps)으로 정지 직후를 찍어 안정 시간을 재고, 안전계수 2를 곱해 대기시간으로 씁니다.

**방진 수단 (효과 순)**

| 수단 | 효과 | 비고 |
|---|---|---|
| 광학 테이블(공압 방진) | 매우 큼 | 고가, 공동 장비 확인 |
| 무거운 석정반 + 방진 패드 | 큼 | 소규모 연구실 현실적 선택 |
| 방진 고무 패드 / 소르보테인 패드 | 중간 | 저렴 |
| 측정 중 팬·주변 장비 정지 | 큼 (원인 제거) | 가장 먼저 할 것 |
| 센서 브래킷 강성 증가 | 중간~큼 | 길고 가는 브래킷은 흔들림 |

## 5. 수행 절차

1. **설치 (W5 월~화)**
   - [ ] 석정반(또는 광학 테이블)을 벽 쪽, 출입문·공조기에서 먼 곳에 둔다.
   - [ ] 받침 아래 방진 패드 3~4점 지지, 수평계로 수평 확인.
   - [ ] 센서 브래킷 볼트 체결 상태 확인(풀린 볼트는 큰 진동원).

2. **기준 시험 — 모든 장비 켬 (W5 수)**
   - [ ] 정밀 평판(또는 게이지 블록)을 FOV 중앙에 고정, 레이저·카메라 워밍업 30분(C6).
   - [ ] 측정과 같은 노출·fps로 **100장** 연속 촬영 → F1 코드로 열별 높이 → `z[100, 열]` 저장.
   - [ ] 6절 `decompose`로 열별 σ, 진동(공통) σ, 노이즈 σ를 계산해 기록.

3. **진동원 찾기 (W5 목~금)**
   - [ ] ROI를 줄여 fps를 최대로 올리고 **1000장** 촬영 → `dominant_freq`로 주된 주파수 확인.
   - [ ] 의심 장비를 하나씩 끄며(프린터 팬, 전원 팬, 옆 장비, 공조기) 2번 시험을 반복하고, 공통 σ가 크게 줄어드는 장비를 찾는다.
   - [ ] 원인 장비별 결과를 `C7_vibration.csv`에 조건으로 기록.

4. **대책 적용과 재시험 (W6 월~화)**
   - [ ] 원인 장비를 측정 중 끄는 규칙을 SOP에 넣거나, 패드·받침을 바꾼다.
   - [ ] 2번 시험을 다시 해서 공통 σ ≤ 1 µm, 열별 총 σ ≤ 5 µm 확인.
   - [ ] 사람이 측정대 옆을 걸어갈 때, 문을 여닫을 때의 영향도 1회 확인(필요하면 "측정 중 접근 금지" 규칙).

5. **정지 후 안정 시간 (W6 수~목, 스텝 & 촬영 또는 프린터 축 사용 시)**
   - [ ] ROI 최소화로 ≥ 500 fps 설정, 스테이지를 0.02 mm 이동·정지시키며 정지 직후 0.5 s를 촬영.
   - [ ] 평판 평균 높이의 시간 변화에 `settle_time`(밴드 ±2 µm)을 적용. 10회 반복 중 **최댓값**을 쓴다.
   - [ ] 대기시간 = 최댓값 × 2 (0.05 s 단위 올림). C1 `config/acquisition.yaml`의 `settle_time_s`에 기록.

6. **인계 (W6 금)**
   - [ ] F1에 노이즈 σ(중심 추출 반복성의 기준값)를, I1에 반복성 항목 원자료를 넘긴다.

## 6. Python 구현

합성 데이터로 ① 방진 전/후의 노이즈 분해, ② 진동 주파수 찾기와 에일리어싱, ③ 정지 후 안정 시간 → 대기시간 계산을 보여 줍니다. 실제 데이터는 `np.load("C7_static_....npz")["z"]`로 `z[프레임, 열]`을 읽어 같은 함수에 넣습니다.

```python
"""C7 진동: (1) 정지 평판 100장 → 노이즈 분해, (2) 주파수 분석으로 진동원 찾기,
(3) 스텝 정지 후 진동 감쇠 시간 → 스텝 & 촬영 대기시간. 모두 합성 데이터 [단위 µm]."""
import numpy as np

rng = np.random.default_rng(4)

def static_plate_stack(n_frames, n_cols, fps, vib_amp_um, vib_hz, noise_um):
    """프레임 × 열 높이 배열: 모든 열이 함께 흔들리는 진동 + 열마다 독립인 센서·스펙클 노이즈"""
    t = np.arange(n_frames) / fps
    common = vib_amp_um * np.sin(2 * np.pi * vib_hz * t + rng.uniform(0, 2*np.pi))
    return common[:, None] + rng.normal(0, noise_um, (n_frames, n_cols)), t

def decompose(z):
    """z: (프레임, 열). 열별 시간 표준편차 = 진동 + 노이즈.
    프레임 평균(모든 열 평균)의 표준편차 ≈ 진동(공통 성분), 나머지 ≈ 노이즈"""
    per_col = np.median(z.std(axis=0, ddof=1))
    common = z.mean(axis=1).std(ddof=1)
    resid = np.median((z - z.mean(axis=1, keepdims=True)).std(axis=0, ddof=1))
    return per_col, common, resid

def dominant_freq(signal, fps):
    """가장 큰 주파수 성분 [Hz] (직류 제외). fps/2 를 넘는 진동은 접혀서(에일리어싱) 보인다"""
    s = signal - signal.mean()
    spec = np.abs(np.fft.rfft(s * np.hanning(s.size)))
    f = np.fft.rfftfreq(s.size, 1 / fps)
    return f[1:][spec[1:].argmax()]

def settle_time(t, z, band_um):
    """|z| 가 band 이내로 들어간 뒤 다시 나가지 않는 첫 시각"""
    outside = np.where(np.abs(z) > band_um)[0]
    return 0.0 if outside.size == 0 else t[min(outside[-1] + 1, t.size - 1)]

if __name__ == "__main__":
    # (1) 방진 전/후 비교: 100장, 1440열 중 대표 500열, 100 fps, 노이즈 3 µm
    for name, amp in [("방진 전(팬 진동 6 µm)", 6.0), ("방진 후(팬 진동 1 µm)", 1.0)]:
        z, _ = static_plate_stack(100, 500, 100, amp, 30.0, 3.0)
        a, b, c = decompose(z)
        print(f"[{name}] 열별 σ {a:.2f} µm ≈ √(진동² + 노이즈²), 진동(공통) σ {b:.2f} µm, 노이즈 σ {c:.2f} µm")

    # (2) 주파수 분석: 1000장, 200 fps, 30 Hz 진동
    z, t = static_plate_stack(1000, 200, 200, 4.0, 30.0, 3.0)
    print(f"주된 진동 주파수: {dominant_freq(z.mean(axis=1), 200):.1f} Hz")
    z, t = static_plate_stack(1000, 200, 100, 4.0, 70.0, 3.0)   # 70 Hz를 100 fps로 찍으면
    print(f"70 Hz 진동을 100 fps로 촬영 → 보이는 주파수: {dominant_freq(z.mean(axis=1), 100):.1f} Hz (에일리어싱)")

    # (3) 스텝 정지 후 감쇠: 진폭 20 µm, 25 Hz, 감쇠 시정수 0.04 s, 1000 fps 고속 측정
    t = np.arange(0, 0.5, 0.001)
    zs = 20 * np.exp(-t / 0.04) * np.cos(2 * np.pi * 25 * t) + rng.normal(0, 0.3, t.size)
    ts = settle_time(t, zs, band_um=2.0)
    dwell = np.ceil(2 * ts / 0.05) * 0.05                     # 안전계수 2, 0.05 s 단위 올림
    print(f"±2 µm 안정 시간 {ts:.3f} s → 스텝 & 촬영 대기시간 {dwell:.2f} s")
```

**실행 방법**: `python scripts/hw/c7_vibration.py`

**기대 출력**

```
[방진 전(팬 진동 6 µm)] 열별 σ 5.19 µm ≈ √(진동² + 노이즈²), 진동(공통) σ 4.26 µm, 노이즈 σ 2.99 µm
[방진 후(팬 진동 1 µm)] 열별 σ 3.07 µm ≈ √(진동² + 노이즈²), 진동(공통) σ 0.73 µm, 노이즈 σ 2.98 µm
주된 진동 주파수: 30.0 Hz
70 Hz 진동을 100 fps로 촬영 → 보이는 주파수: 30.0 Hz (에일리어싱)
±2 µm 안정 시간 0.103 s → 스텝 & 촬영 대기시간 0.25 s
```

**해석**
- 방진 전에는 열별 σ가 5.19 µm로 Z 반복성 목표(5 µm)를 넘습니다. 그중 진동 성분이 4.26 µm입니다(진폭 6 µm 사인파의 σ = 6/√2 ≈ 4.24). 방진 후 진동 성분이 0.73 µm로 줄면 열별 σ는 센서 노이즈(약 3 µm)에 가까워집니다. **진동을 없애도 노이즈 이하로는 내려가지 않습니다.** 그 이하는 F1(중심 추출)과 B(광학)의 몫입니다.
- 30 Hz 봉우리가 보여도 실제 진동이 70 Hz일 수 있습니다. fps를 바꿔 다시 측정해서 봉우리가 움직이면 에일리어싱입니다.
- 이 예에서 안정 시간은 0.103 s, 대기시간은 0.25 s로 정합니다. 2501장 스텝 & 촬영이면 대기만 약 10분이 걸리므로, 가능하면 위치 트리거 연속 스캔(C1)을 씁니다.

## 7. 검증 방법과 완료 기준

| 항목 | 방법 | 합격 기준 |
|---|---|---|
| 진동(공통) 성분 | 정지 평판 100장, 프레임 평균의 σ | **≤ 1 µm** |
| 열별 총 흔들림 | 정지 평판 100장, 열별 시간 σ의 중앙값 | **≤ 5 µm** (Z 반복성 목표) |
| 진동원 목록 | 장비 on/off 비교 | 공통 σ에 0.5 µm 이상 기여하는 장비 모두 식별·조치 |
| 외란 민감도 | 보행·문 여닫기 시험 | 영향 크기 기록, 필요 시 SOP 규칙 |
| 정지 후 안정 시간 | ≥ 500 fps, 10회 | 안정 시간 최댓값 측정, 대기시간 확정 |
| 재현 | 다른 날 2번 시험 반복 | 공통 σ가 다시 ≤ 1 µm |

## 8. 흔한 실수와 대응

| 실수 | 증상 | 대응 |
|---|---|---|
| 진동과 노이즈를 구분 안 함 | 방진 패드를 바꿔도 결과가 안 변해 혼란 | 공통/독립 성분 분해 후 대책 선택 |
| 100 fps로만 주파수 분석 | 엉뚱한 주파수의 장비를 의심 | fps를 바꿔 재측정, 장비 on/off 확인 |
| 워밍업 중 시험 | 드리프트가 σ에 섞여 과대평가 | 30분 워밍업 후 시험 (C6) |
| 브래킷 볼트 풀림 | 특정 시점부터 σ 급증 | 체결 토크 확인, 나사 고정제·페인트 표시 |
| 대기시간을 감으로 정함 | 프로파일마다 높이가 들쭉날쭉(줄무늬) | 고속 촬영으로 실측 × 2 |
| 사람이 측정대에 기대거나 책상을 짚음 | 특정 스캔에서만 큰 줄무늬 | "측정 중 접촉 금지" 표지 |
| 평판 대신 시편으로 시험 | 형상 변화와 진동이 섞임 | 평평하고 무광인 기준 평판 사용 |

## 9. 위험 요소

- **건물 진동**: 엘리베이터, 공사, 대형 장비 등은 연구실이 통제할 수 없습니다. 측정 시간대를 바꾸거나, 매 세션 시작 시 정지 평판 시험(빠른 점검 100장)을 하고 결과가 기준을 넘으면 측정을 미룹니다.
- **프린터 위 측정의 한계**: 프린터 프레임은 강성이 낮아 센서가 흔들릴 수 있습니다. 공통 σ ≤ 1 µm를 못 맞추면 센서를 별도 받침에 다는 구조로 바꾸는 것을 K4 위험으로 올립니다.
- **방진 패드의 처짐**: 무거운 받침 아래 고무 패드는 시간이 지나며 눌려 수평이 변합니다. 월 1회 수평 확인.
- **안전**: 석정반은 매우 무겁습니다(수십 kg 이상). 두 사람 이상이 옮기고, 손가락 끼임에 주의합니다.
