## 1. 목적

카메라에 들어오는 빛 중 **레이저 선이 아닌 모든 빛은 노이즈**입니다. 이 요소의 목적은 측정대를 조립하는 W5-6 동안

1. 주변광 차단(필터·차광막·조명 관리)을 설치하고,
2. 정량 기준 **"레이저를 끈 이미지의 최대 밝기 < 레이저 신호의 5 %"** 를 측정으로 확인하며,
3. 남은 주변광을 줄이는 **배경 차감** 절차를 정해 F1(라인 추출)에 넘기는 것입니다.

M1(W7-8)의 레이저 평면 캘리브레이션은 이 조건이 갖춰진 뒤에 해야 의미가 있습니다.

## 2. 배경 지식 (초보자용)

**주변광이 왜 문제인가?** 레이저 선 중심은 "밝기의 무게중심"으로 계산합니다(F1). 그런데 선 주변에 주변광이 깔려 있고, 그 밝기가 위아래로 다르면(예: 위쪽 형광등 때문에 아래쪽이 더 밝음) 무게중심이 밝은 쪽으로 끌려갑니다. 픽셀 이동은 곧 높이 오차입니다 (B1: 1 px ≈ 27.6 µm).

```
 밝기                       주변광이 기울어 있으면
  │      ▲ 레이저 선         무게중심이 오른쪽(밝은 쪽)으로 밀림
  │     ╱ ╲
  │    ╱   ╲  ___----        → 0.1 px 이동 ≈ 2.8 µm 높이 오차
  │___╱     ╲---
  └──────────────── 행(v)
```

**주변광의 원천**

| 원천 | 특징 | 대응 |
|---|---|---|
| 형광등·LED 천장 조명 | 넓은 파장, 50/60 Hz 깜빡임 (밝기가 프레임마다 다름) | 대역통과 필터 + 차광막 |
| 햇빛 | 매우 강하고 시간에 따라 변함 | 블라인드, 창가 설치 금지 |
| 프린터 LED·디스플레이 | 측정대 바로 옆, 반사로 들어옴 | 측정 중 끄기 또는 검은 테이프 |
| 레이저 자체의 2차 반사 | 레이저 파장이라 필터를 통과함 | 무광 흑색 배경, 반사면 제거 (E1) |

**대역통과 필터의 한계**: 405 ± 10 nm 필터는 다른 색의 빛을 대부분 막지만, 형광등과 백색 LED에도 405 nm 근처 성분이 조금 있습니다. 그래서 필터만으로는 부족하고 차광막이 같이 필요합니다. 또 **레이저 파장의 반사광은 필터로 막을 수 없습니다.**

**배경 차감**: 같은 노출·게인으로 "레이저 끈 이미지"를 찍어 "레이저 켠 이미지"에서 뺍니다. 고정된 주변광은 거의 사라집니다. 단, ① 두 이미지의 노이즈가 더해져 노이즈가 약 √2배 늘고, ② 깜빡이는 조명은 두 장이 달라서 완전히 지워지지 않으며, ③ 포화된 픽셀은 복구되지 않습니다.

**5 % 기준의 의미**: 8-bit 카메라에서 레이저 신호가 200이면, 레이저를 껐을 때 가장 밝은 픽셀도 10 미만이어야 합니다.

## 4. 결정 사항

| 결정 항목 | 선택지 | 권장 | 근거 |
|---|---|---|---|
| 차광 방식 | 인클로저(상자) / 암막천 커튼 / 실내 소등 | **검은 무광 인클로저 + 실내 조명 유지** | 소등은 작업 안전·재현성 문제, 인클로저는 매번 같은 조건 |
| 인클로저 재질 | 검은 아크릴 / 무광 흑색 보드 / 암막천 | **무광 흑색 보드 + 틈새 암막천** | 광택 아크릴은 레이저를 반사 |
| 레이저 안전과의 관계 | – | 인클로저가 **빔 차단막 역할도** 하도록 설계 | C8 |
| 프린터 조명 | 켬 / 끔 | **측정 중 끔** (G코드 또는 수동) | 측정대 바로 옆 광원 |
| 배경 차감 | 안 함 / 세션당 1장 / 스캔마다 N장 평균 | **스캔 시작 전 레이저 끈 이미지 10장 평균** | 노이즈 증가를 1/√10로 줄임 |
| 판정 통계 | 최댓값 / 99.99 백분위수 | **99.99 백분위수** + 최댓값 병기 | 핫픽셀 몇 개가 판정을 지배하지 않게 |
| 합격 기준 | 5 % / 2 % | **< 5 %** (청사진 기준), 목표 < 2 % | |

## 5. 수행 절차

1. **기준 상태 측정 — 대책 없음 (W5 월)**
   - [ ] 실제 측정과 같은 노출·게인·레이저 출력으로, 평소 실내 조명 상태에서 흰 무광 평판을 놓는다.
   - [ ] 레이저 끈 이미지 10장, 켠 이미지 10장을 찍는다(조건 A).
   - [ ] 6절 스크립트의 `ambient_ratio`로 비율을 계산해 기록한다. (예상: 수십 %)

2. **대역통과 필터 효과 (W5 화)**
   - [ ] 필터 장착 상태에서 1번을 반복한다(조건 B). 필터가 이미 장착돼 있으면 필터를 뗀 상태를 조건 A로 삼는다.
   - [ ] 필터 장착 후 레이저 신호도 약간 줄어든다(필터 투과율). 신호 최대값이 포화의 50~90 %가 되도록 노출을 다시 맞춘다(F1의 포화 금지 규칙).

3. **차광 인클로저 제작 (W5 수~금)**
   - [ ] 측정대 크기 + 사방 50 mm 여유로 상자를 만든다. 앞면은 여닫이 또는 암막천.
   - [ ] 내부는 무광 흑색. 케이블 구멍은 브러시 그로밋이나 천으로 막는다.
   - [ ] 프린터 위에서 측정하는 경우(C2), 프린터 프레임에 탈착식 암막 커튼을 단다.

4. **대책 적용 후 측정 (W6 월)**
   - [ ] 필터 + 인클로저 + 프린터 LED 끔 상태에서 1번 반복(조건 C).
   - [ ] 비율 < 5 %인지 확인. 실패하면 이미지에서 밝은 곳의 위치를 찾아 원인(틈새, 반사면)을 제거하고 반복.
   - [ ] 실내 조명을 켜고/끄고, 창 블라인드를 열고/닫고 각각 측정해 **바깥 조건에 둔감한지** 확인(비율 변화 < 1 %p).

5. **배경 차감 효과 확인 (W6 화)**
   - [ ] 평판 이미지에서 열마다 레이저 중심을 배경 차감 전후로 계산한다.
   - [ ] 100장 반복 측정의 열별 표준편차를 비교한다 (C7·F1과 같은 방법). 차감 후 표준편차가 커지면(√2배 이상) 배경 평균 장수를 늘린다.

6. **체크리스트와 인계 (W6 수)**
   - [ ] 매 측정 세션 시작 시 확인할 조명 체크리스트를 작성한다(10절).
   - [ ] `config/acquisition.yaml`에 배경 차감 설정을 넣고 F1·D2 담당에게 알린다.

## 6. Python 구현

합성 이미지로 두 상황(차광 없음 / 필터+차광막)을 만들어 ① 주변광 비율 판정과 ② 배경 차감 전후의 레이저 중심 오차를 비교합니다. 실제 시험에서는 `make_images` 대신 `cv2.imread(path, cv2.IMREAD_UNCHANGED)`로 읽은 이미지 10장의 평균을 넣습니다.

```python
"""C5 주변광: 레이저 끔/켬 이미지로 (1) 주변광 비율 판정, (2) 배경 차감 효과 확인. 합성 이미지."""
import numpy as np

rng = np.random.default_rng(2)
H, W = 200, 300                       # 작은 ROI 이미지 (행 v, 열 u)
V_TRUE = 100.3                        # 참 레이저 중심 행 (서브픽셀)

def make_images(bg_level, bg_slope, led_peak, laser_peak=200.0, sigma_line=1.5):
    """bg_level: 균일 배경, bg_slope: 행 방향 밝기 기울기(조명 그라데이션), led_peak: 국소 광원"""
    v, u = np.mgrid[0:H, 0:W].astype(float)
    bg = bg_level + bg_slope * v                                  # 위→아래로 밝아지는 주변광
    bg += led_peak * np.exp(-((u - 250) ** 2 + (v - 60) ** 2) / (2 * 8 ** 2))  # LED 반사
    laser = laser_peak * np.exp(-(v - V_TRUE) ** 2 / (2 * sigma_line ** 2))
    off = bg + rng.normal(0, 1.0, (H, W))
    on = bg + laser + rng.normal(0, 1.0, (H, W))
    return np.clip(off, 0, 255), np.clip(on, 0, 255)

def ambient_ratio(off, on, robust_pct=99.99):
    """주변광 비율 = (레이저 끈 이미지 최대값) / (레이저 신호 최대값)
    최대값은 핫픽셀 영향을 줄이려고 99.99 백분위수를 쓴다."""
    signal = np.percentile(on - off, robust_pct)
    return np.percentile(off, robust_pct) / signal

def cog_rows(img, half_win=6):
    """열마다 최대점 주변 무게중심 (F1의 간단한 버전, 임계값 없이)"""
    pk = img.argmax(axis=0)
    out = np.empty(img.shape[1])
    for c in range(img.shape[1]):
        r0, r1 = max(pk[c] - half_win, 0), min(pk[c] + half_win + 1, img.shape[0])
        w = img[r0:r1, c]
        out[c] = r0 + (w * np.arange(r1 - r0)).sum() / w.sum()
    return out

if __name__ == "__main__":
    cases = {
        "차광 없음(형광등+LED)": dict(bg_level=40, bg_slope=0.15, led_peak=120),
        "필터+차광막":          dict(bg_level=3, bg_slope=0.01, led_peak=4),
    }
    for name, kw in cases.items():
        off, on = make_images(**kw)
        r = ambient_ratio(off, on)
        e_raw = np.abs(cog_rows(on) - V_TRUE)                # 배경 차감 안 함
        e_sub = np.abs(cog_rows(np.clip(on - off, 0, None)) - V_TRUE)  # 배경 차감
        print(f"[{name}] 주변광 비율 = {100*r:.1f} % → {'합격' if r < 0.05 else '불합격'} (기준 < 5 %)")
        print(f"   중심 오차 평균: 차감 전 {e_raw.mean():.3f} px, 차감 후 {e_sub.mean():.3f} px")
```

**실행 방법**: `python scripts/hw/c5_ambient.py`

**기대 출력**

```
[차광 없음(형광등+LED)] 주변광 비율 = 83.7 % → 불합격 (기준 < 5 %)
   중심 오차 평균: 차감 전 0.128 px, 차감 후 0.017 px
[필터+차광막] 주변광 비율 = 4.4 % → 합격 (기준 < 5 %)
   중심 오차 평균: 차감 전 0.020 px, 차감 후 0.016 px
```

**해석**
- 차광 없이 기울어진 주변광이 있으면 중심이 평균 0.128 px 밀립니다. B1 계산 예(1 px ≈ 27.6 µm)로 환산하면 **약 3.5 µm의 계통 오차**로, Z 반복성 목표(5 µm)와 비슷한 크기입니다.
- 배경 차감은 이 오차를 0.017 px(≈ 0.5 µm)까지 줄입니다. 하지만 실제로는 형광등 깜빡임 때문에 완전히 지워지지 않으므로 **차광이 우선이고 차감은 보조**입니다.
- 차광이 잘 된 경우에는 차감 전후 차이가 작습니다. 이 상태가 목표입니다.

**실제 이미지로 판정하는 최소 코드**

```python
import glob
import cv2
import numpy as np
from c5_ambient import ambient_ratio   # 위 파일

def mean_image(pattern):
    files = sorted(glob.glob(pattern))
    return np.mean([cv2.imread(f, cv2.IMREAD_UNCHANGED).astype(float) for f in files], axis=0)

off = mean_image("data/raw/hw_tests/C5_ambient_20261110/off_*.png")
on = mean_image("data/raw/hw_tests/C5_ambient_20261110/on_*.png")
print(f"주변광 비율 = {100 * ambient_ratio(off, on):.1f} %")
```

## 7. 검증 방법과 완료 기준

| 항목 | 방법 | 합격 기준 |
|---|---|---|
| 주변광 비율 (주 기준) | 레이저 끔 99.99 백분위수 / 레이저 신호 99.99 백분위수 | **< 5 %** (목표 < 2 %) |
| 최댓값 기준 (참고) | 레이저 끔 최댓값 / 레이저 신호 최댓값 | < 5 %, 넘으면 핫픽셀인지 확인 |
| 외부 조건 둔감성 | 실내등 켬/끔, 블라인드 열림/닫힘 | 비율 변화 < 1 %p |
| 레이저 신호 포화 | 레이저 켠 이미지 최댓값 | 센서 최댓값의 50~90 % |
| 배경 차감 후 반복성 | 정지 평판 100장, 열별 중심 표준편차 | 차감 전 대비 증가 < 20 % |
| 체크리스트 | 문서 + 첫 세션 사용 기록 | 모든 항목 체크 |

| 노출을 바꾼 뒤 예전 배경 이미지로 차감 | 차감 후 음수·양수 줄무늬 | 배경 이미지는 같은 노출·게인으로 매 스캔 직전 촬영 |
| 광택 검은 아크릴로 인클로저 제작 | 레이저 반사가 이미지에 가짜 선으로 나타남 | 무광 흑색 재질, 반사점 위치 확인 |
| 필터 장착 후 노출 재조정 안 함 | 신호가 어두워 노이즈 증가 | 신호 최대값 50~90 % 되게 재조정 |
| 최댓값 하나로 판정 | 핫픽셀 1개 때문에 불합격 | 99.99 백분위수 사용, 핫픽셀 목록 기록 |
| 압축(JPEG) 이미지로 시험 | 블록 노이즈, 밝기 왜곡 | 무손실 PNG/TIFF 또는 원본 형식 |
| 프린터 LED·화면을 켜 둔 채 측정 | 특정 위치에 밝은 점 | 체크리스트에 "프린터 조명 끔" 포함 |
| 문을 연 상태로 측정 | 세션마다 결과가 달라짐 | 인클로저 닫힘 확인 후 측정 시작 |

## 9. 위험 요소

- **깜빡이는 조명(50/60 Hz)**: 노출 시간이 짧으면(≤ 1 ms) 프레임마다 주변광 밝기가 다릅니다. 차감으로 지워지지 않으므로 차광으로 해결해야 합니다.
- **인클로저 내부 발열**: 밀폐하면 카메라·레이저·모터 열이 갇혀 온도가 오릅니다(C6). 환기 구멍은 빛이 직접 들어오지 않도록 미로 구조(꺾인 통로)로 만듭니다.
- **인클로저가 작업을 방해**: 시편 교체가 불편하면 사람들이 열어 둔 채 측정합니다. 여닫기 쉬운 구조로 만듭니다.
- **안전**: 인클로저는 레이저 빔이 바깥으로 나가는 것도 막아 줍니다. 다만 인클로저 안을 들여다볼 때는 레이저를 끄는 규칙을 지킵니다(C8).
