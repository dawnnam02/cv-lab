## 1. 목적

재료는 온도에 따라 늘어나고 줄어듭니다. 시편, 베드, 센서 브래킷, 게이지 블록이 모두 해당합니다. 이 요소의 목적은

1. 온도 변화가 측정값에 주는 영향을 **숫자로 계산**하고(열팽창 계산표),
2. **베드 냉각 대기시간**과 **센서 워밍업 시간**을 실측해 규칙으로 정하며,
3. 매 측정마다 온도를 기록하는 체계를 만들고,
4. 온도 요인을 불확도 예산(I1)의 한 항목으로 넘기는 것입니다.

온도는 M5(Gage R&R)에서 "날마다 결과가 다른" 원인으로 자주 나타납니다. W5-6에 규칙을 정해 두면 이후 모든 데이터가 같은 조건에서 쌓입니다.

## 2. 배경 지식 (초보자용)

**열팽창 공식**

```
ΔL = α · L · ΔT
  α : 열팽창계수 [µm/(m·°C)]   L : 길이 [m]   ΔT : 온도 변화 [°C]
예) PLA 50 mm, 5 °C 상승 → 68 × 0.05 × 5 = 17 µm
```

| 재료 | α (대략) | 50 mm·1 °C | 50 mm·5 °C | 50 mm·38 °C (60→22 °C) |
|---|---|---|---|---|
| PLA | ~68 µm/(m·°C) | 3.4 µm | 17 µm | ~129 µm |
| ABS | ~90 | 4.5 µm | 22.5 µm | ~171 µm |
| 알루미늄 | ~23 | 1.2 µm | 5.8 µm | ~44 µm |
| 강철(게이지 블록) | ~11.5 | 0.6 µm | 2.9 µm | ~22 µm |

이 표가 말하는 것: **가열 베드(60 °C) 위에서 바로 재면 50 mm PLA 시편은 실온보다 100 µm 이상 클 수 있습니다.** 측정하려는 치수 오차(±0.1 mm)와 같은 크기입니다. 그래서 반드시 식힌 뒤 잽니다. (PLA는 60 °C 근처가 유리전이 온도라 실제 거동은 단순 선형식과 다를 수 있습니다. 표는 크기를 가늠하는 용도입니다.)

**측정 기준 온도**: 길이 측정의 국제 기준 온도는 **20 °C**입니다(ISO 1). 연구실이 22 °C이면 그 상태로 재고, 보고서에 측정 온도를 적습니다. 모든 측정을 같은 온도 범위(예: 22 ± 1 °C)에서 하는 것이 핵심입니다.

**뉴턴 냉각**: 뜨거운 물체는 처음엔 빨리, 실온에 가까워질수록 천천히 식습니다.

```
T(t) = T_실온 + (T_처음 − T_실온) · exp(−t / τ)        τ: 시정수(분)
실온 + 1 °C 에 도달하는 시간  t = τ · ln(ΔT_처음 / 1 °C)
예) τ = 9분, ΔT_처음 = 38 °C → 9 × ln 38 ≈ 33분
```

**워밍업 드리프트**: 카메라 센서, 레이저 다이오드, 모터는 켠 뒤 스스로 데워집니다. 카메라 기판과 브래킷이 늘어나면 측정 높이가 천천히 변합니다. 예를 들어 센서와 측정면 사이 알루미늄 브래킷 100 mm가 1 °C 데워지면 2.3 µm가 변합니다. 그래서 켠 직후 바로 측정하지 않고 드리프트가 멈출 때까지 기다립니다 (청사진 규칙: 30분).

**온도와 캘리브레이션**: 캘리브레이션(D)을 22 °C에서 했는데 26 °C에서 측정하면 캘리브레이션이 맞지 않을 수 있습니다. 캘리브레이션 기록에도 온도를 적습니다.

## 6. Python 구현

열팽창 계산표, 냉각 곡선 맞춤, 워밍업 드리프트 맞춤을 한 파일에 담았습니다. 측정 로그 대신 합성 데이터(냉각 τ = 9분, 워밍업 드리프트 8 µm·τ = 10분)를 넣어 동작을 확인합니다. 실제 로그는 `pandas.read_csv`로 `t`, `T`, `z` 배열을 읽어 넣으면 됩니다.

```python
"""C6 온도: (1) 열팽창 계산표, (2) 베드 냉각 곡선 → 측정 가능 시각, (3) 센서 워밍업 드리프트 → 대기시간"""
import numpy as np
from scipy.optimize import curve_fit

ALPHA_UM_PER_M_C = {"PLA": 68, "ABS": 90, "알루미늄": 23, "강철(게이지블록)": 11.5}

def expansion_um(material, length_mm, dT_C):
    """열팽창 ΔL = α · L · ΔT  [µm]"""
    return ALPHA_UM_PER_M_C[material] * (length_mm / 1000) * dT_C

def cooling(t, T_room, dT0, tau):
    """뉴턴 냉각: T(t) = T_room + dT0 · exp(−t/τ)"""
    return T_room + dT0 * np.exp(-t / tau)

def warmup(t, A, tau, z0):
    """워밍업 드리프트: z(t) = z0 + A · (1 − exp(−t/τ))"""
    return z0 + A * (1 - np.exp(-t / tau))

if __name__ == "__main__":
    rng = np.random.default_rng(3)
    # (1) 열팽창 계산표: 길이 50 mm, 높이 10 mm, ΔT = 1 °C / 5 °C / 38 °C (60 °C 베드 → 22 °C)
    print("재료, 50mm·1°C, 50mm·5°C, 50mm·38°C, 높이10mm·38°C [µm]")
    for m in ALPHA_UM_PER_M_C:
        print(f"{m}: {expansion_um(m,50,1):.1f}, {expansion_um(m,50,5):.1f}, "
              f"{expansion_um(m,50,38):.0f}, {expansion_um(m,10,38):.0f}")

    # (2) 베드 냉각 로그 (합성): 60 °C에서 히터 끔, 실온 22 °C, τ = 9분, 1분 간격, 온도계 노이즈 0.1 °C
    t = np.arange(0, 61, 1.0)
    T = cooling(t, 22.0, 38.0, 9.0) + rng.normal(0, 0.1, t.size)
    (Tr, dT0, tau), _ = curve_fit(cooling, t, T, p0=(20, 40, 10))
    t_ready = tau * np.log(dT0 / 1.0)                 # T − T_room ≤ 1 °C 가 되는 시각
    print(f"냉각 맞춤: 실온 {Tr:.2f} °C, τ = {tau:.2f} 분 → 실온+1 °C 도달 {t_ready:.1f} 분 후")

    # (3) 워밍업 드리프트 (합성): 전원 켠 뒤 기준 평판 높이, 총 드리프트 8 µm, τ = 10분
    t2 = np.arange(0, 61, 2.0)
    z = warmup(t2, 8.0, 10.0, 0.0) + rng.normal(0, 0.5, t2.size)
    (A, tau_w, z0), _ = curve_fit(warmup, t2, z, p0=(5, 5, 0))
    t_warm = tau_w * np.log(abs(A) / 1.0)              # 남은 드리프트 ≤ 1 µm 시각
    print(f"워밍업 맞춤: 총 드리프트 {A:.2f} µm, τ = {tau_w:.2f} 분 → 남은 드리프트 1 µm 이하 {t_warm:.1f} 분 후")
    print("규칙: 워밍업 대기 =", int(np.ceil(max(t_warm, 30) / 5) * 5), "분 (최소 30분)")
```

**실행 방법**: `python scripts/hw/c6_temperature.py`

**기대 출력**

```
재료, 50mm·1°C, 50mm·5°C, 50mm·38°C, 높이10mm·38°C [µm]
PLA: 3.4, 17.0, 129, 26
ABS: 4.5, 22.5, 171, 34
알루미늄: 1.2, 5.8, 44, 9
강철(게이지블록): 0.6, 2.9, 22, 4
냉각 맞춤: 실온 22.00 °C, τ = 9.01 분 → 실온+1 °C 도달 32.8 분 후
워밍업 맞춤: 총 드리프트 8.21 µm, τ = 10.31 분 → 남은 드리프트 1 µm 이하 21.7 분 후
규칙: 워밍업 대기 = 30 분 (최소 30분)
```

**해석**
- 냉각: 이 예에서는 출력 종료 후 약 33분이 지나야 베드가 실온 + 1 °C에 도달합니다. 3회 측정 중 가장 긴 값 + 5분(예: 40분)을 SOP 대기시간으로 정합니다.
- 워밍업: 드리프트가 1 µm 이하로 줄어드는 시간은 약 22분이지만 청사진 규칙의 최소 30분을 적용합니다.
- 10 mm 높이 PLA 시편이 38 °C 차이에서 26 µm 커진다는 점은 **높이 오차에도** 온도가 직접 들어간다는 뜻입니다.

## 8. 흔한 실수와 대응

| 실수 | 증상 | 대응 |
|---|---|---|
| 출력 직후 바로 측정 | 반복 스캔마다 치수가 줄어듦 (수십 µm) | 냉각 대기 규칙, `minutes_after_print_end` 기록 |
| 전원 켠 직후 측정 | 첫 스캔들이 나중 스캔과 체계적으로 다름 | 30분 워밍업, `sensor_on_minutes` 기록 |
| 게이지 블록을 손으로 오래 쥠 | 검증(D5) 결과가 µm 단위로 틀어짐 | 장갑·집게 사용, 측정 전 10분 이상 측정대 위 방치 |
| 온도계를 송풍구·창가에 둠 | 실제 측정대 온도와 다른 값 기록 | 센서 높이, 측정대 옆에 고정 |
| 베드 온도 표시를 시편 온도로 착각 | 베드는 식었는데 시편 내부는 아직 따뜻함 | 시편 높이 수렴 시간도 한 번 확인 (5절 3번) |
| 온도로 계산 보정을 함부로 적용 | 보정 후 오히려 반복성 악화 | 보정하지 않고 조건 통제 + 불확도에 반영 |
| 인클로저를 밀폐 | 내부 온도가 서서히 상승 | 미로형 환기구, 내부 온도도 기록 (C5) |

## 9. 위험 요소

- **계절 변화**: 겨울과 봄 사이 실험실 온도가 수 °C 달라질 수 있습니다. 실험 기간(W18-21 본 실험)이 겨울에 걸치므로 냉난방 상태를 기록합니다.
- **화상**: 베드(60 °C 이상)와 노즐(200 °C 이상)에 손이 닿지 않게 합니다. 냉각 중 시편을 만지지 않습니다.
- **층별 측정 데이터의 혼동**: C2 2단계 데이터는 뜨거운 상태입니다. 실온 데이터와 같은 표에 섞지 말고 `timing` 필드로 구분합니다.
- **재료 비선형성**: PLA는 유리전이 온도(약 55~65 °C) 근처에서 거동이 달라 단순 선형 계산이 맞지 않습니다. 정량 결론은 실온 측정만으로 냅니다.
