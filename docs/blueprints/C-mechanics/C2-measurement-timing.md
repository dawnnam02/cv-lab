## 1. 목적

"언제, 어디에서 측정하는가"를 정합니다. 이 선택은 **어떤 오차를 측정할 수 있는지**를 결정합니다.

- 시편을 베드에서 떼면 G코드 좌표계와의 연결이 끊어져 **위치 오차**를 잴 수 없습니다.
- 출력이 끝난 뒤 윗면만 재면 **내부 층의 오차**는 볼 수 없습니다.

이 요소의 목표는 (1) 1단계 방식 "공정 후, 베드 위에서"를 확정하고 절차를 문서로 만들며, (2) 2단계 "층별 측정"을 위한 G코드 삽입 도구와 조건을 미리 준비해 M4 이후 확장할 수 있게 하는 것입니다.

## 2. 배경 지식 (초보자용)

**세 가지 측정 시점**

| 방식 | 설명 | 측정 가능한 오차 | 어려움 |
|---|---|---|---|
| **공정 후, 베드 위** (1단계 권장) | 출력이 끝나면 떼지 않고 그대로 스캔 | 높이·윤곽·치수·**위치** | 낮음 |
| 공정 후, 떼어 내서 | 별도 측정대에서 스캔 | 높이·윤곽·치수 (위치 ✗) | 낮음 |
| **공정 중 층별 (in-situ)** (2단계) | N층마다 출력을 멈추고 스캔 | 위 + **층별 마스크와 1:1 비교**, 내부 층 기록 | 높음 |

**왜 베드에서 떼면 위치 오차가 사라지나?** G코드는 "베드 위 X=100, Y=100에 그려라"라고 명령합니다. 시편을 떼서 다른 곳에 놓으면 "원래 베드 어디에 있었는지"를 알 방법이 없습니다. 그러면 정합(H4)은 모양을 최대한 겹치는 방식밖에 쓸 수 없고, 전체가 0.2 mm 밀린 오차는 정합이 지워 버립니다.

**층별 측정의 원리**: 슬라이서(Cura, PrusaSlicer, OrcaSlicer 등)는 층이 바뀔 때마다 G코드에 `;LAYER_CHANGE` 또는 `;LAYER:n` 같은 주석을 넣습니다. 이 위치에 "노즐을 들어 올려 치우고, 일정 시간 기다리는" 명령을 넣으면 그 시간 동안 센서로 방금 쌓은 층의 윗면을 스캔할 수 있습니다. 슬라이서에는 이를 위한 "층 변경 시 G코드(Before/After layer change G-code)" 입력란이 있고, 이 문서의 스크립트는 같은 일을 Python으로 해서 "몇 층마다" 같은 조건을 정확히 제어합니다.

**층 번호 규칙 (중요)**: 이 과제에서는 **층 번호를 0부터** 셉니다. 층 0은 첫 층(노즐 Z = 0.2 mm), 층 5는 여섯 번째 층(Z = 1.2 mm)입니다. G1 파서(G1)와 같은 규칙을 씁니다.

**층별 측정 시 주의할 물리 현상**
- 방금 쌓은 층은 **뜨겁습니다** (PLA 기준 베드 60 °C, 윗층은 그보다 높음). 식으면서 줄어들므로 같은 층이라도 측정 시점에 따라 높이가 다릅니다(C6).
- 노즐에서 흘러나온 재료(oozing)가 측정면에 떨어질 수 있습니다.
- 출력을 멈추는 동안 층이 식어서 다음 층과의 접착력이 바뀌어, **측정 행위 자체가 시편을 바꿀 수 있습니다.** 그래서 층별 측정 시편과 비측정 시편을 비교하는 대조 실험이 필요합니다.

## 4. 결정 사항

| 결정 항목 | 선택지 | 권장 | 근거 |
|---|---|---|---|
| 1단계 측정 시점 | 베드 위 / 떼어 내서 | **공정 후, 베드 위** | 위치 오차 측정 가능, 구현 쉬움 |
| 2단계 측정 시점 | 층별 / 안 함 | M4 통과 후 **층별** 확장 | 층별 마스크(G3)와 1:1 비교 |
| 측정 전 냉각 | 베드 끄고 실온 / 베드 온도 유지 | **베드 끄고 실온까지 (± 1 °C)** | C6 열팽창. 같은 조건 유지 |
| 층별 스캔 간격 | 매 층 / N층마다 | **N = 5** 출발 (시편 20층 기준 3~4회) | 매 층은 시간·냉각 영향이 큼 |
| 층별 스캔 대기시간 | 계산값 | 스캔 시간 + 여유 10 s (예: 25 s + 15 s ≈ **40 s**) | C1 스캔 시간 25 s 기준 |
| 노즐 회피 위치 | 측정 영역 밖 | 센서 FOV와 스캔 경로를 피하는 위치 (예: X200 Y200) | 노즐·흘림이 측정을 가리지 않게 |
| 노즐 들어 올림 | 1~5 mm | **2 mm** | 센서와 충돌·흘림 방지 |
| 스캔 시작 신호 | 고정 시간 대기 / 펌웨어 메시지(`M118`) / 스테이지 위치 감지 | 처음엔 **고정 시간 대기**, 가능하면 `M118` | 구현 난이도 순 |
| 대조군 | 있음 / 없음 | **있음**: 같은 G코드를 스캔 정지 없이 출력 | 정지 자체의 영향 분리 |

## 5. 수행 절차

1. **1단계 방식 확정 (W3)**
   - [ ] 센서가 베드 위 시편을 스캔할 수 있는 위치·높이인지 C1 브래킷 설계와 함께 확인한다 (노즐·팬 덕트와 간섭 없어야 함).
   - [ ] 측정 가능 영역(베드 위 X·Y 범위)을 표시한다. 시편과 기준 마커(C3)가 이 안에 들어와야 한다.
   - [ ] `C2_timing_decision.md`에 "1단계 = 공정 후 베드 위, 2단계 = N=5 층별" 을 기록한다.

2. **공정 후 측정 절차서 작성 (W3)**
   - [ ] 출력 종료 → 베드 히터·노즐 히터 끄기 (`M140 S0`, `M104 S0`).
   - [ ] 노즐을 측정 영역 밖으로 이동하고 모터 고정을 유지한다 (모터 해제 시 베드가 밀릴 수 있음, `M84` 금지).
   - [ ] 베드 온도가 실온 + 1 °C 이하가 될 때까지 대기 (PLA·유리 베드 기준 대략 20~40분, C6에서 측정).
   - [ ] 프린터 조명·팬 끄기(C5, C7) → 스캔 → 메타데이터 기록 → 시편 제거.

3. **층별 스캔 G코드 도구 준비 (W4)**
   - [ ] 6절 스크립트를 `scripts/hw/`에 저장하고 합성 G코드로 시험한다.
   - [ ] 실제 시편 G코드에 적용해 `*_insitu_N5.gcode`를 만들고, 슬라이서 미리보기나 G1 파서로 **복귀 이동이 압출 없이** 이뤄지는지 확인한다.
   - [ ] 슬라이서의 "층 변경 시 리트랙션(retract on layer change)"을 켠다 (정지 중 흘림 감소).

4. **층별 스캔 건식 시험 (W4, 필라멘트 없이)**
   - [ ] 필라멘트를 빼고 노즐 온도 0 상태로 `*_insitu_N5.gcode`를 실행해 이동 경로·정지 시간만 확인한다.
   - [ ] 정지 중 노즐 위치가 센서 FOV 밖인지, 센서 이동 경로와 충돌하지 않는지 눈으로 확인한다.
   - [ ] 각 정지 구간 길이를 스톱워치로 재서 설정값(40 s)과 ± 2 s 이내인지 확인한다.

5. **(M4 이후) 층별 측정 본 시험**
   - [ ] 같은 G코드로 층별 측정 시편 3개, 대조군(정지 없음) 3개를 출력한다.
   - [ ] 최종 윗면 높이·치수를 대조군과 비교해서 정지의 영향이 측정 불확도(I1) 이내인지 확인한다.
   - [ ] 층별 스캔 데이터의 메타데이터에 `layer_index`, `nozzle_z_mm`, `bed_temp_C`, `elapsed_since_layer_s`를 기록한다.

## 6. Python 구현

G코드 파일에서 층 변경 주석(`;LAYER_CHANGE` 또는 `;LAYER:`)을 찾아 **N층마다 스캔 정지 블록**을 넣습니다. 블록은 ① 노즐을 2 mm 올리고 ② 측정 영역 밖으로 이동한 뒤 ③ 기다리고 ④ **원래 XY로 돌아와서** ⑤ 원래 높이로 내려옵니다. ④를 빠뜨리면 다음 압출 명령이 회피 위치에서 시편까지 재료를 끌며 선을 그립니다(8절).

```python
"""C2 층별(in-situ) 측정: G코드의 층 변경 지점마다 '스캔 정지 블록'을 삽입한다."""
from pathlib import Path

# G코드 안 주석은 펌웨어 호환을 위해 영어(ASCII)로만 쓴다
SCAN_BLOCK = """; ---- SCAN BLOCK (layer {layer}, Z={z:.3f}) ----
G91 ; relative
G1 Z2 F600 ; lift nozzle 2 mm
G90 ; absolute
G1 X{park_x:.1f} Y{park_y:.1f} F6000 ; park outside scan area
M400 ; wait for moves
M118 SCAN_START L{layer} ; notify PC (if supported)
G4 S{wait_s} ; dwell during scan
G1 X{last_x:.3f} Y{last_y:.3f} F6000 ; back to last XY (still lifted)
G1 Z{z:.3f} F600 ; back to layer Z
; ---- END SCAN BLOCK ----
"""

def insert_scan_blocks(lines, every_n=5, park=(200.0, 200.0), wait_s=40,
                       first_layer=1):
    """lines: G코드 줄 목록 (절대 좌표 G90 가정).
    ;LAYER_CHANGE 또는 ;LAYER: 주석이 나오면 '직전 층'이 끝난 것으로 본다.
    직전 층 번호(0부터 셈)가 first_layer 이상이고 every_n의 배수이면 스캔 블록을 넣는다.
    반환: (새 줄 목록, 스캔한 층 목록[(층번호, 노즐Z)])"""
    out, scanned = [], []
    layer, x, y, z = -1, 0.0, 0.0, 0.0
    for raw in lines:
        s = raw.strip()
        is_layer_mark = s.startswith(";LAYER_CHANGE") or s.startswith(";LAYER:")
        if is_layer_mark and layer >= first_layer and layer % every_n == 0:
            block = SCAN_BLOCK.format(layer=layer, z=z, park_x=park[0], park_y=park[1],
                                      wait_s=wait_s, last_x=x, last_y=y)
            out += [l + "\n" for l in block.splitlines()]
            scanned.append((layer, round(z, 3)))
        if is_layer_mark:
            layer += 1
        code = s.split(";")[0].upper().split()
        if code and code[0] in ("G0", "G1"):
            for w in code[1:]:                 # 현재 노즐 위치 추적
                if w[0] == "X": x = float(w[1:])
                if w[0] == "Y": y = float(w[1:])
                if w[0] == "Z": z = float(w[1:])
        out.append(raw if raw.endswith("\n") else raw + "\n")
    return out, scanned

def added_time_min(n_scans, wait_s, move_s=6.0):
    """스캔 횟수 × (대기 + 이동·복귀 시간) → 늘어나는 출력 시간 [분]"""
    return n_scans * (wait_s + move_s) / 60.0

if __name__ == "__main__":
    # 합성 G코드: 층 높이 0.2 mm, 20층짜리 10 mm 정사각형 외벽
    g = ["G90\n", "M82\n", "G92 E0\n"]
    e = 0.0
    for k in range(20):
        z = 0.2 * (k + 1)
        g += [";LAYER_CHANGE\n", f"G1 Z{z:.2f} F600\n", ";TYPE:WALL-OUTER\n"]
        for px, py in [(10, 0), (10, 10), (0, 10), (0, 0)]:
            e += 0.33
            g.append(f"G1 X{px} Y{py} E{e:.3f} F1800\n")
    g.append(";LAYER_CHANGE\n")      # 마지막 층의 끝 표시

    new, scanned = insert_scan_blocks(g, every_n=5, wait_s=40)
    print("원래 줄 수:", len(g), "→ 삽입 후:", len(new))
    print("스캔하는 층(층번호, 노즐Z):", scanned)
    print(f"늘어나는 시간: {added_time_min(len(scanned), 40):.1f} 분")
    Path("insitu_demo.gcode").write_text("".join(new), encoding="utf-8")
    i = next(i for i, l in enumerate(new) if "SCAN BLOCK (layer" in l)
    print("".join(new[i:i + 11]), end="")
```

**실행 방법**: `python scripts/hw/c2_insert_scan.py` (현재 폴더에 `insitu_demo.gcode` 생성)

**기대 출력**

```
원래 줄 수: 144 → 삽입 후: 177
스캔하는 층(층번호, 노즐Z): [(5, 1.2), (10, 2.2), (15, 3.2)]
늘어나는 시간: 2.3 분
; ---- SCAN BLOCK (layer 5, Z=1.200) ----
G91 ; relative
G1 Z2 F600 ; lift nozzle 2 mm
G90 ; absolute
G1 X200.0 Y200.0 F6000 ; park outside scan area
M400 ; wait for moves
M118 SCAN_START L5 ; notify PC (if supported)
G4 S40 ; dwell during scan
G1 X0.000 Y0.000 F6000 ; back to last XY (still lifted)
G1 Z1.200 F600 ; back to layer Z
; ---- END SCAN BLOCK ----
```

**해석**: 20층(층 0~19) 시편에서 층 5, 10, 15가 끝난 직후 3번 스캔합니다. 층 0은 `first_layer=1` 때문에 건너뜁니다(첫 층은 베드 접착이 우선). 출력 시간은 약 2.3분 늘어납니다. 실제 시편이 100층이고 N = 5이면 19회 × 46 s ≈ 15분이 늘어납니다.

**사용 시 주의**
- 이 스크립트는 **절대 좌표(G90)** G코드를 가정합니다. 슬라이서 출력은 보통 G90입니다.
- 실제 펌웨어에 따라 `M118`을 지원하지 않을 수 있습니다. 지원하지 않으면 그 줄을 지워도 동작합니다.
- 출력 결과 G코드는 반드시 4번 단계(건식 시험)를 거친 뒤 사용합니다.

| 베드 위 스캔 가능성 | 시편 + 마커가 같은 스캔에 찍힘 | 마커 3개 이상 + 시편 전체가 1회 스캔에 포함 |
| 삽입 스크립트 정확성 | 합성 G코드 테스트 | 스캔 층 목록이 예상(5, 10, 15)과 일치 |
| 복귀 이동 무압출 | G1 파서로 삽입 G코드 파싱 | 회피 위치 ↔ 시편 사이에 압출 선분 0개 |
| 정지 시간 | 건식 시험 스톱워치 | 설정값 ± 2 s |
| 충돌·간섭 | 건식 시험 관찰 | 노즐·센서·케이블 간섭 0건 |
| (2단계) 정지 영향 | 대조군 vs 층별 시편 최종 높이 | 차이 < 확장불확도 U (I1) 또는 차이를 별도 보고 |

## 8. 흔한 실수와 대응

| 실수 | 증상 | 대응 |
|---|---|---|
| 스캔 전에 시편을 떼어 냄 | 위치 오차를 계산할 수 없음 | 1단계 SOP에 "스캔 후 제거"를 굵게 명시 |
| 출력 직후 바로 스캔 | 같은 시편인데 반복 측정마다 높이가 줄어듦 | 베드 끄고 실온 + 1 °C 이내 대기 (C6) |
| 스캔 블록 뒤 원래 XY로 복귀 안 함 | 시편 위에 가는 실이 그어짐 | 블록 끝에 마지막 XY 복귀 + Z 하강 |
| `M84`(모터 해제)로 출력 종료 | 베드(Y축)가 손에 밀려 위치가 바뀜 | 측정 끝날 때까지 모터 유지 |
| 층 번호를 1부터 셈 | 기준 마스크와 한 층 어긋난 비교 | 0부터 세는 규칙을 G1·G3·메타데이터에 통일 |
| G코드 주석에 한글 사용 | 일부 펌웨어/호스트에서 오류 | G코드 안 주석은 영어(ASCII)만 |
| 대조군 없이 층별 측정만 수행 | 측정 행위의 영향을 분리 못 함 | 같은 G코드, 정지 없는 대조군 출력 |

## 9. 위험 요소

- **뜨거운 노즐·베드**: 층별 측정 중 노즐은 200 °C 이상입니다. 센서 브래킷과 케이블이 노즐 근처를 지나지 않게 설계하고, 화상 위험 표지를 붙입니다.
- **장시간 정지로 인한 품질 변화**: 정지 중 노즐 끝 재료가 흘러 표면에 점이 생길 수 있습니다. 대조군 비교로 정량화합니다.
- **열 수축 진행 중 측정**: 층별 데이터는 "뜨거운 상태의 높이"입니다. 최종 실온 데이터와 직접 비교하면 안 되며, 해석 시 온도를 같이 기록합니다(C6).
- **펌웨어 차이**: Marlin, Klipper, RepRapFirmware 사이에 명령 지원이 다릅니다. 사용하는 펌웨어 문서로 각 명령을 확인합니다.
- **CNC로 확장할 경우**: 절삭유·칩이 측정면을 덮습니다. 에어 블로우 후 측정 등 별도 절차가 필요합니다.
