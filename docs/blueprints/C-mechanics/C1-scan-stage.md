## 1. 목적

레이저 선 하나는 시편의 **단면 한 줄(프로파일)** 만 잽니다. 면 전체의 높이맵을 얻으려면 센서나 시편을 한 방향(스캔 방향, 이 문서에서는 **Y**)으로 일정한 간격만큼 옮기며 여러 번 찍어야 합니다. 이 요소의 목적은 다음 네 가지입니다.

1. 스캔 이동 방식(전동 스테이지 / 프린터 축 / 수동 스테이지)을 **하나로 확정**한다.
2. 스캔 간격(pitch), 속도, 촬영 방식(위치 트리거 / 스텝 & 촬영)을 **숫자로 확정**한다.
3. 고른 장치의 **위치 반복성·백래시·각도 오차**를 직접 측정해서 사양(A2)을 만족하는지 확인한다.
4. W3-4 안에 측정대 기구 설계(센서 브래킷, 스테이지 고정)를 끝내 W5-6 조립(C5, C8)으로 넘긴다.

## 2. 배경 지식 (초보자용)

**스캔이란?** 복사기를 생각하면 쉽습니다. 복사기 안의 막대 모양 조명·센서가 한 줄씩 읽으며 종이를 따라 움직여 전체 이미지를 만듭니다. 레이저 삼각측량 센서도 한 번에 X 방향 한 줄의 높이(프로파일)를 얻고, Y로 이동하며 줄을 쌓아 높이맵을 만듭니다.

```
  위에서 본 모습 (레이저 선 = X 방향, 이동 = Y 방향)

   Y ↑   ───────────  ← 프로파일 #2501
         ...
         ───────────  ← 프로파일 #2  (간격 0.02 mm 위)
         ───────────  ← 프로파일 #1
         └──────────→ X  (FOV ≈ 20 mm)
```

**용어 정리**

| 용어 | 뜻 | 이 과제에서의 값 |
|---|---|---|
| 스캔 간격 (pitch) | 프로파일과 프로파일 사이 Y 거리 | 0.02 mm (X 점 간격 δx ≈ 13.8 µm와 비슷하게) |
| 스캔 속도 | 연속 이동 시 스테이지 속도 | 2 mm/s (B4 계산 → 100 fps) |
| 위치 반복성 | 같은 위치로 여러 번 보냈을 때 실제 위치의 흩어짐 | ≤ 간격/2 = 10 µm |
| 백래시 (backlash) | 이동 방향을 바꿀 때 기어·나사 틈 때문에 생기는 "헛도는" 거리 | 측정해서 기록 (보통 수~수십 µm) |
| 엔코더 | 실제 위치를 읽는 눈금자 센서. 일정 거리마다 펄스를 냄 | 분해능 예 0.1~1 µm |
| 직진도 | 이동 중에 옆(X)이나 위아래(Z)로 벗어나는 정도 | 높이 오차로 바로 들어감 |
| 피치/요/롤 | 이동 중 스테이지가 앞뒤/좌우/옆으로 기우는 각도 오차 | arcsec(각초) 단위 |
| 아베 오차 | 각도 오차 × 측정점까지의 거리(오프셋) 만큼 생기는 위치 오차 | 아래 계산 |

**아베(Abbe) 오차 공식**

```
아베 오차 ≈ L · tan(α)        L: 스테이지 기준(가이드)에서 측정점까지 거리, α: 각도 오차
1 arcsec = 4.848 µrad  →  L = 50 mm, α = 10″ 이면 ≈ 2.4 µm
```

스테이지가 이동 중 피치 방향으로 10″ 기울면, 가이드에서 50 mm 떨어진 레이저 측정점은 약 2.4 µm 어긋납니다. 이 값은 Z 반복성 목표(5 µm)의 절반에 가까우므로 **무시할 수 없습니다.** 그래서 측정점을 가이드에 가깝게 두는 것(L을 줄이는 것)이 중요합니다.

**위치 트리거 vs 시간 트리거**: 스테이지 속도는 가속·감속 구간과 모터 맥동 때문에 완벽히 일정하지 않습니다. "100 fps로 찍으면 0.02 mm마다 찍힌다"는 시간 기반 가정은 속도가 1 % 흔들리면 Y 위치가 1 % 틀립니다. 엔코더 펄스 N개마다 카메라에 하드웨어 트리거를 보내면 속도와 무관하게 **정확한 위치에서** 촬영됩니다.

## 4. 결정 사항

| 결정 항목 | 선택지 | 권장 | 근거 |

| 이동 방식 | 전동 직선 스테이지 + 엔코더 / 프린터·CNC 자체 축 / 수동 마이크로미터 스테이지 | 예산이 있으면 **전동 스테이지 + 엔코더**, 없으면 **프린터 축**으로 시작 | 프린터 축은 비용이 거의 0이고 G코드 좌표와 연결이 쉬우나 백래시·스텝 오차를 반드시 측정해야 함 |

## 5. 수행 절차

1. **요구 사양 정리 (W3 월~화)**
   - [ ] A2 사양표에서 XY 간격(0.02 mm), 스캔 길이(≥ 50 mm), 스캔 시간 허용치(예: ≤ 60 s)를 옮겨 적는다.
   - [ ] 스테이지 요구 사양을 계산한다: 위치 반복성 ≤ 10 µm(간격/2), 엔코더 분해능 ≤ 1 µm, 이동 범위 ≥ 70 mm, 하중 ≥ 센서 무게 × 2.
   - [ ] 6절 스크립트로 fps, 촬영 장수, 트리거당 펄스 수, 모션 블러를 계산한다.

2. **후보 비교와 선정 (W3 수~금)**
   - [ ] 후보 2~3개(전동 스테이지 모델, 연구실 프린터 축)를 4절 표 항목으로 비교한다.
   - [ ] 전동 스테이지는 사양서에서 반복성, 직진도, 피치/요 각도(arcsec), 엔코더 출력(A/B 상 TTL) 여부를 확인한다. 가격은 **견적을 받아** 기록한다(K3).
   - [ ] 프린터 축을 쓰는 경우 펌웨어가 `M400`(이동 완료 대기)과 직렬 통신 응답을 지원하는지 확인한다.
   - [ ] 지도교수와 선정 결과를 확인하고 `C1_stage_selection.md`에 기록한다.

3. **트리거 연결 방식 확정 (W3 금)**
   - [ ] 엔코더 펄스 → 카메라 트리거: 컨트롤러의 "위치 비교 출력(position compare)" 기능 또는 마이크로컨트롤러로 펄스를 N분주한다. N = 간격 / 엔코더 분해능 (예: 20 µm / 0.5 µm = 40, **정수여야 함**).
   - [ ] 트리거 기능이 없으면 스텝 & 촬영으로 결정하고 대기시간 0.2 s를 가정한다(2501장 × (이동 + 0.2 s) ≈ 10분 이상이므로 스캔 길이를 줄일지 검토).

4. **측정대 기구 설계 (W4 월~수)**
   - [ ] 센서(카메라 + 레이저) 브래킷: 두께 ≥ 6 mm 알루미늄 판 또는 프로파일. 카메라와 레이저는 **같은 강체 판**에 고정한다(서로 움직이면 D2 캘리브레이션이 깨짐).
   - [ ] 레이저 측정점이 스테이지 가이드에서 가능한 가깝게(L ≤ 50 mm 목표) 오도록 배치한다 (아베 오차).
   - [ ] 레이저 평면이 스캔 방향(Y)에 대해 대략 수직(±1° 이내)이 되도록 브래킷에 기준면을 둔다. 정밀 보정은 D3에서 한다.
   - [ ] 케이블은 스트레인 릴리프(고정 클립)로 묶어 이동 중 당기는 힘이 센서에 걸리지 않게 한다.

5. **성능 시험: 반복성·백래시 (W4 목)**
   - [ ] 다이얼 게이지(1 µm 눈금) 또는 레이저 센서 자체(평판 단차 측정)로 스테이지 위치를 읽는다.
   - [ ] 목표 위치 25 mm에 **+방향으로 10회** 접근(매번 20 mm로 후퇴 후 접근), **−방향으로 10회** 접근(매번 30 mm에서 접근)한다.
   - [ ] 각 접근 후 0.5 s 기다린 뒤 읽고 `C1_stage_repeat_YYYYMMDD.csv`에 기록한다.
   - [ ] 6절 스크립트로 단방향 반복성(2σ), 백래시를 계산한다. 합격: 단방향 2σ ≤ 10 µm.

6. **성능 시험: 직진도·각도 (W4 금)**
   - [ ] 정밀 평판(또는 석정반 위 게이지 블록)을 놓고 센서로 스캔해서, 평판 높이가 Y에 따라 어떻게 변하는지 본다. 평판을 180° 돌려 다시 스캔하면 평판 자체의 기울기와 스테이지 직진도를 분리할 수 있다(반전법).
   - [ ] 사양서의 피치 각도로 아베 오차를 계산하고(6절), 2.5 µm를 넘으면 L을 줄이는 설계 변경을 검토한다.

7. **확정과 인계 (W4 금)**
   - [ ] `config/acquisition.yaml`의 `scan:` 블록을 확정한다(10절 양식).
   - [ ] C7(진동)에 스텝 & 촬영 대기시간 측정을, D3에 스캔 방향 벡터·배율 교정을 넘긴다.

## 6. Python 구현

스캔 계획 계산, 반복성·백래시 분석, 아베 오차 계산을 한 파일에 넣었습니다. 측정 원자료 대신 **합성 데이터**(랜덤 1.5 µm, 백래시 12 µm)를 넣어 동작을 확인합니다. 실제 시험 후에는 `plus`, `minus`에 CSV에서 읽은 값을 넣으면 됩니다.

```python
"""C1 스캔 이동 장치: 스캔 계획 계산 + 스테이지 반복성/백래시 분석 + 아베 오차 계산"""
import numpy as np

def scan_plan(pitch_mm, speed_mm_s, length_mm, encoder_res_um,
              exposure_us, img_w=1440, img_h=1080, roi_rows=None):
    """스캔 간격·속도·길이로부터 촬영 조건을 계산한다."""
    fps = speed_mm_s / pitch_mm                     # 필요한 프레임 속도
    n_frames = int(round(length_mm / pitch_mm)) + 1 # 촬영 장수 (양 끝 포함)
    scan_time_s = length_mm / speed_mm_s            # 스캔 시간
    pulses = pitch_mm * 1000 / encoder_res_um       # 촬영 1회당 엔코더 펄스 수
    blur_um = speed_mm_s * 1000 * exposure_us * 1e-6  # 노출 중 이동량 (모션 블러)
    rows = roi_rows if roi_rows else img_h
    size_gb = n_frames * img_w * rows / 1e9         # 8-bit 원본 이미지 용량
    return {
        "fps_필요": fps,
        "촬영_장수": n_frames,
        "스캔_시간_s": scan_time_s,
        "트리거당_펄스": pulses,
        "펄스_정수여부": abs(pulses - round(pulses)) < 1e-9,
        "모션블러_um": blur_um,
        "블러_허용(<간격의1/4)": blur_um < pitch_mm * 1000 / 4,
        "원본용량_GB": size_gb,
    }

def repeatability_backlash(pos_plus_um, pos_minus_um):
    """같은 목표 위치에 +방향/−방향으로 각각 여러 번 접근한 실제 위치(µm, 목표 대비 편차)"""
    p, m = np.asarray(pos_plus_um), np.asarray(pos_minus_um)
    return {
        "단방향_반복성_2σ_um": 2 * p.std(ddof=1),   # 한 방향 접근만의 흩어짐
        "단방향_범위_um": p.max() - p.min(),
        "백래시_um": abs(p.mean() - m.mean()),       # 방향을 바꿨을 때의 평균 차이
        "양방향_범위_um": max(p.max(), m.max()) - min(p.min(), m.min()),
    }

def abbe_error_um(offset_mm, angle_arcsec):
    """아베 오차 = 오프셋 거리 × tan(각도 오차). 1 arcsec = 4.848 µrad"""
    ang = np.radians(angle_arcsec / 3600.0)
    return offset_mm * 1000 * np.tan(ang)

if __name__ == "__main__":
    # (1) 스캔 계획: 간격 0.02 mm, 속도 2 mm/s, 길이 50 mm, 엔코더 0.5 µm, 노출 800 µs
    plan = scan_plan(0.02, 2.0, 50.0, 0.5, 800, roi_rows=300)
    for k, v in plan.items():
        print(f"{k}: {v:.3f}" if isinstance(v, float) else f"{k}: {v}")

    # (2) 반복성·백래시 시험 (합성 데이터: 랜덤 1.5 µm, 백래시 12 µm)
    rng = np.random.default_rng(0)
    plus = rng.normal(0.0, 1.5, 10)
    minus = rng.normal(12.0, 1.5, 10)
    rb = repeatability_backlash(plus, minus)
    for k, v in rb.items():
        print(f"{k}: {v:.2f}")
    ok = rb["단방향_반복성_2σ_um"] <= 0.02 * 1000 / 2
    print("단방향 반복성 합격(≤ 간격/2 = 10 µm):", ok)

    # (3) 아베 오차: 측정점이 스테이지 기준에서 50 mm 위, 피치 각도 오차 10 arcsec
    for arcsec in (5, 10, 30):
        print(f"각도 {arcsec:2d}\" → 아베 오차 {abbe_error_um(50, arcsec):.2f} µm")
```

## 9. 위험 요소

- **납기 지연**: 전동 스테이지는 주문 후 수 주가 걸릴 수 있습니다. W3에 주문하지 못하면 W5-6 조립이 밀립니다 → 프린터 축으로 먼저 시작하는 대안을 같이 준비합니다.
- **프린터 축 정밀도 부족**: 스텝 모터의 미세 스텝은 실제 위치가 불균일할 수 있습니다(수 µm~수십 µm). 반복성 시험에서 10 µm를 넘으면 D3 배율 보정만으로 해결되지 않으니 스테이지 구매를 재검토합니다(K4).
- **아베 오차 과소평가**: 사양서의 각도 오차가 전체 행정 기준인지 확인합니다. 짧은 구간에서는 더 작을 수 있습니다.
- **열에 의한 스테이지 변형**: 모터 발열로 이동 축이 늘어날 수 있습니다 → C6의 워밍업 규칙을 스테이지에도 적용합니다.
- **안전**: 이동 중인 스테이지에 손이 끼일 수 있습니다. 비상 정지 버튼 위치를 확인합니다.
