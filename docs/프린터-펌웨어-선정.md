## 2. 이 워크플로우가 프린터·펌웨어에 요구하는 것

### 9.2 단 고르기 규칙과 ε × d 계산

- h1 = 층 윗면 z_n 이하 (같은 높이 허용)에서 가장 높은 단. h2 = h1보다 낮고 h1 − 3 mm 이상인 단 중 가장 낮은 것 (= h1 − 3 mm에 가장 가까운 낮은 단, 간격 ≤ 3 mm). d = z_n − h1.
- 심도 안: 스캔 높이 = z_n + Z hop 2 mm, 심도 8 mm → 두 단 모두 z_n − 8 mm 이상이면 안 [팀장검증 4차 §7.2 기준].
- 그 자리 배율 오차 ε = √(2 σ² + 2 u²) ÷ (h1 − h2), σ = 기준물 스캔 잡음 1.5 µm, u = 블록 (필러) 교정 표준불확도 2 µm (k = 1, T2 B29) [모두 T2 5.4절 추정값] → 분자 3.54 µm. 간격 3 mm면 ε = 0.118 %, 간격 0.5 mm면 0.707 % [계산].
- 합격선: ε × d ≤ 4 µm → T2 5.4절 C1 민감도 a = 4 µm 행, U = 15.3 µm 이하 (B29 표준불확도 해석, 코디네이터 정정 10-27). d < 3 mm. 충돌 0.

# THERMAL=cooled, gauge temperature, bed_bare on every line.
[respond]

[idle_timeout]

[output_pin cam_trig]
# free pin from Sovol Extra_PIN_definition.pdf; name below is a placeholder

pwm: True
cycle_time: 0.008333     # 1/120 s -> one rising edge per camera frame

- `layer_num`이 0부터라는 근거: 테스트 G코드 ①의 층 변경 칸 `CURRENT_LAYER={layer_num + 1}` (3205줄)이 첫 층에서 1을 냄 (115줄). "전" 칸은 다음 층 직전에 돌므로 방금 끝난 층 = `layer_num - 1` [추정, 13절 9단계에서 대조]. 층 번호 기록은 슬라이서의 `SET_PRINT_STATS_INFO`에 맡기고 매크로는 넣지 않음.
- 끝 G코드의 `{total_layer_count - 1}` 산식: Orca가 `{layer_num + 1}` 식을 이미 처리하므로 같은 문법으로 봄 [추정].
- 테스트 G코드 ②는 Marlin (MK3S)이라 이 매크로를 그대로 못 씀. 모양만 쓰고 SV08 프로필로 다시 슬라이스 (1절).
- **출력 전 충돌 조건 (블록 20 mm가 이미 서 있음):** ① QGL · 메시 이동 높이 25 mm (`HORIZONTAL_MOVE_Z=25`, 블록 최고 20 mm + 5) ② 메시는 `ADAPTIVE=1` (출력물 둘레만, `[exclude_object]` 필요 [추정]) ③ QGL 측정점 · Z 홈 위치가 단 줄 (X 15–325 · Y 37.5–72.5)과 겹치지 않는지 SV08 설정에서 확인 [미상] ④ 퍼지 선 위치를 단 줄 밖으로 [미상, SV08 시작 매크로] ⑤ 전원 직후 `G28` 전 XY 이동 높이 (`safe_z_home` z_hop 등) [미상]. 셋 중 하나라도 확인 못 하면 블록을 G28 · QGL · 메시 뒤에 올려놓고 (`PAUSE`) 이어서 `SCAN_PREPRINT` [추정].
- `M84` (모터 끄기)는 끝 매크로 안에서 식힌 재측정 뒤에만. Orca 프로필이 펌웨어 리트랙트 (`G10`/`G11`)를 쓰면 `[firmware_retraction]`이 있어야 함 (①).
- 단 줄 좌표 (X 20–320)는 레이저 좌표. `sensor_dx`가 크면 노즐이 닿는 범위를 넘을 수 있어 (SV08 X 이동 범위 [미상]) 장착 뒤 줄 전체를 옮기거나 필러 4장을 다른 자리 (얇아 충돌과 무관)로 뺌.
