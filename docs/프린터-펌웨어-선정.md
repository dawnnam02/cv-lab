## 0. 요약

- **최종 1순위: Sovol SV08 + Klipper (Sovol 포크 그대로)** · 조합 점수 57/66 (Voron Trident · Voron 2.4와 동점).
- 이유 1: 스캔 축 (Y)으로 베드가 움직이지 않음 (베드 고정, 갠트리가 Z로 움직임). Z 모터 4개 + QGL로 자동 수평 [출처 16, 17]. 구조 점수가 Trident · 2.4와 같음.
- 이유 2: Klipper 기본 탑재라 변수·조건 매크로, `M400`, `GET_POSITION`, Moonraker 구독이 그대로 열림 [출처 1, 2, 3, 17]. 포크 판이 문제면 mainline 전환 경로가 공개돼 있음 [출처 48].
- 이유 3: 공식 저장소에 핫엔드·Z축·AB축 조립체 STEP과 보드 핀 정의 PDF가 공개돼 센서 브래킷과 트리거 배선을 설계할 수 있음 [출처 43].
- 동점 처리 (§5.3): ① 구조 6 = 6 = 6 → ② 개조비 2만 = 2만 = 2만 → ③ 본체 가격 SV08 81.5만–99.6만 < Trident 195만–214만 < 2.4 216만–233만 [계산]. SV08이 완성품이라 조립 부담도 없음.
- **키트 조립을 감수하지 않으면: SV08 + Klipper (확정).**
- **키트 조립을 감수하면: 규칙상 여전히 SV08.** 다만 본체 예산이 200만 원 이상이고 "mainline Klipper · 전원을 꺼도 처지지 않는 리드스크루 Z"를 더 중시하면 Voron Trident + Klipper가 대안 (점수 같음).
- 가격대별 추천: 50만 이하 = Ender-3 V3 SE + Klipper 교체 (42/66, 권하지 않음) · 50~100만 = SV08 + Klipper (57/66) · 100만 초과 = Voron Trident + Klipper (57/66).
- 예산 (측정 장비 + 검증 기준물 + 개조비): SV08 명목 82.7만 (100만 안) · 상한 136.4만 (넘음 → D-12). 측정 장비가 67.3만 원 이하로 들어와야 100만 원 미만 [계산]. 본체 가격은 따로.
- 매크로 v2: 모든 층 스캔 (every_n = 1), 마지막 층은 끝 G코드에서 따로 스캔, 이어서 식힌 재측정 (모터·베드 온도 유지). 프레임 시각은 프린터 PWM 핀이 카메라 외부 트리거에 프레임마다 펄스를 주는 경로 (펄스 번호 → 위치)로 정함. 모두 실기 미시험.
- 사용자에게 확인할 것: ① 본체 예산과 **키트 조립 감수 여부** (D-13, 위 두 줄과 묶어서) ② 실측 G코드 프로필 (테스트 G코드 2개는 Voron 2.4 350 · Prusa MK3S 프로필이라 SV08로 다시 슬라이스 필요) ③ 구입 시점 ④ 측정 장비 상한이 90만이면 100만 원을 넘는데 감수할지 (D-12).

## 2. 이 워크플로우가 프린터·펌웨어에 요구하는 것

모든 층이 끝날 때마다 노즐을 비키고, 툴헤드 옆 레이저 센서 (M54)로 방금 쌓은 윗면을 Y 방향 2.4 mm/s · 40 mm로 훑음. 같은 높이에서 계단 기준물 (높이를 아는 블록게이지 윗면)도 이어서 훑음. 마지막 층도 재고, 식힌 뒤 한 번 더 잼 (D-06). 프레임마다 정확한 Y 위치가 붙어야 하고, 센서-윗면 거리가 층마다 믿을 만해야 함.

| 참고 총액 (본체 + 장비 + 기준물 + 개조비, 명목) | 115.8만 | 164.2만–182.3만 + 배송 | 277.7만–296.7만 | [계산] |
| 참고 총액 (상한) | 169.5만 | 217.9만–236.0만 + 배송 | 331.4만–350.4만 | [계산] |

- **판정: 명목이면 세 추천 모두 100만 원 미만. 측정 장비 상한 (90만)이면 기준물을 가장 싸게 골라도 넘음** (상한 여유 10만 원 < 기준물 최소 소계) → D-12로 본인에게. 측정 장비가 67.3만 원 이하로 들어오면 SV08 · Trident 경로는 100만 원 미만.
- SV08 본체의 100만 원 경계: 할인가 529 USD면 81.5만–88.0만, 정가 599 USD면 92.2만–99.6만 (관세 8 %일 때 99.6만) [계산 ×1,400 × 1.10–1.188]. 배송비는 [미상]이라 정가 + 관세 8 % + 배송이면 100만 원을 넘어 가격대가 "100만 초과"로 바뀔 수 있음. 넘어도 조합 점수 순위는 같고, 100만 초과 가격대 안에서는 SV08이 Trident보다 쌈.
- 기준물 배송비 (국내)는 [미상]. 마이크로미터를 이미 가진 곳이면 명목에서 13.96만이 빠짐 [미상].
- 개조비 품목은 모두 [추정]이고 견적이 없음. mainline 전환이 필요해지면 (SV08) 전환용 보드 비용이 붙을 수 있음 [미상, 출처 48].
- 카메라 영상은 외부 PC (USB 3.0)로 받는다고 봄. PC는 이미 있다고 보고 0원 [추정].

## 9. 층 변경 매크로 초안

최종 1순위 조합 (Sovol SV08 + Klipper) 문법. mainline Klipper에서도 같음. **실기 미시험.** 층 번호는 0부터. 주석은 ASCII. 매크로 판 `LM-T14-2` (`meta.layer_macro_version`).

1차에서 고친 것 (팀장검증 2차 §4.3, 세부청사진 §11 C3 · C4):

| 번호 | 1차 결함 | 2차 |
|---|---|---|
| 1 | 마지막 층은 층 변경이 없어 스캔되지 않음 → D-06 못 함 | 끝 G코드 맨 앞에서 `SCAN_LAYER LAYER={total_layer_count - 1} FORCE=1` → 이어서 `COOL_RESCAN` (식힌 재측정) → 그다음 원래 끝 매크로 |
| 2 | `every_n` = 5 (층 4 · 9 · 14만) | `every_n` = 1 기본 (모든 층). 5는 설정값으로만 |
| 3 | 게이트 신호가 카메라 시각에 어떻게 찍히는지 없음 | 경로 ⓐ: PWM 핀이 스캔 동안 프레임마다 펄스 → 카메라 외부 트리거. 프레임 = 펄스 번호 → 위치 y = y0 + v · k · T. 경로 ⓑ (대안): 게이트 LED를 카메라 시야에 넣어 카메라 시계로 엣지를 봄 |
| 4 | `SET_PRINT_STATS_INFO CURRENT_LAYER`가 슬라이서 값과 겹침 | 매크로에서 뺌. 슬라이서가 `CURRENT_LAYER={layer_num + 1}`을 이미 넣음 (테스트 G코드 ① 3205 · 115줄) |
| 5 | 식힌 재측정 매크로 없음 | `COOL_RESCAN`: 모터·베드 온도 유지, 노즐만 끔, 대기 시간 기록, cooled 표시, 같은 센서 거리에서 재스캔 |
| 6 | (새로 찾음) 계단 기준물을 재면 툴헤드가 더 높은 블록과 부딪힘 | 지금 Z보다 낮은 블록 중 가장 높은 것만 고름. 블록은 시편에서 멀어질수록 높게 배치 |

printer.cfg에 더할 부분:

```ini
# --- T14 draft v2 (LM-T14-2): per-layer laser scan, Sovol SV08 / Klipper ---
# NOT tested on hardware. Layer index starts at 0. ASCII comments only.
[respond]

[idle_timeout]
timeout: 3600            # keep motors on (belt Z gantry drops if released)

[output_pin cam_trig]
# free pin from Sovol Extra_PIN_definition.pdf; name below is a placeholder
pin: PLACEHOLDER_PIN
pwm: True
cycle_time: 0.008333     # 1/120 s -> one rising edge per camera frame
value: 0
shutdown_value: 0

[gcode_macro SCAN_LAYER]
description: Scan specimen + step gauge after a layer (draft v2)
variable_every_n: 1
variable_last_layer: -1
variable_sensor_dx: 0.0          # laser line minus nozzle, X (set after mounting)
variable_sensor_dy: 0.0          # laser line minus nozzle, Y
variable_scan_x: 175.0           # specimen scan line X (laser position)
variable_scan_y0: 155.0
variable_scan_len: 40.0
variable_scan_speed: 2.4
variable_lead_in: 5.0
variable_z_hop: 2.0
variable_retract: 0.8
variable_ref_every: 1
variable_ref_clear: 1.0          # nozzle must stay this far above a gauge top
variable_ref_heights: [0.2, 5.0, 10.0, 15.0, 20.0]
variable_ref_xs: [230.0, 255.0, 280.0, 305.0, 330.0]
variable_ref_y0: 165.0
variable_ref_len: 20.0
gcode:
  {% set v = printer["gcode_macro SCAN_LAYER"] %}
  {% set layer = params.LAYER|default(-1)|int %}
  {% set force = params.FORCE|default(0)|int %}
  {% set p = params.PASS|default(0)|int %}
  {% set thermal = params.THERMAL|default("in_process") %}
  {% set hop = params.ZHOP|default(v.z_hop)|float %}
  {% set r = 0.0 if thermal == "cooled" else v.retract %}
  {% set due = (layer % v.every_n == v.every_n - 1) or force == 1 %}
  {% set dup = layer == v.last_layer and thermal == "in_process" %}
  {% set z_scan = printer.gcode_move.gcode_position.z + hop %}
  {% set ns = namespace(i=-1) %}
  {% for h in v.ref_heights %}
    {% if h <= z_scan - v.ref_clear %}{% set ns.i = loop.index0 %}{% endif %}
  {% endfor %}
  {% if layer >= 0 and due and not dup %}
    {% if thermal == "in_process" %}
      SET_GCODE_VARIABLE MACRO=SCAN_LAYER VARIABLE=last_layer VALUE={layer}
    {% endif %}
    M118 SCAN layer={layer} pass={p} thermal={thermal} event=layer_change
    SAVE_GCODE_STATE NAME=scan_state
    M83
    {% if r > 0 %}
      G1 E-{r} F1800
    {% endif %}
    G91
    G1 Z{hop} F600
    G90
    _SCAN_LINE X={v.scan_x} Y0={v.scan_y0} LEN={v.scan_len} LAYER={layer} PASS={p} KIND=specimen
    {% if ns.i >= 0 and layer % v.ref_every == 0 %}
      _SCAN_LINE X={v.ref_xs[ns.i]} Y0={v.ref_y0} LEN={v.ref_len} LAYER={layer} PASS={p} KIND=step_gauge H={v.ref_heights[ns.i]}
    {% endif %}
    RESTORE_GCODE_STATE NAME=scan_state MOVE=1 MOVE_SPEED=100
    {% if r > 0 %}
      SAVE_GCODE_STATE NAME=unretract_state
      M83
      G1 E{r} F1800
      RESTORE_GCODE_STATE NAME=unretract_state
    {% endif %}
    M118 SCAN layer={layer} pass={p} event=resume
  {% endif %}

[gcode_macro _SCAN_LINE]
description: One constant-speed Y pass with frame trigger pulses (draft v2)
gcode:
  {% set v = printer["gcode_macro SCAN_LAYER"] %}
  {% set x = params.X|float - v.sensor_dx %}
  {% set y0 = params.Y0|float - v.sensor_dy %}
  {% set f = v.scan_speed * 60 %}
  {% set tag = "layer=" ~ params.LAYER ~ " pass=" ~ params.PASS ~ " kind=" ~ params.KIND ~ " h=" ~ params.H|default("-") %}
  G1 X{x} Y{y0 - v.lead_in} F6000
  M400
  M118 SCAN {tag} event=m400_done
  GET_POSITION
  G1 Y{y0} F{f}
  SET_PIN PIN=cam_trig VALUE=0.5
  M118 SCAN {tag} event=scan_start
  G1 Y{y0 + params.LEN|float} F{f}
  SET_PIN PIN=cam_trig VALUE=0
  M118 SCAN {tag} event=scan_end
  M400
  GET_POSITION

[gcode_macro COOL_RESCAN]
description: Hold motors and bed temp, wait, rescan last layer as cooled (D-06)
variable_wait_s: 1800
gcode:
  {% set layer = params.LAYER|int %}
  {% set w = params.WAIT_S|default(printer["gcode_macro COOL_RESCAN"].wait_s)|int %}
  {% set hop = printer["gcode_macro SCAN_LAYER"].z_hop %}
  {% set z0 = printer.gcode_move.gcode_position.z %}
  SET_IDLE_TIMEOUT TIMEOUT={w + 3600}
  M104 S0
  M106 S0
  G91
  G1 Z10 F600
  G90
  M118 SCAN layer={layer} event=cool_start wait_s={w}
  {% for i in range((w / 60)|int) %}
    G4 P60000
  {% endfor %}
  M118 SCAN layer={layer} event=cool_end wait_s={w}
  G1 Z{z0 + hop} F600
  SCAN_LAYER LAYER={layer} FORCE=1 PASS=1 THERMAL=cooled ZHOP=0
```

프레임 시각 경로 (C4):

| 경로 | 연결 | 프레임 ↔ 위치 | `frame.trigger_mode` | 위험 |
|---|---|---|---|---|
| ⓐ 프레임 트리거 (기본안) | 보드 PWM 핀 → 1.8 V 레벨 변환 → 카메라 외부 트리거 입력 (OV9281은 XVS 핀, 펄스 폭 ≥ 2 µs) [출처 50] | k번째 프레임 = k번째 펄스 → y_k = y0 + 2.4 mm/s × k × 1/120 s = y0 + 0.02 mm × k [계산]. 호스트·카메라 시계가 필요 없음. 펄스 수 = 프레임 수 (40 mm면 2,000장 [계산])로 빠짐 검사 | hw | ① SET_PIN이 이동 큐에 맞춰 바뀌는지 문서 없음 [추정] ② 소프트웨어 PWM 지터 [미상] ③ USB 카메라 보드 펌웨어가 트리거 모드를 지원 안 한다는 사용자 보고 [출처 50] |
| ⓑ 게이트 LED (대안) | 같은 핀을 펄스 대신 계속 켬 (VALUE 1) → 450 nm LED가 카메라 시야 구석에 켜짐 | 카메라 시계 (`frame.t_cam_ns`) 위에서 LED 켜짐·꺼짐 프레임을 찾아 시작·끝을 맞추고 그 사이를 등속 보간. 분해능 1프레임 = Y 20 µm [계산] | gate | LED 빛이 레이저 선 영상에 섞임 (ROI 밖에 둠), SET_PIN 시각 문제는 같음 |
| (참고) M118 시각 | 호스트가 G코드를 읽은 시각이라 실제 움직임보다 앞섬 | 이벤트 순서 확인에만 씀, 위치 계산에 안 씀 | - | - |

- 두 경로 모두 "SET_PIN이 앞 이동이 끝나는 순간에 바뀐다"는 가정이 핵심 [추정]. 13절 9단계에서 오실로스코프 (또는 LED 촬영)로 펄스 시작과 스텝 펄스 시작을 비교해 확인.
- 도움닫기·감속: 2.4 mm/s에서 가속 3,000 mm/s²면 가감속 거리 v²/2a ≈ 1 µm [계산]이라 무시. 도움닫기 5 mm (약 2.1 s)는 링잉이 가라앉을 시간 (MF-MEC-02).
- 층당 시간: 시편 45 mm ÷ 2.4 = 18.8 s, 기준물 25 mm ÷ 2.4 = 10.4 s, 이동 약 5 s [추정] → 약 34 s. 테스트 G코드 ① 16층 + 식힌 재스캔 ≈ 10분 + 대기, ② 64층 ≈ 37분 + 대기 [계산]. 기준물을 2층마다 재면 `ref_every: 2`.
- 메시 보정은 스캔 중에도 켜져 Z가 메시대로 움직임 (fade 기본 꺼짐 [출처 5]). 스캔 구간 메시 Z 보정은 `pos.mesh_dz_mm`로 남김 (MF-MEC-07).
- `namespace`는 Jinja2 2.10 이상 기능 [추정]. Sovol 포크의 Jinja 판이 낮으면 블록 고르기를 PC가 계산해 `SCAN_LAYER REF=<번호>`로 넘기게 바꿈.

슬라이서에 넣는 줄:

| 슬라이서 칸 | 넣는 줄 | 근거 |
|---|---|---|
| OrcaSlicer "Before layer change G-code" (`before_layer_change_gcode`), 기존 `;BEFORE_LAYER_CHANGE` 줄 뒤 | `SCAN_LAYER LAYER={layer_num - 1}` | 테스트 G코드 ①: 이 칸이 다음 층 `G1 Z` · `G10` 리트랙트보다 앞에서 돔 (305–323줄) |
| OrcaSlicer "Machine end G-code", `END_PRINT` 앞 | `SCAN_LAYER LAYER={total_layer_count - 1} FORCE=1` 다음 줄 `COOL_RESCAN LAYER={total_layer_count - 1}` | ① 98줄 `TOTAL_LAYER=16` = `[total_layer_count]` → 마지막 층 15 |
| PrusaSlicer "Before layer change G-code" (`before_layer_gcode`) | `SCAN_LAYER LAYER={layer_num - 1}` | `layer_num`은 Before layer · End 칸에서 쓸 수 있음 [출처 51] |
| PrusaSlicer "End G-code" 맨 앞 (Z 올림·주차보다 먼저) | 위 끝 G코드 두 줄과 같음 | `total_layer_count`는 모든 사용자 G코드에서 쓸 수 있음 [출처 51]. ②의 끝 G코드는 Z 올림으로 시작 (8182줄) |

- `layer_num`이 0부터라는 근거: 테스트 G코드 ①의 층 변경 칸 `CURRENT_LAYER={layer_num + 1}` (3205줄)이 첫 층에서 1을 냄 (115줄). "전" 칸은 다음 층 직전에 돌므로 방금 끝난 층 = `layer_num - 1` [추정, 같은 층 번호가 두 칸에 같다는 가정. 13절 9단계에서 대조].
- 끝 G코드의 `{total_layer_count - 1}` 산식: Orca가 `{layer_num + 1}` 식을 이미 처리하므로 같은 문법으로 봄 [추정].
- 테스트 G코드 ②는 Marlin (MK3S)이라 이 매크로를 그대로 못 씀. 모양만 쓰고 SV08 프로필로 다시 슬라이스 (1절).
- SV08 시작 매크로에 넣을 곳: `G28` → `QUAD_GANTRY_LEVEL` → `G28 Z` → `BED_MESH_CALIBRATE` 다음, 퍼지 선 전에 베드 기준 스캔 (`_SCAN_LINE X=<베드 빈 곳> Y0=… LEN=40 LAYER=-1 PASS=0 KIND=bed_bare`)과 필러게이지 스캔 (`KIND=feeler`). SV08 기본 시작 매크로 이름은 [미상]. 메시 프로필과 `printer.bed_mesh`를 이때 PC가 받아 `meta.bed_mesh_file`로 남김 [출처 2].
- `M84` (모터 끄기)는 끝 매크로 안에서 식힌 재측정 뒤에만. Orca 프로필이 펌웨어 리트랙트 (`G10`/`G11`)를 쓰면 `[firmware_retraction]`이 있어야 함 (①).
- 블록 배치: 블록은 시편 쪽에서 멀어질수록 높게 (0.2 → 20 mm) 한 줄로, 블록 사이 간격 25 mm [추정, 툴헤드 폭 확인 필요]. 툴헤드는 고른 블록보다 높은 블록 위로 지나가지 않음. 슬라이서 출력 영역 밖에 둬서 출력 이동과 겹치지 않게 함. 20 mm보다 높은 출력 (②는 22.25 mm)은 20 mm 블록 (스캔 높이 아래 약 4 mm)으로 덮이고, 28 mm를 넘으면 30 mm 블록 추가 [계산].
