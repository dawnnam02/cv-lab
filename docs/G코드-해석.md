# G코드 해석과 층별 정답 높이 지도 (1차)

> T4a 산출 문서 · 세부청사진: [세부청사진_T4a_G코드해석](운영/세부청사진_T4a_G코드해석.md) · 대조표: [결과_T4a_대조표](운영/결과_T4a_대조표.md)
> 작성 2026-10-27 기준모델 worker. 코드 `src/cvlab/gcode/`, 설정 `config/gcode.yaml`, 실행 `scripts/gcode_reference.py`, 시험 `tests/gcode/`.

## 0. 요약

- G코드 한 파일을 읽어 **선분 표**, **층 표**, **층별 정답 높이 지도** (RefStack) 셋을 만든다.
- 방언을 못 읽으면 멈춘다. 압출 사이의 모르는 명령, 주석 층과 압출 Z 층의 불일치, 나선·순차 출력은 모두 `GCodeError`.
- 정답 높이는 층 Z (flat, MF-GCD-01 기본 정의). 첫 층 눌림·비드 볼록은 넣지 않았다.
- 손 G코드 24개 (`_mimic` 7개), 기대값 78행으로 시험한다 (후속 G-1 뒤 27개 · 84행).
- GC12 (2026-10-27): 사용자가 고른 `voron24_test_box` (첫 파이프라인 시험)와 `caliper_pyramid` (판정 시험)를 `data/gcode_samples/_local/` (Git 밖)에 복사해 돌렸다. 둘 다 통과 (§6 끝) [계산].
- 후보 7개 탐색 실행 (읽기만): 1차에는 4개 통과, 2개가 `TIMELAPSE_TAKE_FRAME`에서 멈췄다. 후속 G-1 (위치 다시 정하기 규칙, §2) 뒤 6개 통과. `orca_calib_cube` (중간 층이 잘린 파일)는 층 누락으로 멈춤 [계산].
- 후속 G-2로 정답 지도 만들기가 빨라졌다 (voron24 34.0 s → 1.5 s, 결과는 옛 방식과 비트 단위로 같음, §5 · §6) [계산].

## 1. 입력과 방언

**방언 → 명세 `meta.gcode_flavor` 옮김 표**

| 머리말 원문 (예) | 옮긴 값 | 근거 |
|---|---|---|
| `; gcode_flavor = marlin` · `marlin2` · `marlinlegacy` · Cura `;FLAVOR:Marlin` | `marlin` | 이름이 marlin으로 시작 |
| `; gcode_flavor = klipper` | `klipper` | 같은 이름 |
| `reprap` · `reprapfirmware` · `rrf` | `reprap` | 이름이 reprap으로 시작 |
| `Griffin` · `UltiGCode` · `smoothie` · `sailfish` 등 | `other` | 위 셋에 들지 않음 |
| 없음 | `None` + 경고 | GC6 |

**머리말에서 읽는 값**

| 값 | 키 (앞쪽 우선) | 슬라이서 |
|---|---|---|
| 슬라이서 이름·판 | `; generated by X v` · `;Generated with X v` · `; BambuStudio v` | Orca·Prusa · Cura · Bambu |
| 선언 층 수 | `total layers count` > `LAYER_COUNT` > `total layer number` | Orca (`total layer number`는 voron24에서 32로 틀림 [계산]) · Cura |
| 선언 필라멘트 길이 | `filament used [mm]` (쉼표 값 합) · `Filament used: x m` (×1000) | Orca·Prusa · Cura |
| 노즐·필라멘트 지름·층 높이 | `nozzle_diameter` · `filament_diameter` · `layer_height` (쉼표면 첫 값) | Orca·Prusa |
| 선폭 (종류별) | Orca `*_line_width`, Prusa `*_extrusion_width`. `%`·0은 None | Orca·Prusa (Cura는 머리말에 없음) |
| 첫 층 선폭 | `initial_layer_line_width` · `first_layer_extrusion_width` | Orca·Prusa |
| 윗면 층 수·채움 각 | `top_shell_layers`·`top_solid_layers` · `infill_direction`·`fill_angle` | Orca·Prusa |
| 파일 SHA-256 | 파일 바이트 | `parse_file` |

- 우선 방언은 Klipper · Marlin (프린터 1차 결과 Voron Trident + Klipper [출처: docs/프린터-펌웨어-선정.md, 확정 아님]).

## 2. 파서 규칙

**명령 목록 (코드 `parser.py` 한 곳)**

| 목록 | 명령 | 처리 |
|---|---|---|
| 움직임 | G0 · G1 · G2 · G3 · G28 · G92 · G10 · G11 | 선분 표에 반영 |
| 상태 | G90 · G91 · M82 · M83 · G20 · G21 · G17 | 뒤 줄 해석을 바꿈 |
| 움직임 없음 | G4 · M18 · M84 · M73 · M104–M109 · M117 · M118 · M140 · M141 · M190 · M191 · M201 · M203–M205 · M207 · M220 · M221 · M300 · M400 · M420 · M115 · M572 · M862.1 · M862.3 · M900 · M403, Klipper `SET_VELOCITY_LIMIT` · `SET_PRESSURE_ADVANCE` · `SET_PRINT_STATS_INFO` · `EXCLUDE_OBJECT_*` · `SET_FAN_SPEED` · `SET_HEATER_TEMPERATURE` · `TEMPERATURE_WAIT` · `RESPOND` · `SET_RETRACTION` | 건너뜀 |
| 시작·끝 구간만 | `START_PRINT` · `PRINT_START` · `END_PRINT` · `PRINT_END` · G80 · G29 · M702 · T<n> | 첫 압출 앞, 마지막 압출 뒤면 통과. 압출 사이면 위치 다시 정하기 규칙 (아래), 못 맞추면 오류 |
| 모름 | 위 밖 | 셈. G·M·T 꼴이면 엄격 모드에서 바로 오류. 매크로 꼴 (`MY_MACRO`)은 시작·끝 구간이면 경고 후 통과, 압출 사이면 위치 다시 정하기 규칙 (아래), 못 맞추면 오류 |

- 허용 목록 `allow_commands: [{name, reason}]`: 이유가 비면 설정 오류. 허용 명령은 "움직임 없음"으로 보고 `allowed`에 센다.
- "압출 사이"는 첫 압출 뒤에 나온 명령 다음에 다시 압출이 오는 경우다. 마지막 압출 뒤 명령 (`END_PRINT` 등)은 정답에 닿지 않아 경고만 남긴다. 세부청사진 GC3 문장 ("첫 압출 뒤 모르는 매크로는 오류")을 이렇게 좁혀 읽었다 [추정: 끝 매크로를 오류로 하면 Klipper 파일 전부가 멈춤].
- **위치 다시 정하기 (후속 G-1, 팀장검증_3차)**: 압출 사이에 매크로·시작·끝 구간 명령이 오면 그 속에서 머리가 어디로 갔는지 모른다고 본다. 그 뒤 다음 압출 전에 ① 절대 좌표 (G90) G0/G1로 X · Y · Z가 모두 한 번 이상 정해지고 ② E가 상대 모드 (M83, 또는 `g9x_sets_e: true`에서 G91)이거나 매크로 뒤 `G92 E`가 있으면, 위치와 E 기준을 아는 상태이므로 통과시키고 경고 (`줄 n: 압출 사이 명령 뒤 위치를 다시 정해 통과 (줄 m 매크로 이름)`)를 남긴다. 매크로 속을 믿지 않아도 되는 규칙이라 기본 허용 목록은 `[]` 그대로 둔다.
  - 세지 않는 것: 상대 좌표 (G91) 이동, `G92 X/Y/Z` (좌표를 바꿀 뿐 위치 확인이 아님), 매크로 앞의 `G92 E`, 압출하는 줄 자신의 X·Y·Z (그 선분의 시작점을 모름). 매크로 뒤 `G28`이 오면 그 축은 다시 정해야 한다. 매크로가 또 오면 처음부터 다시 센다.
  - G·M·T 꼴의 모르는 코드 (`M999` 등)는 이 규칙과 상관없이 지금처럼 바로 오류.
  - 후보 xyz_cube_10mm · benchy_helix는 층마다 `TIMELAPSE_TAKE_FRAME` → 압출 없는 `G3 Z… P1` (나선 Z홉) → `G1 X… Y… Z…` (절대) → `G1 E.8` (M83 상대 되밀기) → 압출 순서라 이 규칙으로 통과한다 [계산: 통과 경고 xyz 49개 · benchy 239개, 마지막 1개는 끝 구간]. 손 G코드 H25 (매크로 → 바로 압출, 오류) · H26 (매크로 → X · Y만, 오류) · H27 (M82 → 매크로 → M83 + X · Y · Z 절대, 통과 + 경고).

**모달 상태**

| 규칙 | 내용 |
|---|---|
| 처음 위치 | X·Y·Z 모름 (NaN), E = 0. `G28`도 지정 축 (없으면 전부)을 모름으로 만듦 |
| 위치 모르는 압출 | 첫 층 표시 앞이면 시작 퍼지선으로 보고 PRIME. 층 표시 뒤거나 파일에 층 표시가 없으면 오류 |
| G90/G91과 E | `g9x_sets_e: true` (Marlin): G90/G91이 E 모드도 바꿈, M82/M83이 다시 덮음. `false` (Klipper식): G91 동안 E는 상대, G90이면 M82/M83 따름. Klipper 동작은 `klippy/extras/gcode_move.py`의 `absolute_coord`·`absolute_extrude` 두 값으로 기억하나 이번에 공식 문서를 다시 열지 않음 [확인 필요] |
| G92 | 준 축만 바꿈. 축이 없으면 X·Y·Z·E 모두 0 |
| G20/G21 | X·Y·Z·E·I·J·R·F 모두 25.4배 |
| 원호 G2/G3 | XY 평면 (G17)만. I·J는 시작점 기준. R > 0 짧은 호, R < 0 긴 호. 끝점 = 시작점이면 한 바퀴. 현 개수 n = ⌈r·θ / arc_seg_mm⌉, 마지막 점은 끝점 그대로. 반지름 차 > 0.05 mm면 오류, > 0.005 mm면 경고. Z·E는 현마다 고르게 나눔 |
| 원호 P (바퀴 수) | 압출 없는 원호 (Orca 나선 Z홉)면 경고 후 한 바퀴로 펼침. 압출 있는 원호면 오류 |
| G10/G11 | 매개변수 없으면 펌웨어 리트랙트: 종류만 기록, ΔE 0. 매개변수가 있으면 (RRF 공구 설정 등) 오류 |
| 체크섬 | `*` 앞 모든 글자 XOR. 틀리면 그 줄을 쓰지 않고 셈, 경고 |
| 주석 | `;` 뒤, `( )` 안. 대소문자 무시, 공백 없는 단어 (`G1X10Y5E.3`), `\r\n` |
| 한 줄 두 명령 | 오류 (`G90 G1 X10`) |

**선분 종류 (MF-GCD-06)**

| 종류 | 조건 |
|---|---|
| extrude | XY 이동 + ΔE > 0. **정답 경로는 이것만** |
| travel | XY 이동 + ΔE = 0 |
| wipe | XY 이동 + ΔE < 0 |
| retract · unretract | XY 이동 없음 + ΔE < 0 · > 0 (G10 · G11 포함) |
| zmove | Z만 바뀜 |

- 경로 종류 이름은 표준 이름 (WALL-OUTER · WALL-INNER · FILL · SKIN · SKIRT · BRIM · SUPPORT · PRIME-TOWER · IRONING · CUSTOM)으로 옮긴다. 모르는 이름은 대문자 그대로 두고 경고. `;TYPE` 없는 압출은 UNTYPED, 첫 층 표시 앞 압출은 PRIME.

**압출량 대조 (GC7)**

- ΣΔE = 층 줄 범위 안 모든 선분의 ΔE 합 (압출 + 리트랙트·되밀기·와이프가 서로 상쇄된 순 사용량). 시작 퍼지선 (PRIME)과 마지막 압출 뒤 끝 G코드의 ΔE는 뺀다.
- 이 정의로 후보 6개의 선언값 차가 모두 0.002 % 안이다 [계산, §6]. 파일 전체 ΔE 합으로 하면 simple_cura는 +7.9 % (퍼지 E30 포함), caliper_pyramid는 +8.2 %로 어긋났다 [계산].
- 선언값이 없으면 `filament_diff_pct = None` ([미상]).

## 3. 층 정하기

| 항목 | 규칙 |
|---|---|
| ① 주석 기준 | 층 표시 `;LAYER_CHANGE` (Prusa·Orca) · `;LAYER:n` (Cura) · `; CHANGE_LAYER` (Bambu). 표시 뒤 5줄 안의 `;Z:` · `; Z_HEIGHT:`를 그 표시의 주석 Z로 |
| 압출 없는 표시 | 층으로 세지 않고 경고 (voron24 표시 32개 → 층 16) |
| 첫 표시 앞 압출 | PRIME, 층 −1, 두 방법 모두에서 뺌 (simple_cura · caliper 퍼지선) |
| ② 압출 Z 기준 | 압출 선분 Z를 오름차순으로 묶음 (차 ≤ 0.0001 mm면 같은 층) |
| 대조 (`both`) | 층 수, 층마다 Z, 주석 Z와 압출 Z 차 ≤ 0.0001 mm 모두 맞아야 통과 |
| 표시가 없는 파일 | ②만 쓰고 경고 |
| 오류 | 한 선분 안 Z 변화 (나선) · 한 층 표시 안 압출 Z 둘 이상 · 압출 Z가 내려감 (순차 출력) · 층 수나 Z 불일치 |
| Z hop · 나선 Z홉 | 압출이 없어 층을 늘리지 않음 |
| 층 번호 | 압출 있는 층만 0부터 |

**줄 범위 (명세 `meta.gcode_line_start` · `meta.gcode_line_end`)**

| 경우 | 시작 | 끝 |
|---|---|---|
| 주석 있음 | 앞 층 마지막 압출 뒤 첫 층 표시 줄 (겹친 표시면 묶음의 첫 줄) | 다음 층 시작 − 1, 마지막 층은 마지막 압출 줄 |
| 주석 없음 | 층 0: 첫 압출 앞 마지막 Z 이동 줄. 층 n: 층 n−1 마지막 압출 줄 + 1 | 같음 |

- 압출이 아닌 선분도 줄 범위로 층 번호를 붙인다. 범위 밖 (시작·끝 G코드)은 −1.
- 층 표 열: `layer_idx, layer_z_mm, layer_h_mm, gcode_line_start, gcode_line_end, n_extrude (압출 G코드 줄 수, 원호는 한 줄 = 1), extrude_len_mm, sum_de_mm (그 층 압출 ΔE), types`. `layer_h_mm`은 첫 층이면 첫 층 Z (첫 층 두께, MF-GCD-03).

## 4. 비드 모델과 정답 높이 정의

| 항목 | 정의 |
|---|---|
| 단면 | 사각형 + 양 끝 반원: A = (w − h)·h + π·h²/4, w ≥ h. `bead_area(0.42, 0.2)` = 0.0754159 mm² [계산] |
| 역산 | `width_from_area(A, h)` = (A − π h²/4)/h + h. 시험 값 4쌍에서 1e-9 안 [계산] |
| 실효 선폭 w_eff | A_e = ΔE·π(d_f/2)²/L, w_eff = `width_from_area(A_e, 층 높이)`. L < 0.5 mm 선분은 뺌 (G2 결정) |
| **정답 높이 (기본, flat)** | **층 Z = 노즐 끝 Z = 비드 윗면** (MF-GCD-01). 설정 `height_model`은 `flat`만 받음 |
| 대안 (민감도용) | `bead_profile_height(d, w, h, z)`: 평평한 가운데는 z, 양 끝 반원은 z − h/2 + √((h/2)² − t²). 정답 지도에는 쓰지 않음 |
| 첫 층 눌림 | 넣지 않음. 첫 층 두께는 층 표 `layer_h_mm` 0번에 따로 있음 |

## 5. 층별 정답 높이 지도

| 항목 | 규칙 |
|---|---|
| 격자 | {G} mm, `A[iy, ix]`, 칸 중심 x = x0_mm + ix·res_mm, x0_mm·y0_mm은 res_mm 정수배로 내림. 격자 JSON `{"frame": "G", "x0_mm", "y0_mm", "res_mm", "nx", "ny"}`. 기본 res 0.02 mm |
| 범위 | 층에 든 압출 선분 끝점의 경계 상자 ± 1 mm (PRIME 빠짐. 퍼지선이 들어가면 베드 전체가 격자가 됨) |
| 선폭 | 첫 층이면 첫 층 선폭 → 종류별 → 기본 선폭 (머리말) → `config line_width_mm`. 모두 없으면 오류. `width_model: extrusion`이면 w_eff 우선 |
| 발자국 | 압출 선분에서 칸 중심까지 거리 ≤ w/2 + 1e-9 mm (캡슐) |
| 계산 방식 (후속 G-2) | 기본 `method="band"` (`capsule_cells`): 선분 경계 상자 안에서 행마다 캡슐이 닿을 수 있는 x 범위 (반지름 + 2칸, 앞뒤 1칸 여유)만 거리 계산. 칸 좌표·t·거리 식은 1차 판 `capsule_window`와 같아 결과가 비트 단위로 같다. 1차 판은 `method="window"`로 남겨 대조 시험에 쓴다 |
| 꼭대기 층 | L_n(x, y) = max{k ≤ n : 발자국_k ∋ (x, y)}, 없으면 −1 |
| 높이 | Z_ref = z[L_n], 없으면 NaN |
| 경로 종류 | 같은 층에서 FILL → SKIN → WALL-INNER → WALL-OUTER → 그 밖 순으로 그려 뒤가 이김. `type_at(n)`은 `type_names` 번호, 없으면 −1 |
| 뺄 것 | 없음. 스커트·브림·서포트·아이롱도 넣음 (판정 제외는 G4 · T4b) |
| 저장 | `npz`: 격자 JSON, 층 Z, 층마다 `np.packbits` 발자국, 발자국 칸의 종류 번호. `RefStack.load` 뒤 발자국·높이·종류 배열이 모두 같음 |
| 그림 | `imshow(origin="lower", extent=격자 가장자리)` |

## 8. T4b에 넘길 것

- **판정 영역 (G4)**: 지도에는 스커트·브림·서포트·아이롱·PRIME-TOWER가 모두 들어 있다. `type_at(n)` 과 `type_names`로 빼면 된다. PRIME (퍼지선)은 지도에서 이미 빠져 있다.
- **PRIME 선분**: 퍼지선은 선분 표 `segments`에 종류 PRIME · 층 −1로 남아 있다. G4가 "출력물은 있으나 판정 밖"으로 쓸 수 있다.
- **판정 칸 경계와 격자 원점**: 판정 칸 경계는 정답 격자 원점 (압출 경계 상자 − 1 mm를 0.02 mm 배수로 내림)을 따른다. 한 출력 안에서는 일정하지만 출력마다 0.2 · 0.4 mm 칸 위치가 다르다. 원점을 0.4 mm 배수로 맞출지는 T4b · T10이 정한다.
- **격자 간격이 두 곳**: `config/default.yaml`의 `grid.res_mm`와 `config/gcode.yaml`의 `grid_res_mm`가 따로 있다 (지금은 둘 다 0.02). T10 통합 때 하나로 묶는다.
- **압출 사이 매크로**: `TIMELAPSE_TAKE_FRAME`는 허용 목록에 넣지 않고 위치 다시 정하기 규칙 (§2)으로 통과시킨다. 사용자 G코드에서 매크로 뒤 위치를 다시 정하지 않는 꼴이 나오면 멈추므로, 그때 허용 목록에 이유를 달아 넣을지 정한다.
- **caliper_pyramid 쓸 때 주의 (판정 시험 파일)**:
  - 홈 깊이가 심도를 넘는다. 블록 안 홈 바닥 6.85 mm ↔ 꼭대기 22.25 mm = 15.4 mm로 레이저 심도 약 8 mm의 두 배 가까이. 층 23 (Z ≈ 8.25)부터 41개 층에서 윗면 높이차 > 8 mm [계산, §6]. 이 칸들은 "측정 못 함"으로 판정에서 빼거나, 높이를 나눠 스캔해야 한다 (T4b · T5).
  - 노즐 0.6 mm 프로필이다 (압출 폭 0.65, 외벽 0.68, 층 0.35). 0.4 mm 노즐 Trident에서 그대로 출력하면 선폭·층 높이가 정답과 다르다.
  - Marlin 방언이다 (`M862.x` 기종 확인 · `G80` 메시 · `M900` · `M702`, `G90`이 E 모드도 바꾼다는 경고). 원점도 Prusa MK3S 베드 기준.
  - 그래서 Voron (Klipper, 0.4 노즐)용으로 원본 모델 (`caliper pyramid.scad` · `main part.stl` · `insert.stl`)을 다시 슬라이스해야 할 수 있다. **슬라이서 실행은 금지라 이번에는 메모만 남긴다.** 다시 슬라이스하면 새 파일로 GC12를 다시 돌리고 MANIFEST에 행을 더한다 [출처: docs/테스트-G코드-후보.md §5].
- **측정 격자 정렬**: 정답 격자는 {G} 0.02 mm. 측정 지도와 맞추는 변환 (원점이 가운데인 베드 포함, xyz·benchy는 −110~110)은 T4b · T10.
- **선폭 모델**: `width_model: extrusion`이면 E 반올림 때문에 w_eff가 0.419995처럼 조금 작아져, 선폭 간격 채움 사이 정확히 가운데 칸 줄이 빈다 (§9). 판정 칸 (0.2 mm)으로 묶을 때 영향을 볼 것.

## 9. 한계

- **속도**: 정답 지도는 후속 G-2로 voron24 1.5 s, voron_design_cube (150층) 18.4 s [계산]. 선분마다 파이썬 반복이 남아 있어 선분 수에 비례한다. `height_at_layer(n)`도 층 0–n 발자국을 매번 다시 푼다 (voron24 모든 층 1.6 s, 팀장 측정). 층이 많은 사용자 G코드면 누적 저장을 검토한다.
- **층 표시 없는 파일의 퍼지선**: PRIME은 첫 층 표시 앞 압출로 가른다. 층 표시가 없는 파일에서는 퍼지선이 첫 층과 같은 Z면 층 0에 섞여 격자가 넓어지고 판정 영역에 들어간다. 첫 층보다 높은 Z면 "압출 Z가 내려감" 오류로 멈춘다 [계산: 지어낸 조각으로 확인].
- **선폭 경계**: 캡슐 경계를 닫힌 경계 (≤ w/2 + 1e-9)로 둬 선폭 간격 채움은 빈칸이 없지만, w가 아주 조금만 작아도 (w_eff) 가운데 줄이 빈다.
- **Klipper G90/G91과 E**: 기본값은 Marlin식 (`g9x_sets_e: true`). 후보 Klipper 파일 4개는 `G90` 뒤 `M83`이라 두 동작의 결과가 같다 [계산: 경고 없음]. simple_cura (Marlin)는 끝 G코드의 `G91`에서 E 모드가 바뀐다는 경고가 나왔고 층 밖이라 정답에는 영향 없다.
- **원호 P**: 압출 없는 원호에서만 받고 한 바퀴로 펼친다. Marlin의 P 뜻 (더 도는 바퀴 수)은 이번에 확인하지 않았다 [확인 필요].
- **시작 구간 위치**: 시작 매크로 (`PRINT_START` 등) 안의 움직임은 모른다. 뒤따르는 절대 이동으로 위치를 다시 얻는다고 본다. 상대 이동 (G91)만 이어지면 위치를 모르는 채로 압출이 되어 오류로 멈춘다.
- **고른 후보는 남의 출력 파일**: GC12 두 파일은 라이선스 [미상]이라 `_local/` (Git 밖)에만 있다. 다른 사람이 클론하면 GC12 시험은 skip되고, MANIFEST의 지문과 출처 URL로 같은 파일을 받아야 다시 돌릴 수 있다. 사용자 프린터에서 만든 G코드는 아직 없다.
- **G1–G4 요소 청사진에 바꿀 점 (고치지 않음, 목록만)**: ① G1 `TYPE_ALIASES`에 Orca 이름 (`Outer wall`, `Inner wall`, `Overhang wall`, `Sparse infill`, `Gap infill`, `Internal Bridge`, `Bridge`, `Bottom surface`) 추가 ② G1 압출량 대조에 "층 범위 안 순 ΔE" 정의 (퍼지선·끝 G코드 제외) ③ G1 선언 층 수는 `total layers count`를 `total layer number`보다 앞세움 ④ G3 격자 범위에서 PRIME 제외를 명시.
