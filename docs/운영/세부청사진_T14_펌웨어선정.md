## 1. 목적

사용자는 아직 프린터가 없습니다. 층마다 레이저로 윗면 절대 높이를 재는 이 워크플로우에 가장 잘 맞는 **프린터 기종과 펌웨어 조합**을 고릅니다.
"완벽한 걸로"라는 지시에 따라 가격보다 측정 적합성을 앞에 둡니다. 다만 본체 예산을 아직 묻지 않았으므로 가격대 3개마다 추천을 하나씩 내고, 그중 최종 1순위를 고릅니다.
고른 조합이 실제로 내는 위치·시각 정보와 기구 특성 (Z 구동, 베드 움직임)이 T1 명세의 허용 값과 T3 시뮬레이터 모델이 됩니다.
구입·설치·플래싱은 하지 않습니다 (가상 단계 비범위). 실측 전환 때 쓸 절차만 적어 둡니다.

## 5. 판정 기준

칸에는 "가능·부분·불가·미상" 중 하나 + 한 줄 설명 + 근거 태그 (`[출처 n]` · `[계산]` · `[추정]` · `[미상]`)를 씁니다. 예: `가능. Klipper 기본 탑재, printer.cfg 공개 [출처 12]`.

### 5.5 G코드 헤더 추정 규칙 (팀장 초안, worker가 확인 후 사용)

사용자 G코드는 어느 프린터 프로필로 슬라이스했는지 알려 줍니다. 최종 1순위와 다르면 정답 데이터 (G코드)를 그 기종으로 다시 슬라이스해야 하므로 T4·T5에 알립니다. 아래 단서는 **확인 전**입니다. worker가 슬라이서 문서로 확인한 것만 1절 근거로 씁니다.

| 단서 (G코드 안) | 가리키는 것 | 주의 |
|---|---|---|
| 끝부분 설정 블록의 `; gcode_flavor = …` (PrusaSlicer · OrcaSlicer 계열) | 슬라이서에 설정한 방언 | 실제 펌웨어와 다를 수 있음 |
| 머리말 `;FLAVOR:…` (Cura 계열) | 같음 | Klipper 프린터에도 Marlin 방언을 흔히 씀 |
| `; generated by …` · `printer_model` · `printer_settings_id` | 슬라이서 이름·판, 프린터 프로필 | 기종 추정의 출발점 |
| 대문자 매크로 호출 (`PRINT_START` · `START_PRINT`), `EXCLUDE_OBJECT_DEFINE`, `SET_PRINT_STATS_INFO` | Klipper 프로필 가능성 | 매크로 이름은 사용자 정의 |
| `M98 P"…"` 매크로 호출, RRF식 도구 온도 `G10 P… S…` | RepRapFirmware 프로필 가능성 | |

| 제조사 전용 슬라이서 표기 (예: Bambu Studio) | 제조사 전용 프로필 | |
