## 시작 확인 (2026-10-27)

- 사용자 지시 원문: "테스트할 만한 G코드를 몇 개 받아와서 보고하면, 내가 보고 어떤 G코드로 테스트를 돌릴지 결정할게."
- 손대지 않는 곳: `src/cvlab/gcode/` · `data/gcode_samples/` · `scripts/` · `tests/` · git 쓰기
- 웹 조사 상한: 검색·본문 합쳐 40회

| 번호 | 목표 (완료 기준) |
|---|---|
| G1 | 실제 .gcode 후보 5~8개 내려받기. STL만 있는 것은 "슬라이스 필요" 목록 2~3개 |
| G2 | 후보마다 출처 URL·라이선스. 확인 못 하면 [미상] |
| G3 | 다양성: 단차 시편 · 평평한 블록 · 곡면·경사 형상 · Klipper/Voron 계열 1개 이상 · Marlin 계열 1개 이상 |
| G4 | 파일마다 직접 파싱한 값 표 (슬라이서·버전·프로필, 방언 단서, 층 높이·층 수·최대 Z, XY 범위, 노즐·압출 폭, 재료, 층 표시 방식, 상대/절대 E, 파일 크기, 예상 시간) |
| G5 | 측정 적합성: 시야 20 mm·스캔 40 mm 분할 수, 평평한 윗면 비율, 8 mm 초과, 층 수 × 17초, 판정 시험 적합도 |
| G6 | 추천 1~3위와 이유 한 줄씩 (결정은 사용자) |
