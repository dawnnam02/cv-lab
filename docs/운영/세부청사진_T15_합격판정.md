## 1. 목적

차이 지도 Δ와 허용 오차 T, 확장불확도 U를 받아 출력물 하나를 **합격 · 불합격 · 보류 · 측정 불충분**으로 판정하는 규칙을 글과 코드로 고정합니다.

- 규칙은 본인 확정 D-05 (T = 0.2 mm), D-06 (측정 당시 높이, 마지막 층 식힌 재측정은 보고만), D-07 (가드밴드 방식 B), D-08 (전체 층 합산 95 %)을 그대로 따릅니다. 바꾸지 않습니다.
- 청사진이 "T15에서 정함"이라고 남긴 것 (판정 칸 크기, 유효 칸 기준, 측정 불충분 문턱, 식었다고 보는 기준)은 **안 + 근거**로 내고, 본인 결정이 필요한 것은 §14 결정 요청에 올립니다. → 문서 §14의 R1–R7은 **10-27 본인이 기본안대로 확정 (D-20)** 했습니다 (§6.13).
- 경계에서 한 칸이라도 틀리면 불량을 합격으로 내보낼 수 있습니다 (MF-JDG-01, S5). 그래서 경계 사례를 손계산으로 맞춘 단위 시험이 이 작업의 중심입니다.

## 2. 목표 (완료 기준)

| 번호 | 완료 기준 | 측정 방법 |
|---|---|---|
| JD1 | **Δ 정의.** Δ = Z_meas − Z_ref, {G} Z (베드 면 = 0), 내부 단위 mm, 보고 단위 µm, + = 실측이 높음 (재료 과다, A1 · H5 부호). 측정 당시 판정이라 열 수축 기울기는 U가 아니라 Δ에 들어간다는 점 (청사진 §1.2, **D-15 확정**)을 적음 | 문서 §2 · 명령 ④ |
| JD2 | **판정 칸.** 기본 0.2 mm, 0.4 mm 판정을 함께 보고 (MF-JDG-04, **D-20 R1 확정**). 0.02 mm 격자 → 판정 칸 묶기 함수 `aggregate_to_cells` (§6.3 규칙). 칸 크기 ÷ 격자 간격이 정수가 아니면 오류 | 시험 · 명령 ① |
| JD3 | **판정 영역 인터페이스 (G4와 맞출 자리만).** 층마다 판정 칸 격자 위 bool 배열 `region` + 선택 `exclusion_code` (int8, §6.4 코드표). 영역 밖 값은 세지 않음. 뺀 이유별 칸 수를 결과에 넣음. G4 마스크 자체는 만들지 않음 (T4b) | 시험 · 문서 §4 |
| JD4 | **점 분류 (방식 B, D-07).** 합격점 \|Δ\| ≤ T − U, 불합격점 \|Δ\| > T + U, 그 사이 보류점. 비교는 1 nm 단위로 반올림한 정수로 함 (§6.5). U는 반드시 인자로 받고 출처 문자열 `U_source`도 받음. U < 0, U ≥ T, U가 NaN이면 오류. U = 0이면 방식 A와 같은 결과 | 시험 · 명령 ② |
| JD5 | **출력물 판정 (D-08).** 전체 층의 유효 칸을 합쳐 셈 (층별 비율의 평균이 아님). 측정 불충분을 먼저 보고, 그다음 합격점 ≥ 95 % → 합격, 불합격점 > 5 % → 불합격, 그 밖 보류. 비율 비교는 정수 곱셈으로 (§6.5) | 시험 · 명령 ② |
| JD6 | **유효 칸과 측정 불충분.** 유효 칸 = 판정 영역 안 + Δ 있음. 유효 칸 < 판정 영역 칸의 90 % (**D-20 R2 확정**)면 측정 불충분. 판정 영역이 비면 측정 불충분 | 시험 · 명령 ② |
| JD7 | **열 상태 (D-06).** 판정에는 `thermal_state = in_process`만 받음. `cooled`를 판정에 넣으면 오류 (MF-JDG-05). 식힌 재측정은 `post` 인자로 따로 받아 마지막 층과의 차이 (n, 평균, 중앙값, p05, p95, 최대 \|·\|, µm)만 보고. `post`가 있든 없든 판정은 같음. "식었다"고 보는 기준을 §6.7 식으로 냄 (**D-20 R4 · R5 확정: 경고만**) | 시험 · 문서 §8 |
| JD8 | **층별 보고와 경고 (MF-JDG-06).** 층마다 칸 수·합격·보류·불합격 비율. 한 층 불합격 비율 > 50 % (T2 예시 값, **D-20 R7 확정**)면 경고. 같은 `layer_idx`가 두 번 들어오면 오류 (패스 합치기는 앞 단계 몫) | 시험 |
| JD9 | **참고 판정.** 방식 A (\|Δ\| ≤ T 비율, 95 % 규칙)를 함께 냄 (청사진 §2.3). 이상치 마스크 `outlier`가 있으면 제외 전·후 두 판정을 모두 내고, 다르면 경고. 주 판정은 둘 중 덜 유리한 것 (§6.6, **D-20 R3 확정**) | 시험 |
| JD10 | **보고 수치.** H5 대표 지표 (평균, 표준편차 n−1, RMS, P95 \|Δ\|, 최대 \|Δ\|, \|Δ\| ≤ T 비율)를 전체·층별로. `JudgeResult.to_dict()`가 JSON으로 저장되고 T · U · `U_source` · 칸 크기 · 문턱 값 전부와 해석 주의 문장 (청사진 §2.2)을 담음 | 시험 · 문서 §10 |

**공개 이름 (이 이름은 바꾸지 않음, 검증 명령이 씀).**

```python
classify_cells(delta_mm, T_mm, U_mm) -> np.ndarray[int8]   # 1 합격점, 0 보류점, -1 불합격점, -9 값 없음(NaN)
aggregate_to_cells(delta_fine_mm, valid_fine, region_fine, factor, stat="mean", fill_min=0.5, region_fill_min=1.0)
    -> (delta_cell_mm, valid_cell, region_cell)
LayerInput(layer_idx, thermal_state, delta_mm, region, outlier=None, exclusion_code=None)
JudgeParams(T_mm=0.20, U_mm=None, U_source=None, pass_min_pct=95, fail_max_pct=5, valid_min_pct=90,
            cell_mm=0.2, layer_fail_warn_pct=50, ...)
judge_print(layers, params, post=None) -> JudgeResult
    # .verdict ∈ {"pass","fail","hold","insufficient"}  .counts {n_region,n_valid,n_pass,n_hold,n_fail}
    # .pct  .per_layer  .method_a  .outlier_variants  .cooled  .metrics  .warnings  .params  .to_dict()
score_c12(pred, true) -> dict   # confusion, false_pass, false_fail_rate, hold_rate, insufficient_rate,
                                # c12_required_ok, c12_target_ok
```

## 6. 설계 규칙

### 6.1 격자 약속 (T4a와 같은 글)

| 항목 | 약속 |
|---|---|
| 좌표 | {G}, mm. 높이는 {G} Z, 베드 면 = 0 |
| 배열 순서 | `A[iy, ix]` (G3 · C4) |
| 칸 중심 | x = x0_mm + ix·res_mm, y = y0_mm + iy·res_mm. x0_mm · y0_mm은 res_mm의 정수배 |
| 격자 JSON | `{"frame": "G", "x0_mm": …, "y0_mm": …, "res_mm": …, "nx": …, "ny": …}` |
| 값 없음 | float 배열은 NaN, 마스크는 bool |
| 고운 격자 | res_mm = 0.02 (G3 결정). 정답 지도 (T4a)와 실측 지도 (T9)가 이 격자 |

### 6.2 판정 칸

- 판정 칸 한 변 = factor × res_mm. factor는 정수 (0.2 ÷ 0.02 = 10). 아니면 오류.
- 판정 칸 (jy, jx)는 고운 칸 iy ∈ [jy·f, (jy+1)·f), ix ∈ [jx·f, (jx+1)·f)를 묶습니다. 가장자리에서 f칸이 안 차는 묶음은 판정 영역 밖으로 둡니다.
- 판정 칸 중심 = x0_mm + (jx·f + (f − 1)/2)·res_mm.

### 6.3 묶기 규칙 (D-20 R6 확정, 문서에 근거와 함께)

| 규칙 | 기본 | 근거 |
|---|---|---|
| 영역 칸 | 묶음 안 고운 칸 중 판정 영역 비율 ≥ `region_fill_min` (기본 1.0, 전부) | 엣지가 섞인 칸을 판정에 넣지 않음 (MF-JDG-03) |
| 유효 칸 | 영역 칸 중 Δ 있는 고운 칸 비율 ≥ `fill_min` (기본 0.5) | 한두 점으로 칸 값을 정하지 않음 [추정] |
| 칸 값 | 유효한 고운 칸 Δ의 평균 (`stat="mean"`, 선택 `median`) | 평균은 결함을 숨기지 않음. 중앙값은 비교용 |

### 6.4 판정 영역 인터페이스 (G4 · T4b가 채울 자리)

| 입력 | 형 | 뜻 |
|---|---|---|
| `region` | bool, 판정 칸 격자 | True = 판정에 넣는 칸 |
| `exclusion_code` (선택) | int8, 같은 모양 | 0 영역 안 · 1 엣지 띠 · 2 가림 예측 · 3 시야 밖 · 4 제외 경로 종류 (스커트·브림·서포트) · 5 출력물 없음 · 9 기타 |

- T15는 `region`만으로 판정합니다. `exclusion_code`는 뺀 이유별 칸 수를 결과에 적는 데만 씁니다 (MF-JDG-03 "뺀 자리 지도").
- 코드표는 T4b가 G4를 만들 때 그대로 씁니다. 바꾸려면 팀장에게 먼저 묻습니다.

### 6.5 경계와 비율의 정수 비교

| 비교 | 방법 |
|---|---|
| 점 분류 | q = rint(\|Δ\|·10⁶) (nm 정수), t_pass = rint((T − U)·10⁶), t_fail = rint((T + U)·10⁶). 합격점 q ≤ t_pass, 불합격점 q > t_fail |
| 합격 | n_pass·100 ≥ pass_min_pct·n_valid |
| 불합격 | n_fail·100 > fail_max_pct·n_valid |
| 측정 불충분 | n_valid·100 < valid_min_pct·n_region, 또는 n_region = 0 |

- 실수로 빼고 더하면 끝자리가 어긋나는 경우가 있습니다. 예: `0.2 - 0.171` = 0.028999999999999998, `0.2 + 0.141` = 0.34099999999999997. 이러면 경계 바로 위의 \|Δ\|가 어느 쪽에 들어갈지 실수 표현에 달립니다. 1 nm 정수로 비교하면 이 문제가 없고, 1 nm는 U보다 4자리 이상 작아 판정 뜻을 바꾸지 않습니다.
  - (3차 검증 정정) 처음 쓴 예 "0.2 − 0.03 = 0.17000000000000001"은 틀렸습니다. Python에서 `0.2 - 0.03 == 0.17`은 참입니다. 위 예는 worker가 바꾼 것으로, 실제로 어긋나는 예입니다.
- 합격 조건 (≥ 95 %)과 불합격 조건 (> 5 %)은 동시에 참일 수 없습니다 (합격점 ≥ 95 %면 불합격점 ≤ 5 %). 시험으로 확인합니다.
- **문턱 검사 (J-1).** `decide`는 합격을 불합격보다 먼저 보므로, 문턱을 바꿔 합이 100보다 작아지면 (예: 90 · 5) 불합격점 8 %인 출력이 합격으로 나옵니다. 그래서 `JudgeParams`는 `pass_min_pct + fail_max_pct < 100`이면 설정을 읽을 때 ValueError로 멈춥니다 (생성자 · `from_dict` · yaml 모두). 합이 100 이상이면 n_pass + n_fail ≤ n_valid라서 둘이 함께 참일 수 없습니다.

### 6.6 이상치 전후 (MF-JDG-03, D-20 R3 확정)

- `outlier` 마스크가 없으면 판정 하나.
- 있으면 ① 제외 전 (이상치 칸도 유효, 값 그대로) ② 제외 후 (이상치 칸은 무효)를 둘 다 냅니다.
- 다르면 경고 "이상치 처리에 따라 판정이 바뀜". 주 판정은 덜 유리한 쪽입니다. 순서: 합격 < 보류 < 측정 불충분 < 불합격. 불량을 합격으로 내보내지 않는 방식 B의 뜻을 따른 것으로, 10-27 본인이 확정했습니다 (D-20 R3).

### 6.7 식힌 재측정과 "식었다" 기준 (D-06)

- 차이 = Δ_post − Δ_last (같은 정답 지도이므로 실측 높이 차와 같음). 음수면 식으면서 낮아진 것.
- 둘 다 유효한 칸만 셉니다. 공통 칸이 없으면 차이는 None + 경고.
- "식었다" 기준 (T1 명세 14절 15번이 T15에 넘긴 것, **D-20 R4 확정**): 남은 수축 δ = α · H · ΔT가 δ_max 이하가 되는 온도 차 ΔT = 시편 윗면 온도 − 실내 온도.
  - ΔT_max = δ_max ÷ (α · H). α = 68 µm/(m·°C) (청사진 §1.2), H = 출력 높이 (G코드 최대 층 Z).
  - δ_max = 5 µm: T2 심각도 S2 (1–5 µm, 경고 수준)의 상한 [추정, 근거 T2 2절 표].
  - 예: H = 20 mm면 α · H = 1.36 µm/°C, ΔT_max = 5 ÷ 1.36 = 3.7 °C [계산].
  - 시간 기준 (`meta.cool_wait_s` 하한)은 열 모델이 없어 정하지 않습니다 ([미상]).
  - 시편 온도 센서가 없으면 "식힘 기준 판단 못 함" 경고만 내고 `meta.cool_wait_s`와 실내 온도를 보고서에 적습니다 (**D-20 R5 확정**).
- 기준은 판정을 바꾸지 않습니다. 기준을 못 넘으면 보고서에 "식힘 부족" 경고만 냅니다.
