## 5. 막힌 점 4건 결정

### 5.1 ① C2 (h1 ≤ 층 Z)와 교정값 충돌 → **(가) 채택, 공칭 검사를 덧붙임**

결정: 명세 4절 C2 · 두 단 규칙의 "h1 ≤ 층 Z"를 두 줄로 나눔.
1. **공칭 h1 ≤ 층 Z** (ID에서 읽는 공칭 높이, 같은 높이 허용) — 매크로가 출력보다 높은 단을 고르지 않았는지. D-16 조건 C2 ("출력보다 높은 계단 금지")를 글자 그대로 지킴.
2. **교정 h1 (`ref.gauge_height_mm`) ≤ 층 Z + 0.02 mm** — 교정 공차 몫. 0.02는 명세가 이미 쓰는 값 (필러 `abs(x − 공칭) ≤ 0.02`, 두 단 간격 상한 3.04 = 3.0 + 0.02 × 2)과 같음.
3. 두 단 비 경고 (W-REF-25): d = 층 Z − h1이 음수 (−0.02 이상)면 외삽이 아니므로 경고하지 않는다는 문장을 더함.

### 5.2 ② 같은 층 반복 (MSA) 꼴 → **(나) 채택: 반복 한 번 = 보통 스캔 하나, 폴더 · ID 끝에 `_qNN`**

결정 (명세 v1.2 초안, 이름은 T1이 고를 수 있으나 꼴은 이대로):
- 같은 줄을 같은 층에서 다시 재면 그 반복은 **따로 된 스캔 폴더** `L008_q01` … `L008_q04` (줄 1을 반복하면 `L008_p01_q01`). 스캔 ID `S01_r01_L008_q01`. 정규식 `^S\d{2}_r\d{2}(_L\d{3})?(_p\d{2})?(_q\d{2})?$` (`meta.scan_id` · `rep.scan_id`, 층 폴더). `_q`는 timing = layer만.
- `pos.pass_idx` = 그 스캔이 몇 번째 반복인지 (`_q` 숫자, 없으면 0). 스캔 안 모든 행이 같은 값. post는 0 그대로. LM-T14-3의 `PASS` 인자 (줄마다 모든 M118 행에 같은 값)와 뜻이 같아짐.
- 스캔 단위 규칙 (scan_start · scan_end 1개, Y 단조, 펄스 번호 0부터 · 위치 식, 게이트 한 덩어리, `scan_start_t_ns`)은 **하나도 안 바뀜.**
- 바뀌는 여러 스캔 규칙: `meta.scan_pass_idx` 연속 · "그 층 첫 줄 스캔" · `ref.scan_id` · `meta.paired_scan_id`는 `_q` 없는 스캔만 셈. 같은 Z 규칙 (X-REF-16)에는 `_q` 스캔도 넣음 (반복은 Z를 안 움직임). **판정 묶음에는 `_q` 없는 스캔만** (처리 · T10).
- 7절: design 행마다 실행 스캔이 따로 생김. `rep.repeat_idx` 1 = `_q` 없는 스캔, k ≥ 2 = `_q`(k − 1).

|---|---|---|---|
| (가) X-POS-04를 pass마다 | X-POS-04만 고치면 X-POS-09 · X-MET-12 · 펄스 위치 식 · 게이트 규칙이 남음. 프레임에 pass 칸이 없어 처리가 프레임을 pass로 나누려면 새 필드 (`frame.pass_idx`)가 필요할 수 있음 | 프레임 · 위치 로그 뜻 5–6곳 + 처리 쪽 프레임 나누기 | 버림 |
| **(나) 반복용 폴더 · ID** | 충족. 반복 스캔이 보통 스캔이라 스캔 단위 규칙 그대로 통과 | ID · 폴더 정규식 3곳, `pos.pass_idx` 뜻 한 줄, 여러 스캔 규칙 4곳 (첫 줄 선택 · 줄 번호 연속 · X-POS-12 · 판정 묶음), 필드 추가 0 | **채택** |

- 이유 요약: worker가 이미 반복을 "따로 된 줄 객체 (모든 행 pass k)"로 만들었으므로 (나)는 writer가 폴더만 나누면 됨. (가)는 한 스캔 안에 여러 등속 구간을 허용하느라 프레임 쪽 뜻까지 건드림.
- T14 매크로: `SCAN_LAYER`에 `REPEAT` 인자 (기본 0)를 더해 첫 줄 뒤 `_SCAN_LINE … PASS=k SPASS=0` (k = 1 … REPEAT)를 부르고, 호스트가 `PASS=k`를 `_qNN` 폴더로 적음. 지금 매크로는 같은 층 두 번째 호출을 `dup` 조건으로 막아 반복을 못 함. 기본 0이면 출력이 같으므로 판 표기 (LM-T14-3)는 그대로, T14 문서 변경 이력에 적음.
- 용량 정정: 반복은 첫 측정 (층 스캔)에 더해 4번이라 추가 프레임은 4 × 1,255 = 5,020장 (1.64 GB). §6.11은 5 × 1,255 (2.06 GB)로 적어 0.41 GB 많게 셈 → 합계 약 31.4 GB [계산].

## 6. 참 판정에 열 · Z축 몫을 넣음 (10-29 이미 정함, 사용자에게 알림) — 이유 기록

- 결정: 정상 캠페인 `truth.judgement`는 열 수축 · Z축 오차 · 프레임 드리프트를 넣은 참 형상으로 셈. 스위치 (`layer_thermal_field` · `z_axis_error` · `frame_drift`)로 끌 수 있고, SM2 (T5 기대 판정 61/61)는 끈 상태로 따로 봄.
- 이유:
  1. **명세 부록 A**: 참 출력 형상 = G코드 + 출력 오차 + 열 상태 (측정 당시).
  2. **D-06**: 판정은 측정 당시 높이로. **D-15**: 층별 열 수축 기울기는 U가 아니라 실제 형상 (Δ 쪽).
  3. Z축 오차는 출력물 실제 높이를 바꿈 (출력과 측정이 같은 Z라 측정이 못 보는 몫, MF-CAL-05). 참값에서 빼면 실제로 있지도 않은 형상을 정답으로 두게 됨.
  4. 빼면 C12 채점이 거꾸로 됨: 열 수축을 제대로 본 측정이 "틀림"으로 채점됨.
- 결과: caliper ZSC-B01 (경계 시나리오 B) fail → pass (시드 20261029). Z 배율 11,000 ppm이 높은 칸을 T 밖으로 미는 것을 측정 당시 열 수축 (20 mm에서 약 20 µm)이 반대로 깎아 T 밖 칸이 5 % 아래로 줄어듦. 다른 행 합격점 변화 최대 13.94 %p (ZSC 계열) [모델 문서 §1.4, 팀장 참고 실행 §1.1에서 재현].
- 따르는 규칙: C12 채점은 캠페인 참값 `truth.judgement`로 함 (T5 `기대판정.csv`는 SM2 대조용). 평가 세트 (G2 · M3 · M4)와 T12 스윕은 경계 행이 시드마다 뒤집힐 수 있으므로 기대 판정을 시나리오 표에서 가져오지 않음.
