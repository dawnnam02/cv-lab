## 후속 J-1 시작 확인 (2026-10-27)

- 기준: `docs/운영/팀장검증_3차.md` §2.3 허점 1, §7 J-1.
- 문제: `decide`는 합격을 불합격보다 먼저 본다. 문턱을 90 · 5로 바꾸면 합격점 92 % · 불합격점 8 %인 출력이 합격으로 나온다.
- 할 일: `JudgeParams`에서 `pass_min_pct + fail_max_pct < 100`이면 ValueError. 합이 100 이상이면 n_pass + n_fail ≤ n_valid라서 둘이 함께 참일 수 없다.
- 시험: 문제 사례 재현 (검사를 건너뛴 문턱으로 `decide`가 pass를 내는 것 확인) · 90 · 5 거부 (생성자 · yaml 덮어쓰기) · 합 100 경계 통과 · 기본값 동작 그대로.
- (선택) `check_U`가 `np.floating`을 받도록 + 시험 1개.
- 손대지 않는 것: D-05–D-08 값, `decide` 순서, 다른 작업 파일.
- 쓸 파일: `src/cvlab/judge/params.py`, `tests/judge/test_judge_params_scoring.py`, `config/judge.yaml` (주석), `docs/판정-규칙.md` §7, 이 대조표.
