## 1. 목적

하드웨어가 있었다면 나왔을 데이터를 **필드 하나하나까지** 정합니다.
시뮬레이터는 이 명세대로 가짜 데이터를 만들고, 처리 코드는 이 명세대로 읽습니다.
나중에 실제 장비 데이터가 같은 명세로 들어오면 코드를 고치지 않고 돌립니다.
실패사례(T2)를 알아낼 수 있는 필드도 여기서 확보합니다.

```
## 1. 원시 프레임 (frame)
## 2. 위치 로그 (pos)

## 10. 삭제된 하드웨어 항목 대응표
## 11. T2 연결표 (실패사례 → 탐지 필드)
```

묶음 절(1–7)마다 다음을 씁니다: 목적 한두 줄 → 파일 형식과 위치 → 필드표 → 예시 몇 줄.

### 4.1 필드표 형식

```markdown
| 필드 | 뜻 | 단위 | 자료형 | 필수/선택 | 예시 | 검증 규칙 |
|---|---|---|---|---|---|---|
| `meta.nozzle_temp_c` | 스캔 시작 때 노즐 온도 | °C | float | 필수 | 205.0 | 0 ≤ x ≤ 320 |
```

- 첫 칸은 반드시 백틱 안의 `묶음.필드` (소문자·숫자·밑줄만). 묶음 코드는 `frame` `pos` `cal` `ref` `meta` `blt` `rep` `truth`.
- 필드명 끝에 단위 접미사를 붙입니다: `_mm` `_um` `_ns` `_s` `_c` `_deg` `_rad` `_pct` `_px` `_mw` `_nm` `_us` `_db` `_mm_s` `_mm_s2`. 단위가 없는 필드(ID·개수·참거짓)는 단위 칸에 `-`.
- 칸 안에 `|` 문자를 쓰지 않습니다 (표가 깨집니다). "또는"으로 씁니다.
- 필드표가 아닌 표 (10절 대응표, 11절 연결표, 13절 제외 필드, 부록 C)는 첫 칸에 백틱 필드명을 두지 않습니다. 첫 칸은 요소 코드·실패 ID·번호·옛 필드명으로 씁니다. 검증 명령이 백틱으로 시작하는 행을 모두 필드표 행으로 읽기 때문입니다.
- 공간 필드는 뜻 칸에 좌표계를 적습니다. 예: "베드 위 목표 X, {G}".
- 검증 규칙은 기계로 검사할 수 있게 씁니다: 범위, 허용 값 목록, 정규식, 다른 필드와의 관계.

## 5. 7묶음 정의 지침

| 묶음 | 담는 것 | 형식 기본안 | 꼭 다룰 점 |
|---|---|---|---|
| 1. 원시 프레임 `frame` | 카메라 영상 + 프레임별 색인 | 영상: 무손실 PNG (8비트 또는 16비트 그릇에 10비트) 또는 묶음 `.npz`. 색인: `frames_index.csv` | 비트 깊이 보존. 압축 여부 (`frame.lossy`). USB 카메라가 손실 압축(MJPG)만 낼 수 있는 경우를 표시할 필드. 레이저 끈 프레임 (배경). 카메라 시각과 PC 수신 시각을 둘 다 |
| 2. 위치 로그 `pos` | 프린터 축 위치와 이벤트 | `position_log.csv` | 위치의 출처 (명령·계획·보고·스텝 계수)를 구분. 시계가 둘 (호스트·프린터 MCU)일 때 차이. 층 변경·스캔 시작·끝·정지 이벤트. 베드 메시 보정량. 가속도계는 선택 |
| 3. 교정 원자료 `cal` | D1–D5에 쓰는 원자료와 교정 결과 위치 | `calibration/<cal_id>/` 아래 D1–D5 하위 폴더 + `cal_manifest.csv` | ChArUco 규격과 평탄도. 레이저 켬·끔 쌍. 명령 Z 높이 (평판 방식). 교정 판 원기둥의 G코드 좌표. 필러게이지 공칭·실측 두께와 불확도. 교정 ID와 유효 기간, 무효화 사유 |
| 4. 기준 스캔 `ref` | 베드 맨바닥, 배경(레이저 끔), 암흑, 베드 마커, 일일 기준 시편, 정지 반복 촬영 | `reference/<ref_id>/` | 층마다 베드 마커를 다시 재서 열 드리프트를 잡는 용도 (M54 표의 "열" 행). 정지 반복 100장 (C7·F1 검증) |

① 구조·필드표·삭제 항목

```bash
cd "/c/Users/dawnn/OneDrive/바탕 화면/CV/cv-lab" && PYTHONIOENCODING=utf-8 python - <<'EOF'
import re
t1=open('docs/하드웨어-데이터-명세.md',encoding='utf-8').read()
for i,k in enumerate(['frame','pos','cal','ref','meta','blt','rep'],1):
```
