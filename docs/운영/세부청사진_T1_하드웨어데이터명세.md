## 1. 목적

하드웨어가 있었다면 나왔을 데이터를 **필드 하나하나까지** 정합니다.
시뮬레이터는 이 명세대로 가짜 데이터를 만들고, 처리 코드는 이 명세대로 읽습니다.
나중에 실제 장비 데이터가 같은 명세로 들어오면 코드를 고치지 않고 돌립니다.
실패사례(T2)를 알아낼 수 있는 필드도 여기서 확보합니다.
[개정] 실측 높이를 사용자 G코드의 정답 높이와 **절대 높이로** 비교하므로, 높이 0점 (베드 면), Z축 위치, 측정 당시 열 상태, 허용 오차 T, 펌웨어 정보를 빠짐없이 남깁니다.

묶음 절(1–7)마다 다음을 씁니다: 목적 한두 줄 → 파일 형식과 위치 → 필드표 → 예시 몇 줄.

### 4.1 필드표 형식

```markdown
| 필드 | 뜻 | 단위 | 자료형 | 필수/선택 | 예시 | 검증 규칙 |
|---|---|---|---|---|---|---|
| `meta.nozzle_temp_c` | 스캔 시작 때 노즐 온도 | °C | float | 필수 | 205.0 | 0 ≤ x ≤ 320 |
```

- 첫 칸은 반드시 백틱 안의 `묶음.필드` (소문자·숫자·밑줄만). 묶음 코드는 `frame` `pos` `cal` `ref` `meta` `blt` `rep` `truth`.
- 필드명 끝에 단위 접미사를 붙입니다: `_mm` `_um` `_ns` `_s` `_c` `_deg` `_rad` `_pct` `_px` `_mw` `_nm` `_us` `_db` `_mm_s` `_mm_s2`. 단위가 없는 필드(ID·개수·참거짓)는 단위 칸에 `-`.
- 칸 안에 `|` 문자를 쓰지 않습니다 (표가 깨집니다). "또는"으로 씁니다.
- 필드표가 아닌 표 (10절 대응표, 11절 연결표, 13절 제외 필드, 부록 C)는 첫 칸에 백틱 필드명을 두지 않습니다. 첫 칸은 요소 코드·실패 ID·번호·옛 필드명으로 씁니다. 검증 명령이 백틱으로 시작하는 행을 모두 필드표 행으로 읽기 때문입니다.
- 공간 필드는 뜻 칸에 좌표계를 적습니다. 예: "베드 위 목표 X, {G}".
- 검증 규칙은 기계로 검사할 수 있게 씁니다: 범위, 허용 값 목록, 정규식, 다른 필드와의 관계.

필드 뜻 메모:

| 필드 | 뜻 |
|---|---|
| `meta.bed_ref_id` | 이 스캔의 높이 0점으로 쓴 베드 기준 스캔 ID (`ref.kind` = bed_bare). 출력 전 같은 세션에서 잰 것 |
| `meta.z_offset_mm` | 프린터에 설정된 Z 오프셋 (노즐 끝과 베드 0점 사이 보정값) |
| `meta.thermal_state` | 측정 때 열 상태: in_process (층별, 출력 중) 또는 cooled (식은 뒤 재측정) |
| `meta.tolerance_mm` | 이 출력물의 허용 오차 T. 0.20 고정 (D-05 확정, 10-27) |
| `meta.zero_ref_method` | 높이 0점을 층마다 이어 가는 방법: bed_marker (베드 마커 재측정), ref_tower (시편 옆 기준 탑), z_only (Z 위치만). 출력 높이가 심도 8 mm를 넘으면 bed_marker 불가 |
| `meta.bed_mesh_file` | 이 세션에 쓴 베드 메시 표 원본 파일 경로 (`meta.mesh_enabled` = true면 필수) |
| `meta.paired_scan_id` | 짝 스캔 ID. 마지막 층의 식힌 뒤 재측정 스캔 (`meta.thermal_state` = cooled)이 가리키는 출력 중 스캔 (D-06) |
| `meta.cool_wait_s` | 마지막 층 출력이 끝난 뒤 식힌 재측정을 시작하기까지 기다린 시간 (thermal_state = cooled면 필수) |
| `meta.slicer_name` | G코드를 만든 슬라이서 이름과 버전 |
| `meta.gcode_flavor` | G코드 방언 (예: klipper, marlin, reprap). 파서 (T4 G1)가 읽는 방식을 정함 |
| `meta.firmware_name` | 펌웨어 이름: klipper, marlin, rrf, other 중 하나. 기존 `meta.firmware` (이름+버전 문자열)와의 관계는 명세 13절에 적음 |
| `meta.layer_macro_version` | 층 변경 때 스캔을 넣는 매크로의 버전 (T14 초안 기준) |
| `truth.print_error_params` | 시뮬레이터가 참 형상에 넣은 출력 오차 {종류: 파라미터}. 판정 시험 시나리오 (T5) 이름 포함 |
| `truth.thermal_params` | 열 상태 모델 파라미터 (층별 시편 온도, 수축 계수) |
| `truth.z_axis_error_params` | Z축 오차 참 파라미터 (피치 오차, 워블) |
| `truth.judgement` | 참 판정: **pass 또는 fail** (참 형상과 G코드로 계산, U = 0이라 보류가 없음. 2차 검증 10-27 정정). 경계 시나리오 표시는 `truth.print_error_params`의 "scenario" 키로. 측정 판정 결과 (합격·불합격·보류·측정 불충분)의 코드는 T15가 정함 |
| `truth.pass_pct` | 참 형상 기준 \|Δ\| ≤ T인 측정점 비율 |
