## 1. 용어와 부호

| 용어 | 뜻 |
|---|---|
| 고운 격자 | 0.02 mm 간격 격자. 정답 지도 (T4a)와 실측 지도 (T9)가 이 격자 [출처: G3] |
| 판정 칸 | 고운 칸 f × f를 묶은 칸 (0.2 mm면 f = 10). 판정의 "측정점" [출처: 청사진 §2.3 메모] |
| 판정 영역 | 판정에 넣는 칸 (`region`, bool). G4 · T4b가 채움 |
| 유효 칸 | 판정 영역 안이면서 Δ 값이 있는 칸 (이상치 제외 판정에서는 이상치가 아닌 칸) |
| 합격점 · 보류점 · 불합격점 | 유효 칸 하나의 분류. 코드값 1 · 0 · −1, 값 없음 −9 |
| 판정 | 출력물 하나의 결과: pass 합격 · fail 불합격 · hold 보류 · insufficient 측정 불충분 |
| U | 확장불확도 (k = 2), 시스템 전체 값 하나 [출처: 청사진 §1.1, §2.3] |

- 부호: **+ = 실측이 높음 (재료 과다), − = 실측이 낮음 (재료 부족)**. [출처: A1 · H5]
- 배열 순서 `A[iy, ix]`, 좌표는 {G} (mm), 높이는 {G} Z (베드 면 = 0). [출처: G3 · 세부청사진 §6.1]

## 2. Δ 정의

Δ = Z_meas − Z_ref

| 항목 | 내용 |
|---|---|
| Z_meas | 실측 높이, {G} Z, 베드 면 = 0, 측정 당시 값 (D-06) |
| Z_ref | 정답 높이 (G코드 기준 지도) |
| 내부 단위 | mm (float, 값 없음은 NaN) |
| 보고 단위 | µm |
| 부호 | + 재료 과다 · − 재료 부족 |

- 판정은 측정 당시 높이로 하므로, 아래층이 식으면서 줄어든 열 수축 기울기는 **측정 오차가 아니라 그때의 실제 형상**입니다. 그래서 이 몫은 U가 아니라 Δ에 들어갑니다. [출처: 청사진 §1.2, D-15 확정 · 팀장검증 2차 §3.1 문제 2]
- 같은 이유로 판정 코드는 식은 높이로 환산하지 않습니다.

## 3. 판정 칸

| 항목 | 규칙 | 근거 |
|---|---|---|
| 기본 크기 | 0.2 mm (f = 10), 주 판정 | D-20 R1 확정 |
| 함께 보고 | 0.4 mm (f = 20). 두 판정이 다르면 경고 | D-20 R1 확정, MF-JDG-04 (비드 간격 약 0.4 mm, MF-GCD-02) |
| 정수 조건 | 칸 크기 ÷ 격자 간격이 1 이상의 정수가 아니면 오류 (`cell_factor`, 분수로 정확히 셈) | 세부청사진 §6.2 |
| 묶는 범위 | 판정 칸 (jy, jx) = 고운 칸 iy ∈ [jy·f, (jy+1)·f), ix ∈ [jx·f, (jx+1)·f) | §6.2 |
| 가장자리 | f칸이 안 차는 묶음은 버림 (판정 영역 밖) | §6.2 |
| 칸 중심 | x0_mm + (jx·f + (f − 1)/2)·res_mm | §6.2 |

묶기 규칙 (`aggregate_to_cells`, D-20 R6 확정):

| 규칙 | 기본 | 근거 |
|---|---|---|
| 영역 칸 | 묶음 안 판정 영역 고운 칸 비율 ≥ `region_fill_min` (1.0, 전부) | D-20 R6. 엣지가 섞인 칸을 판정에 넣지 않음 (MF-JDG-03) |
| 유효 칸 | 영역 칸 중, 영역 안 고운 칸 가운데 Δ 있는 비율 ≥ `cell_fill_min` (0.5) | D-20 R6. 한두 점으로 칸 값을 정하지 않음 [추정] |
| 칸 값 | 영역 안 유효한 고운 칸 Δ의 평균 (선택 중앙값) | D-20 R6. 평균은 결함을 숨기지 않음. 중앙값은 비교용 [추정] |

- 결 예 (지도 M13, 시험용 가정): Δ = 0.10 + 0.025·sin(2πx/0.4)면 0.2 mm 칸 값은 0.10 ± 0.015981 mm로 번갈아 나오고, 0.4 mm 칸 값은 0.10 mm입니다. [계산: 반주기 10점 평균 = 0.025 × Σ sin((k+½)π/10) ÷ 10 = 0.025 ÷ (10 · sin 9°) = 0.015981]
- 이상치 마스크를 묶을 때는 묶음 안에 이상치 고운 칸이 하나라도 있으면 그 판정 칸을 이상치로 표시합니다 [추정, 덜 유리한 쪽]. 뺀 이유 코드는 묶음 안 0이 아닌 코드 중 가장 많은 것 (같으면 작은 코드)으로 합니다.

## 4. 판정 영역 인터페이스

G4 · T4b가 채울 자리입니다. T15는 마스크를 만들지 않습니다.

| 입력 | 형 | 뜻 |
|---|---|---|
| `region` | bool, 판정 칸 격자 | True = 판정에 넣는 칸 |
| `exclusion_code` (선택) | int8, 같은 모양 | 뺀 이유. 아래 코드표 |

| 코드 | 뜻 |
|---|---|
| 0 | 영역 안 |
| 1 | 엣지 띠 |
| 2 | 가림 예측 |
| 3 | 시야 밖 |
| 4 | 제외 경로 종류 (스커트 · 브림 · 서포트) |
| 5 | 출력물 없음 |
| 9 | 기타 |

- 판정은 `region`만으로 합니다. `exclusion_code`는 뺀 이유별 칸 수를 결과 `exclusions.by_code`에 적는 데만 씁니다 (MF-JDG-03 "뺀 자리 지도").
- 코드표 밖 값, 영역 안 칸에 0이 아닌 코드는 오류입니다. 영역 밖인데 코드가 0인 칸은 "이유 없음"으로 세고 경고합니다.
- 영역 밖 칸의 Δ는 판정에도 지표에도 쓰지 않습니다 (지도 M07).
- 코드표를 바꾸려면 팀장에게 먼저 묻습니다.

## 5. 유효 칸과 측정 불충분

| 조건 | 결과 |
|---|---|
| n_region = 0 (판정 영역이 빔) | 측정 불충분 (M17) |
| n_valid = 0 | 측정 불충분 |
| n_valid · 100 < valid_min_pct · n_region | 측정 불충분 (M06: 유효 90/100은 판정, 89/100은 측정 불충분) |

- valid_min_pct = 90은 D-20 R2로 확정했습니다 (처음 제안은 청사진 §2.3). 근거: 40 × 40 mm 출력에서 바깥 엣지 띠 0.3 mm만 빼도 3 %, 안쪽 윤곽까지 더하면 5–20 %가 빠지므로 [출처: MF-JDG-03], 엣지 띠를 뺀 뒤의 판정 영역 안에서는 결측이 10 %를 넘으면 "나쁜 곳을 골라 뺐을" 가능성을 의심해야 합니다 [추정].
- 측정 불충분을 합격·불합격보다 먼저 봅니다. 결측이 많은데 남은 칸만으로 합격을 내지 않기 위해서입니다.

## 6. 점 분류 (방식 B)

D-07 가드밴드 방식 B:

| 점 | 조건 | 정수 비교 |
|---|---|---|
| 합격점 | \|Δ\| ≤ T − U | q ≤ t_pass |
| 불합격점 | \|Δ\| > T + U | q > t_fail |
| 보류점 | 그 사이 | t_pass < q ≤ t_fail |

- q = rint(\|Δ\| · 10⁶) (nm 정수), t_pass = rint((T − U) · 10⁶), t_fail = rint((T + U) · 10⁶).
- 실수로 비교하면 경계가 실수 표현에 달립니다. 예: 0.2 − 0.171 = 0.028999999999999998이라 \|Δ\| = 0.029가 합격점에서 빠지고, 0.2 + 0.141 = 0.34099999999999997이라 \|Δ\| = 0.341이 불합격점이 됩니다 [계산, Python float]. 정수 비교는 둘 다 바르게 셉니다 (시험 `test_float_subtraction_does_not_move_boundary`). 1 nm는 U보다 4자리 이상 작아 판정 뜻을 바꾸지 않습니다.
- 세부청사진 §6.5의 예 "0.2 − 0.03 = 0.17000000000000001"은 실제로는 Python에서 0.17과 같은 값이었습니다. 원리는 같으므로 시험은 위 두 예로 바꿨습니다.
- U 검사 (`check_U`): U 없음 · NaN · U < 0 · U ≥ T면 오류 (M11). U = 0이면 보류점이 없고 방식 A와 같습니다 (M10).
- `U_source`가 없거나 빈 문자열이면 판정을 거부합니다. U 값의 출처를 보고서에 반드시 남기기 위해서입니다 (MF-JDG-01).
- 예: U = 31.7 µm면 합격점 \|Δ\| ≤ 0.1683 mm, 불합격점 > 0.2317 mm, 보류 띠 63.4 µm (T의 31.7 %). [계산, 출처: T2 5.2]
- 예: U = 20.9 µm (D-15 기본 U, 참고값, 출처: docs/운영/팀장검증_2차.md §3)면 합격점 \|Δ\| ≤ 0.1791 mm, 불합격점 > 0.2209 mm, 보류 띠 41.8 µm (T의 20.9 %). [계산] 이 값도 코드에 넣지 않고 판정 때 `U_mm=0.0209, U_source="D-15 …"`처럼 출처와 함께 넣습니다.

## 7. 출력물 판정 (전체 층 합산)

D-08: 전체 층의 유효 칸을 합쳐서 셉니다. 층별 비율의 평균이 아닙니다. 스캔은 모든 층을 합니다 (D-18).

| 순서 | 조건 (정수 곱셈) | 판정 |
|---|---|---|
| 1 | §5 조건 | 측정 불충분 |
| 2 | n_pass · 100 ≥ pass_min_pct · n_valid | 합격 |
| 3 | n_fail · 100 > fail_max_pct · n_valid | 불합격 |
| 4 | 그 밖 | 보류 |

- 문턱 백분율은 분수로 바꿔 분모까지 곱합니다 (95.5 같은 값도 정확히 비교).
- 합격 (≥ 95 %)과 불합격 (> 5 %)은 동시에 참일 수 없습니다. n_valid 1–60의 모든 조합으로 확인했습니다 (`test_pass_and_fail_never_both`).
- 문턱을 바꿀 때는 `pass_min_pct + fail_max_pct ≥ 100`이어야 하며, 합이 100보다 작으면 설정을 읽을 때 오류로 멈춥니다 (예: 90 · 5면 합격점 92 % · 불합격점 8 %가 합격으로 나오기 때문, J-1).
- 경계 예: 200칸 중 합격 190 → 95.0 % 합격 (M03). 합격 188 · 보류 2 · 불합격 10 → 불합격 5 %는 "넘지" 않으므로 보류 (M04). 불합격 11 → 5.5 % 불합격 (M05).
- 층 합산 예 (M08): 층 0의 10칸 전부 불합격, 층 1의 990칸 전부 합격 → 합격 99 % → 합격. 층별 비율 평균이면 50 %였을 것입니다. 층 0은 경고로 따로 드러납니다 (MF-JDG-06).
- 층 번호 (`layer_idx`)가 겹치면 오류입니다 (M15). 패스 합치기는 앞 단계 몫입니다.
- 층별 표: 층마다 칸 수, 합격·보류·불합격 비율, 지표. 한 층의 불합격점 > 50 %면 경고합니다 (50 %는 경고 안 함, 지도 M20). 문턱 50 %는 D-20 R7로 확정했습니다 (처음 값은 T2 MF-JDG-06 예시).

## 8. 측정 당시 판정과 식힌 재측정

| 항목 | 규칙 |
|---|---|
| 판정 입력 | `thermal_state = in_process` 층만. `cooled`나 다른 값이 들어오면 오류 (MF-JDG-05, M14) |
| 식힌 재측정 | `post` 인자 (thermal_state = cooled, layer_idx = 마지막 층). 다르면 오류 |
| 보고 | 차이 = Δ_post − Δ_last (µm): n, 평균, 중앙값, p05, p95, 최대 \|·\|. 둘 다 값 있고 영역 안인 칸만. 공통 칸이 없으면 None + 경고 |
| 판정 영향 | 없음. `post`가 있든 없든 판정·칸 수가 같음 (시험으로 확인) |

"식었다" 기준 (T1 명세 14절 15번이 T15에 넘긴 것, D-20 R4 · R5 확정):

- 남은 수축 δ = α · H · ΔT, ΔT = 시편 윗면 온도 − 실내 온도.
- ΔT_max = δ_max ÷ (α · H). α = 68 µm/(m·°C) [출처: 청사진 §1.2, 사용자 제시], H = 출력 높이.
- δ_max = 5 µm (D-20 R4 확정): T2 심각도 S2 (1–5 µm, 경고 수준)의 상한 [추정, 근거 T2 2절 표].
- 예: H = 20 mm면 α · H = 1.36 µm/°C, ΔT_max = 5 ÷ 1.36 = 3.7 °C [계산]. ΔT = 5 °C면 남은 수축 6.8 µm > 5 µm → "식힘 부족" 경고.
- 기준은 판정을 바꾸지 않습니다 (R4). 못 넘으면 경고만, 시편 온도 센서 값·실내 온도·높이가 없으면 "판단 못 함" 경고만 냅니다 (R5).
- 시간 기준 (`meta.cool_wait_s` 하한)은 열 모델이 없어 정하지 않았습니다 [미상]. R4 확정 때 채택하지 않은 다른 안입니다.

## 9. 참고 판정 (방식 A, 이상치 전후)

**방식 A** (청사진 §2.3): U = 0으로 분류해 \|Δ\| ≤ T 비율에 95 % 규칙을 적용한 결과를 `method_a`에 함께 냅니다. 방식 A는 합격인데 방식 B가 보류·불합격이면 "경계 근처 점이 많음" 경고 (MF-JDG-07).

**이상치 전후** (MF-JDG-03, D-20 R3 확정):

| 경우 | 처리 |
|---|---|
| `outlier` 마스크 없음 (또는 전부 False) | 판정 하나 |
| 있음 | ① 제외 전 (이상치 칸도 유효, 값 그대로) ② 제외 후 (이상치 칸은 무효)를 둘 다 냄 |
| 둘이 다름 | 경고 "이상치 처리에 따라 판정이 바뀜" |
| 주 판정 | 덜 유리한 쪽. 순서 합격 < 보류 < 측정 불충분 < 불합격. 같으면 제외 전 (데이터를 빼지 않은 쪽) |

- 예 (M16): 100칸 중 6칸이 Δ 0.5 mm 이상치 → 제외 전 불합격 (6 %), 제외 후 합격 (유효 94 %) → 주 판정 불합격.
- 예 (M18): 보류 15칸이 이상치 → 제외 전 보류, 제외 후 측정 불충분 (유효 85 %) → 주 판정 측정 불충분.
- 블롭·포화 점을 이상치로 빼면 결함이 사라질 수 있어서 (MF-JDG-03) 불량을 합격으로 내보내지 않는 쪽을 골랐습니다. 설정 `outlier_primary`는 `worse` · `before` · `after`를 받고, 확정 기본값은 `worse`입니다 (R3).

## 11. C12 채점 방법

`score_c12(pred, true)`: 참 판정은 채점기가 인자로만 넘깁니다. T15 코드는 정답 파일을 열지 않습니다.

| 항목 | 정의 |
|---|---|
| 참 판정 | {pass, fail, borderline} (명세 부록 A `truth.judgement`의 뜻) |
| 예측 | {pass, fail, hold, insufficient} (문자열 또는 `JudgeResult`) |
| 혼동표 | 참 3 × 예측 4 |
| 필수 | 참 fail → 예측 pass = 0건 (`c12_required_ok`) |
| 안 | 참 pass → 예측 fail ≤ 참 pass 수의 5 % (`c12_target_ok`, 정수 비교 false_fail · 100 ≤ 5 · n_true_pass) |
| 보고 | 보류 비율, 측정 불충분 비율, borderline의 예측 분포, 참 fail → 측정 불충분 건수 |

- 판정 정확도는 팀장만 시드를 아는 평가용 세트로 잽니다 [출처: 청사진 §5.2]. T15는 함수와 정의만 냅니다.

## 12. U 민감도

`scripts/judge_sensitivity.py` → `docs/판정-규칙_자료/민감도_U.csv` (시나리오 4 × U 28 = 112행), `칸크기_민감도.csv` (24행).

- 시나리오 (시험용 가정, 측정값 아님): N1 양호 N(0, 0.05 mm) · N2 경계 근처 N(0.12, 0.04) · N3 T 근처 N(0.20, 0.03) · B1 결 0.10 + 0.025·sin(2πx/0.4) + N(0, 0.005) (고운 2000 × 2000 → 0.2 mm 칸 200 × 200). N1–N3는 1000 × 1000 칸. 시나리오마다 `np.random.default_rng(20261027)`을 새로 만듦.
- U 값: 0–100 µm 5 µm 간격 21개 + 21 (청사진 §2.3 메모) · 31.7 · 66.9 (T2 5.2) + 팀장검증 2차 §3.3의 26.1 · 20.9 · 14.6 · 13.0 µm. 세부청사진 §6.9는 24개였으나 팀장 지시로 4개를 더했습니다.
- 정규분포 시나리오는 해석해 P(\|Δ\| ≤ a) = Φ((a − μ)/σ) − Φ((−a − μ)/σ)와 대조했고 모든 행이 4σ 안입니다. 같은 표본을 U만 바꿔 판정하므로 U가 커질 때 보류 비율은 줄지 않습니다 (단조 위반 0).

팀장 U 후보별 결과 (합격 / 보류 / 불합격 %, 판정):

| U (µm) | 출처 | N1 | N2 | N3 | B1 |

| 31.7 | T2 5.2 RSS | 99.92 / 0.08 / 0.00 합격 | 88.63 / 11.10 / 0.27 보류 | 14.54 / 70.91 / 14.54 불합격 | 100 / 0 / 0 합격 |
| 26.1 | 팀장 단계 1 (GUM) | 99.95 / 0.05 / 0.00 합격 | 91.09 / 8.51 / 0.40 보류 | 19.25 / 61.47 / 19.27 불합격 | 100 / 0 / 0 합격 |

- U가 31.7 → 66.9 µm로 바뀌면 시나리오 N2의 보류가 11.10 % → 37.18 %로 늘어납니다 [표에서 옮김].

## 15. 한계

- 판정 정확도 (C12)는 아직 재지 않았습니다. 함수와 정의만 있고, 평가용 세트는 팀장 몫입니다 (청사진 §5.2).
- 점마다 오차가 독립이라고 보는 95 % 규칙이라, 이웃 칸이 같은 치우침을 공유하면 넓은 영역이 한꺼번에 보류·불합격으로 넘어가거나 좁은 결함 덩어리가 5 % 안에 숨을 수 있습니다 (MF-JDG-02). 방식 C (비율 신뢰구간)와 덩어리 크기 표시는 다루지 않았습니다.
- U는 시스템 전체 값 하나입니다. 점마다 다른 U는 T12 뒤 검토합니다 [출처: 청사진 §2.3].
- 민감도 표의 분포는 시험용 가정입니다. 실제 출력의 Δ 분포는 [미상]입니다.
- 열 수축 시간 모델이 없어 식힘 시간 기준을 정하지 못했습니다 [미상].
- 측정이 못 보는 오차: 프린터 Z축·프레임 드리프트처럼 출력과 측정이 함께 가진 오차는 이 측정이 스스로 보지 못합니다. 그 몫은 U 예산에 그대로 둡니다 (D-14, 청사진 §9).
- 이 문서의 모든 결과는 가상 데이터 단계의 것입니다. 하드웨어 성능의 증거가 아닙니다.
