## 2026-10-07 · 0단계 방법 탐색 — 적합성 실험 1~4

대상: [0_방법탐색/README.md](0_방법탐색/README.md) (청사진), [0_방법탐색/비교-선정.md](0_방법탐색/비교-선정.md) (결과), `scripts/method_screening/`

| 질문 | 답 |
|---|---|
| 1. 목표 기여 | 오차 3종(높이·윤곽·치수)을 정해진 정밀도로 잴 수 있는 방법을 23개 후보에서 숫자로 걸러, 1단계 파일럿 대상 3개와 게이트 판단 규칙을 정했습니다. |
| 2. 수단 중립성 | 레이저 삼각측량(M05)도 같은 사양 조사·같은 모델로 평가했고, 그 결과 보수 기준 3종 모두 불합격으로 나왔습니다. 방법별 측정 특성은 후보 사양 CSV 한 곳에만 있고, 코드는 방법에 묶이지 않습니다. |
| 3. 효율 | 실물 시험 전에 계산으로 23개 → 3개로 줄였습니다. 학내 장비 보유 여부를 먼저 확인하면 파일럿 비용을 더 줄일 수 있습니다. |
| 4. 일관성 | 판정 기준은 A2·중심주제 §1 수치(5 / 10 / 25 µm, 4:1·10:1)를 그대로 썼습니다. **어긋난 점 1**: 중심주제 §3.1 통과 조건에 없는 "시편 1개 ≤ 480분" 실현성 조건을 추가했습니다(M02 촉침식 면 측정 140,000분 문제). **어긋난 점 2**: 예산 상한 500만 원은 K3 확정 전 임시값입니다. |
| 5. 연결 | 파일럿 시험 항목을 숫자로 적었습니다(비교-선정 §5). 결과가 정해지면 B·D·F 영역을 선정 방법에 맞게 다시 써야 합니다(중심주제 §5). C3 기준 마커와 D5 교정 검증은 어떤 방법이든 필요하다는 근거(배율 교정 효과)를 얻었습니다. |
| 6. 정량성 | 모든 후보에 오차 그룹별 판정량(µm)과 등급이 있습니다. 근거 사양의 불확실성은 낙관 / 보수-500 / 보수-100 세 시나리오로 보였고, 가중치 민감도도 계산했습니다. |

**조치**
- 하위 문서 수정: 없음.
- 상위 문서 수정 제안(미반영, 승인 필요): 중심주제 §3.1에 "실현성: 시편 1개 측정 ≤ 1 근무일" 추가.
- 확인 필요: 학내 Alicona(초점 변화)·Zygo(백색광 간섭계)·공초점 현미경·Dektak 보유 여부와 요금, 연구실 예산 상한(K3).
