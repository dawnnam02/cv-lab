# 0단계 · 방법 탐색 청사진

> 상위 문서: [중심주제](../중심주제.md) §2–§4 · 기간: 2026-10-06 ~ 10-19 (W1–W2)
> 결과: [비교-선정.md](비교-선정.md) (적합성 실험 결과와 1차 점수표)

## 1. 목적

G코드 대비 가공 오차를 정량평가할 **측정 방법 후보를 빠짐없이 나열**하고, **적합성 실험**으로 걸러서 1단계 파일럿(W3–W4)에 올릴 상위 2~3개(조합 포함)를 고릅니다.

- 0단계 적합성 실험은 **자료 조사 + 계산·시뮬레이션**입니다. 실물 측정은 1단계 파일럿에서 합니다.
- 레이저 삼각측량(자작)도 다른 후보와 **같은 조건**으로 평가합니다 (수단 중립).

## 2. 판정 기준 (중심주제 §1, §3에서 가져옴)

### 2.1 측정 목표와 필요 정밀도 (A2, FDM 기본값)

| 목표 | 크기 | 4:1 최소 | 10:1 이상 | 이 단계의 판정 지표 |
|---|---|---|---|---|
| 층 높이 오차 | ±0.02 mm | Z 불확도 ≤ 5 µm | ≤ 2 µm | 단차 −20 µm 복원의 2σ ≤ 5 µm |
| 선폭 오차 | ±0.04 mm | 폭 불확도 ≤ 10 µm | ≤ 4 µm | 0.40 mm 선 +40 µm 복원의 2σ ≤ 10 µm |
| 치수 오차 | ±0.1 mm | ≤ 25 µm | ≤ 10 µm | Ø4 mm 구멍 −100 µm 복원의 2σ ≤ 25 µm |
| 윤곽 오차 | (치수 기준) | 경계 위치 ≤ 25 µm | ≤ 10 µm | 윤곽 거리 평균 복원 2σ ≤ 25 µm |
| 위치 오차 | ±0.2 mm (가정) | ≤ 50 µm | ≤ 20 µm | 전체 이동 +0.2 mm 복원 2σ ≤ 50 µm |

### 2.2 통과 조건 (하나라도 못 맞추면 탈락)

1. **정밀도**: 높이·윤곽·치수 중 **최소 2종**이 위 4:1 기준 통과 (시뮬레이션)
2. **G코드 비교 가능성**: 결과를 G코드 좌표계(XY 평면 + Z)에 정합 가능 (기준 마커·베드 기준)
3. **안전·규정**: 연구실에서 운용 가능 (레이저 Class 3B 이상·X선은 별도 허가 필요 → 외부 의뢰로만 허용)
4. **예산**: 구축 또는 이용 비용 ≤ **500만 원** (K3 확정 전 임시 상한), 외부 의뢰는 시편 1개 ≤ 30만 원

### 2.3 비교 점수 (각 1~5점 × 가중치, 중심주제 §3.2 그대로)

정밀도 여유 20 · 오차 종류 15 · 비용 15 · 구축·학습 난이도 15 · 속도·자동화 10 · 재질 의존성 10 · 공정 중 측정 5 · 검증 용이성 5 · 연구 기여도 5 (%)

## 4. 적합성 실험 설계

### 4.1 실험 1 — 사양 조사 (자료)

후보마다 같은 열로 `후보-사양.csv` 한 행을 채우고, 근거(데이터시트·논문 URL)를 `후보/Mxx.md`에 남깁니다.
숫자는 **대표 구성 1개**(이 과제 시편 크기 20 × 40 × 20 mm에 맞춘 구성)를 기준으로 하고, 범위가 넓으면 보수적 값을 씁니다.

| 열 | 뜻 | 단위 |
|---|---|---|
| id, name, config | 후보 ID, 이름, 대표 구성(모델명 등) | — |
| z_sigma_um | Z 반복성 1σ (2σ 표기면 ÷2) | µm |
| xy_step_um | XY 점 간격(픽셀/샘플링) | µm |
| xy_blur_um | 가로 분해능(스폿·PSF·프로브 반경) | µm |
| fov_mm, depth_mm | 한 번에 보는 폭, 측정 깊이 | mm |
| measures_z | 높이 측정 가능 여부 (0/1) | — |
| edge_loss_um | 가장자리·벽에서 잃는 폭 (가림·경사 한계) | µm |
| max_slope_deg | 측정 가능한 최대 경사 | ° |
| time_min | 20 × 40 mm 시편 1개 측정 시간 | 분 |
| cost_krw | 구축·구입 비용(또는 1회 의뢰비) | 원 |
| access | own(구입/자작) / lab(학내 장비) / outsource(의뢰) | — |
| surface_dep | 재질·색·광택·반투명 의존성 1(낮음)~5(높음) | — |
| in_situ | 프린터 안에서 층별 측정 가능 0/1/2(연구 사례) | — |
| safety | 안전 등급·허가 필요 여부 | — |
| learn_weeks | 초보자가 첫 측정까지 걸리는 주 | 주 |
| sources | 근거 URL (`;` 구분) | — |

### 4.2 실험 2 — 통과 조건 1차 판정 (규칙)

`후보-사양.csv`를 2.2절 규칙에 넣어 자동 판정합니다. 예산·안전·G코드 정합 불가는 여기서 탈락합니다.

### 4.3 실험 3 — 측정 시뮬레이션 (핵심)

정답을 아는 **합성 시편**에 각 후보의 측정 특성을 씌우고, 오차를 다시 뽑아서 복원 정확도를 봅니다.

- **합성 시편** (0.002 mm 격자, 20 × 40 mm): 계단(0.2 mm 단차 5개), 단일 선 0.40 mm 폭·0.2 mm 높이 3줄, 구멍 Ø2/4/6, 핀 격자 3 × 3
- **넣는 오차 (정답)**: 단차 −20 µm, 선폭 +40 µm, 구멍 지름 −100 µm, 전체 위치 (+200, −100) µm
- **후보 모델**: 가로 흐림(xy_blur, 가우시안 또는 프로브 반경의 형태학적 필터) → xy_step 샘플링 → Z 잡음(z_sigma) → 경사·가장자리 결측(edge_loss, max_slope) → 높이 없는 방법은 2D 경계만
- **지표 추출**: 단차 = 면 중앙값 차, 선폭 = 반높이 폭, 지름 = 경계 원 맞춤, 위치 = 핀 중심 평균 이동
- **반복**: 몬테카를로 50회 → 복원 오차의 치우침과 2σ
- **판정**: 2.1절 표의 4:1 / 10:1 기준

### 4.4 실험 4 — 점수화와 선정

통과 후보에 2.3절 점수를 매기고, 가중치를 ±50 % 흔드는 민감도 분석에서도 상위에 남는 후보와 **조합안**을 1단계 파일럿으로 올립니다.

## 6. 완료 기준

- 23개 후보 모두 사양 행이 채워지고, 모든 숫자에 출처 또는 "추정 근거"가 붙어 있음
- 시뮬레이션이 정답을 아는 이상 모델(잡음 0, 흐림 0)에서 넣은 오차를 ±1 µm 안에서 복원 (코드 자체 검증)
- 모든 후보에 통과/탈락과 그 이유가 숫자로 기재
- 파일럿 후보 2~3개(조합 포함)와 각 후보의 1단계 시험 항목이 정해짐

## 7. 한계 (기록해 둘 것)

- 시뮬레이션은 데이터시트 수치를 믿는 모델입니다. 반투명 PLA 표면 산란, 다중 반사 같은 실제 효과는 `surface_dep` 점수로만 반영되고, **1단계 실측에서 확인**합니다.
- 비용·접근성은 연구실 상황(학내 장비 보유 여부)에 따라 바뀌므로 확정 전 확인이 필요합니다.
