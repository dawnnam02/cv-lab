# M27 · 관절형 CMM 암 + 레이저 라인 프로브

## 대표 구성

- **FARO Quantum Max ScanArm 2.0 m + PRIZM 레이저 라인 프로브**로 측정 의뢰(국내 FARO 대리점·측정 대행 업체)
- 윗면 전체를 2~3번 겹쳐 쓸어 점군을 얻고, CAD(G코드 경로로 만든 모델)와 비교
- 같은 계열의 저가 프로브 FAROBlu xE도 있으나 정확도가 30 µm로 조금 낮아 PRIZM을 기준으로 잡았습니다.

## 원리

여러 관절의 각도 엔코더로 암 끝의 위치·자세를 계산하고, 끝에 달린 레이저 라인 프로브가 삼각측량으로 선 하나의 단면을 잽니다. 사람이 손으로 프로브를 움직이면 단면들이 암 좌표계에 쌓여 점군이 됩니다. 원리는 M05·M06과 같고, 위치를 프린터 축 대신 암 엔코더가 정한다는 점이 다릅니다.
