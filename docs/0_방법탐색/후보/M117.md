# M117 · 정밀 저울 질량 (체적 편차, 간접)

## 대표 구성

- **A&D GH-252** 분석 저울 (250 g × 0.1 mg / 101 g × 0.01 mg, 반복성 0.1 mg / 0.03 mg, 내장 분동 교정)
- 같은 스풀, 같은 출력 설정으로 뽑은 기준 블록의 질량과 치수로 "출력물의 겉보기 밀도"를 먼저 구함
- 시편 질량 ÷ 겉보기 밀도 = 시편 체적. 이를 G코드(또는 슬라이서)가 예상한 체적과 비교

## 원리

형상을 재지 않습니다. 출력물에 들어간 플라스틱의 양을 질량으로 재서, 압출량이 전체적으로 많았는지 적었는지를 봅니다. 질량은 아주 정밀하게 재지만, 체적으로 바꿀 때 쓰는 밀도의 불확도가 결과를 지배합니다.

## 체적 편차를 얼마나 정밀하게 알 수 있나

시편 공칭 체적을 꽉 찬 블록 20 × 40 × 20 mm = 16,000 mm³로 잡고, PLA 밀도 1.24 g/cm³, 출력물 기공률 약 5 %를 가정하면 질량은 약 18.8 g입니다.

| 불확도 원인 | 크기 (1σ) | 체적 환산 |
|---|---|---|
| 저울 반복성 0.1 mg | 0.0005 % | 0.08 mm³ |
| 습기 흡착(PLA 흡수율 0.1~0.5 %, 보관 조건 차이) | 약 0.05 % (추정) | 약 8 mm³ |
| 겉보기 밀도 (기준 블록으로 교정해도 출력마다 기공률이 달라짐) | 0.5~1 % (추정) | 80~160 mm³ |
| **합계** | **약 0.5~1 %** | **약 80~160 mm³** |

- 100 % 채움 출력물도 기공률이 수 %~10 % 가까이 나온다는 보고가 있어(XCT 측정 9.3 %, 검색 요약 기준이며 원문 미확인), 밀도를 문헌값 1.24 g/cm³로 그냥 쓰면 오차가 5~10 %로 커집니다. 기준 블록 교정이 필수입니다.
