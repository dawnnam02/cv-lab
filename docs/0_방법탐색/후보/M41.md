# M41 · LMI Gocator 2520 (신품)

## 대표 구성

- **Gocator 2520 신품**: CD 47.5 mm, MR 25 mm, 폭 25~32.5 mm, X 13~17 µm, 405 nm Class 2, 1,920점/프로파일
- 시편을 근거리 쪽(폭 25 mm, X 13 µm)에 두고 Y 스캔 1회로 윗면 전체를 덮음
- 고른 이유: 2510과 같은 몸체에 폭만 넓어 20 mm 시편을 이음 없이 한 번에 봄

## 원리

M40과 같은 일체형 레이저 삼각측량 센서입니다. 기준거리가 길고 시야가 넓은 대신 같은 1,920점을 더 넓게 펼쳐 X 간격과 반복성이 2510보다 성깁니다.
