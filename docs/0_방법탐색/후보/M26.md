# M26 · 윤곽 형상 측정기 (Contracer)

## 대표 구성

- 학내 **Mitutoyo Contracer CV-2100M4**(X 100 mm, Z1 50 mm, 둘 다 분해능 0.1 µm)
- 표준 촉침 SPH-71: 한쪽 깎음형, 팁 각 20°, 팁 반경 25 µm, 초경. 측정력 30 mN
- 측정 속도 0.5 mm/s, 40 mm 방향 단면 **10줄**(계단 5단을 가로지르는 줄 4, 단일 선 3줄을 가로지르는 줄 3, 구멍 중심을 지나는 줄 3)

## 원리

촉침이 달린 암이 표면을 따라 X 방향으로 끌려가고, 암의 회전각을 원호 스케일로 읽어 높이(Z1)를 얻습니다. 거칠기 측정기(M32)와 달리 스키드 없이 X축 이송 기준으로 재므로 수 mm 이상의 단차와 형상을 그대로 담습니다. 결과는 단면 한 줄의 (X, Z) 곡선입니다.

## A1 오차 7종 중 잴 수 있는 것

| 오차 | 가능 | 비고 |
|---|---|---|
| 높이 | ◎ | 단면에서 계단 단차를 직접 |
| 윤곽 | △ | 단면 방향의 벽 위치만 |
| 치수 | ○ | 단면 위의 길이(구멍 지름은 중심을 지날 때만) |
| 위치 | △ | 줄 정렬 정확도에 좌우 |
| 배율 | ○ | X 정확도 ±(2.5 + 0.02L) µm |
| 선(비드) | ◎ | 단일 선 단면에서 폭·높이를 바로 읽음 |
| 표면 | ○ | 단면 방향의 층 결 |

## 장점

- 단차와 선 단면을 교정된 장비로 µm 수준에서 직접 봅니다. 1차 M02(Dektak)보다 Z 범위가 넓어 시편 높이 20 mm에도 여유가 있습니다.

## 한계

- 줄 단위라 면 전체 높이맵은 못 얻습니다. 줄 위치를 G코드 좌표에 맞추려면 기준 모서리를 먼저 재야 합니다.
- 줄을 늘리면 시간이 줄 수에 비례해 늘어납니다.

## 이 과제에서의 쓰임

**기준값용(높이·선폭).** 주력 높이맵 방법의 단차·선 단면을 검증합니다.
