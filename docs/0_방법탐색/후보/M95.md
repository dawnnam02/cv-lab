## 원리

모니터에 사인 무늬를 띄우고, 카메라는 시편 표면에 **거울처럼 비친** 무늬를 찍습니다. 무늬를 여러 번 밀어(위상천이) 화소마다 "모니터의 어느 점이 비쳤는지"를 구하면 반사 법칙으로 표면 기울기를 알 수 있고, 기울기를 적분해 높이를 얻습니다. 같은 기울기라도 높이가 다르면 같은 무늬가 비칠 수 있어(높이-기울기 모호성), 모니터를 두 위치에 놓고 다시 찍어 풉니다. 표면이 거울에 가까울수록 정확하고, 빛을 흩뿌리는 면에서는 무늬가 뭉개져 작동하지 않습니다.

| 오차 | 가능 | 비고 |
|---|---|---|
| 높이 | △ | 연속면의 휨·처짐은 민감. 층 단차 같은 불연속은 약함 |
| 윤곽 | △ | 반사 무늬가 끊기는 경계로 윤곽은 나오나 18 µm 화소 + 모서리 손실 |
| 치수 | △ | 같은 이유 |
| 위치 | △ | 기준 마커가 반사면이 아니면 따로 조명 영상 필요 |

| 선(비드) | × | 융기 사이 골에서 무늬가 무너짐 |

## 장점

- 기울기에 아주 민감해 윗면의 휨·물결을 잘 봅니다.
- 부품이 싸고(모니터 + 카메라), 한 장 시야로 윗면 전체를 봅니다.

## 한계

- 거울 반사가 있어야 합니다. FDM PLA 윗면은 대부분 거울이 아닙니다.
- 높이는 기울기를 적분해 얻으므로 단차·모서리처럼 끊긴 곳에서 높이를 잃습니다.
- 높이-기울기 모호성 처리, 화면 보정이 까다롭습니다.

## 이 과제에서의 쓰임

**부적합(표면 형상 보조로만).** 층 높이·선폭·치수 기준을 맞추기 어렵습니다. 광택 PLA 윗면의 휨을 보는 연구용 보조 정도입니다.
