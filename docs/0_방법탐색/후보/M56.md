# M56 · Keyence CL-3000 (크로마틱 공초점 점) + 프린터 축 래스터

## 대표 구성

- **CL-3000 컨트롤러 + CL-P015 헤드**: 기준거리 15 mm, 범위 ±1.3 mm(고정밀 구간 ±0.5 mm), 스폿 ø25 µm, 선형성 ±0.36~0.49 µm, 분해능 0.015 µm(거울면 16,384회 평균), 샘플링 100/200/500/1,000 µs, Class 1
- 프린터 축 래스터, 20 µm 격자
- 고른 이유: CL-P 헤드 중 범위(2.6 mm)와 스폿(25 µm)이 시편 윗면에 가장 잘 맞음. CL-P007은 범위 3 mm지만 스폿 50 µm, CL-P030은 스폿 38 µm

## 원리

여러 파장이 섞인 빛을 색수차가 큰 렌즈로 모으면 파장마다 초점 높이가 달라집니다. 표면에서 돌아온 빛 중 초점이 맞은 파장만 핀홀을 통과하므로, 그 파장을 분광기로 읽어 높이를 냅니다. 송수광이 같은 축이라 그늘이 없고, 반투명 재질에서도 표면 봉우리를 따로 잡습니다. 점 센서라 프린터 축으로 훑습니다.

## 장점과 한계

- 장점: 반투명 PLA에 강하고 그늘이 없음. 국내 Keyence 지사가 있어 대여·시연 문의가 쉬움.
- 한계: 신품 견적이 공개돼 있지 않고 예산을 넘을 가능성이 큼. 전면 측정 45분.

## 이 과제에서의 쓰임

**기준값용 + 높이 주력 후보**. 중고 조합으로 예산 안에 들면 층 높이 오차의 주력 수단.
