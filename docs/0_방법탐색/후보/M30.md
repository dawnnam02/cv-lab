# M30 · 정밀 리니어 게이지 + 프린터 축 래스터

## 대표 구성

- **Mitutoyo LGF-0110L-B(542-181)**: 범위 10 mm, 분해능 0.1 µm, 정확도 (0.8 + L/50) µm, 측정력 1.2 N 이하, Ø3 mm 초경 접촉점, A/B상 차동 출력(RS-422)
- 카운터는 전용 표시기 대신 USB 엔코더 카운터 보드(4체배 직교 신호 입력)로 PC에 바로 받습니다.
- 프린터 헤드에 고정, Z 고정 상태로 X 방향 끌기 주사, 줄 간격 0.5 mm 40줄(M28과 같은 방식). 응답 속도가 400 mm/s라 끌기에 맞습니다.
- 같은 급의 Heidenhain METRO/SPECTO 게이지도 후보지만 가격 자료를 못 찾아 Mitutoyo로 잡았습니다. LGF-0110L-B는 단종 표시가 있어 후속 모델 가격 확인이 필요합니다.

## 원리

게이지 안의 광전식 유리 스케일이 스핀들 변위를 0.1 µm 단위 직교 펄스로 내보냅니다. 카운터가 펄스를 세어 변위로 바꾸고, 프린터 축 위치와 묶어 높이맵을 만듭니다.

## 장점

- 래스터 접촉 센서 가운데 Z 정밀도가 가장 높고, 4:1 기준(5 µm)에 여유가 큽니다.

## 한계

- M28과 같이 XY가 프린터 축에 묶이고, 볼 반경 1.5 mm라 높이 전용입니다.
- 카운터 보드 연결을 직접 해야 합니다.

## 이 과제에서의 쓰임

**보조(높이 기준값용).** 프린터 안에서 단차를 µm 이하로 잴 수 있어, 광학 높이맵의 Z 배율 확인에 씁니다.
