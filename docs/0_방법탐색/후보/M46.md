# M46 · SmartRay ECCO 95.020

## 대표 구성

- **ECCO 95.020+** (현행 개선판), Class 2 판
- 폭 22~28 mm(근·중·원), Z 범위 16 mm, X 11.5~14.5 µm, Z 분해능 1.1~1.6 µm, 1,920점/프로파일, 450 nm
- Y 스캔 1회

## 원리

일체형 레이저 삼각측량 센서입니다. 450 nm 청색 선을 쓰고, 최대 10 kHz로 단면을 내보냅니다. 구형 ECCO 95.020은 폭 25 mm(중앙), 측정범위 20 mm, X 13 µm로 발표됐습니다.

## 감사 (2026-10-08)

- 원문 확인(Soda Vision 사양, 제조사 페이지는 본문이 잘림): 폭 22/25/28 mm, Z 16 mm, X 11.5~14.5 µm, Z 1.1~1.6 µm, 반복성 0.2 µm, 선형성 0.005 %, 450 nm, Class 2/3R. CSV 값과 맞음.
- 반복성 조건을 원문에서 찾음: "표준 알루미늄 시편, 4,100회 연속 스캔". 앞 절의 "조건 확인 못 함"을 이것으로 보완함.
- 가격은 검색에서도 공개가가 없어 추정 유지, 범위 630만~2,500만 원. z_sigma 범위 1.5~10 µm.
- 공통: edge_loss·max_slope는 공개값이 없어 추정(가림 폭 = 단차 0.2 mm × tan(삼각측량 각 15~50°), 경사 30~60°). mode `area`·cal_class `industrial`·measures_z 1 모두 맞음. 새 열 probe = `optical`.
