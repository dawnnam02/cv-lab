# M24 · 비전 측정기(VMM, 영상측정기) 2D + Z 초점

## 대표 구성

- 학내 공동기기의 CNC 영상측정기. 사양은 **Mitutoyo QV-APEX 302 PRO**(측정 범위 300 × 200 × 200 mm)를 기준으로 잡았습니다. Nikon NEXIV 같은 동급 기종이어도 숫자는 비슷합니다.
- 대물 QV-HR2.5X(NA 0.21) + 튜브 렌즈 1X. 카탈로그상 정확도가 이 조합에서 보증되고, 시야는 2.5 × 1.88 mm입니다.
- 대표 세트 약 60요소: 외곽 4변, 구멍 Ø2/4/6, 핀 9개, 단일 선 3줄의 폭(영상 에지), 계단 윗면 5곳과 바닥 기준면의 Z 초점 점.
- 학내에 장비가 없으면 M25(의뢰)와 같은 성격이 됩니다.

## 원리

카메라 영상에서 밝기 경계(에지)를 찾고, 그 화소 좌표에 스테이지 스케일 값을 더해 XY 좌표를 얻습니다. 높이는 Z축을 움직이며 영상 대비가 가장 큰 위치를 찾는 이미지 자동초점으로 잽니다. 면 전체 높이맵이 아니라, 정해 둔 위치마다 Z 점 하나를 얻는 방식입니다.

## 사양

| 항목 | 값 | 출처 / 추정 근거 |
|---|---|---|
| z_sigma_um | 2.0 | QV-APEX의 E1Z = (1.5 + 4L/1000) µm(카탈로그). L이 작으면 1.5 µm이고, 이를 상한으로 보면 1σ ≈ 0.8 µm. 레이저 AF 반복성 σ 0.4 µm도 있으나 반투명 PLA에서는 레이저가 안으로 스며들어 쓰기 어렵다. 이미지 AF는 대비가 낮은 PLA 윗면에서 나빠지므로 **보수적으로 2.0으로 추정** |
| xy_step_um | 4 | 추정. 시야 2.5 mm를 카메라 가로 화소 약 640개로 나눈 값(카탈로그에 화소 수 없음) |
| xy_blur_um | 3 | 추정. NA 0.21의 회절 한계 0.61λ/NA ≈ 1.6 µm(λ 550 nm)에 화소 크기를 더함 |
| fov_mm / depth_mm | 2.5 / 200 | 시야 2.5 × 1.88 mm(카탈로그 렌즈 표). 깊이는 Z 이동 범위 200 mm |
| measures_z | 1 | 자동초점 Z 점 |
| edge_loss_um | 20 | 추정. 비드 모서리가 둥글고 반투명 PLA는 가장자리가 번져 보여 에지 위치가 흔들림 |
| max_slope_deg | 30 | 추정. 초점 대비는 기울어진 확산면에서도 잡히나, 경사가 크면 반사광이 대물 밖으로 나감 |
| time_min | 60 | 추정. 파트 프로그램 작성 30분 + 측정 실행 30분 |
| cost_krw | 60,000 | 추정. 학내 이용료 공개값을 못 찾음. 1차 M02(학내 촉침 장비) 50,000원 수준에 2시간 사용을 가정 |
| access | lab | 학내 장비 |
| surface_dep | 3 | 반투명·광택 PLA에서 에지 대비와 초점 대비가 모두 떨어짐. 조명(링·동축·투과) 선택으로 일부 보완 |
| in_situ | 0 | 프린터 안 측정 불가 |
| safety | 없음 | — |
| learn_weeks | 2 | 추정. 파트 프로그램(QVPAK) 작성 학습 |

## A1 오차 7종 중 잴 수 있는 것

| 오차 | 가능 | 비고 |
|---|---|---|
| 높이 | ○ | 계단 단차를 점으로. 높이맵은 아님 |
| 윤곽 | ◎ | 영상 에지로 외곽·구멍 윤곽을 촘촘히 얻음 |
| 치수 | ◎ | 본업 |
| 위치 | ◎ | 핀·구멍 중심 |
| 배율 | ◎ | 교정된 스케일 기준 |
| 선(비드) | ○ | 윗면 영상에서 단일 선 폭. 반투명 경계 판정이 관건 |
| 표면 | × | 결 높이는 못 봄 |

## 장점

- 교정된 장비로 윤곽·치수·위치를 한 번에 얻고, 높이도 몇 점 같이 잽니다.
- 2D 영상 후보(M20–M22)와 달리 스테이지 스케일이 있어 시야를 넘는 길이도 이어 붙임 오차 없이 잽니다.

## 한계

- Z는 점 단위이고, 반투명 PLA에서 자동초점 반복성이 카탈로그보다 나빠질 가능성이 큽니다.
- 학내 보유 여부와 이용료를 확인해야 합니다.

## 이 과제에서의 쓰임

**기준값용(윤곽·치수·위치).** 주력 높이맵 방법의 XY 결과를 검증하는 데 씁니다. 단차는 보조로만 씁니다.

## 감사 (2026-10-08)

- 확인: E1Z (1.5+4L/1000) µm, LAF σ 0.4 µm, HR2.5X NA 0.21, 시야 2.5×1.88 mm, Z 200 mm (E4317 사양표·렌즈표).
- 추정 유지: z_sigma 2.0(범위 0.8–4), xy_step 4(2–6, 카메라 화소 수는 카탈로그에 없음), xy_blur 3(1.6–5).
- 이용료 60,000원은 근거가 약해 범위를 30,000–180,000원으로 넓게 둠.
- probe = optical. 수정한 값 없음.
