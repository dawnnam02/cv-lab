# M29 · 1 µm 디지털 인디케이터 + 프린터 축 래스터

## 대표 구성

- **Mitutoyo ID-C112CXB(543-394B)**: 분해능 0.001 mm, 범위 12.7 mm, 정확도 0.003 mm, **저측정력 0.4–0.7 N** + SPC 출력용 USB 입력 케이블
- 프린터 헤드에 고정하고 Z는 고정. 1 mm 격자의 점마다 멈춘 뒤 약 1초 기다렸다 값을 읽습니다(21 × 41 = 861점).
- 인디케이터는 연속 출력이 느려 끌기 주사보다 점마다 멈추는 방식이 맞습니다. 측정력이 낮은 모델을 골라 PLA 눌림을 줄였습니다.

## 원리

M28과 같습니다. 스핀들이 밀려 올라간 양을 절대식 엔코더로 읽고, XY는 프린터 축이 정합니다. 산업용 센서 대신 측정실용 인디케이터를 쓰는 점만 다릅니다.

## 장점

- 싸고, 측정실에서 흔히 쓰는 교정 가능한 계측기라 값 자체를 믿기 쉽습니다.

## 한계

- 점마다 멈춰야 해서 느리고, 격자가 성깁니다. 정확도 3 µm는 4:1 기준(Z 5 µm)에 겨우 맞는 수준입니다.

## 이 과제에서의 쓰임

**보조(높이 전용).** 단차 몇 곳을 저비용으로 확인하는 용도입니다. 높이맵 주력으로는 느립니다.
