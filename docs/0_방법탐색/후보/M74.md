# M74 · Creaform HandySCAN·MetraSCAN (의뢰)

## 대표 구성

- **HandySCAN BLACK Elite** (청색 레이저 선 22개 + 1, 측정 분해능 0.025 mm, 메시 분해능 0.1 mm, 작업거리 200–450 mm, 피사계 심도 250 mm). 시편 둘레에 위치 마커를 붙이고 손으로 여러 방향을 훑음.
- 의뢰처(i-Tube 공동활용장비 확인, 모두 BLACK Elite보다 한두 세대 아래 모델):
  - 경북테크노파크 HandySCAN SILVER Elite — 시간당 30,000원.
  - 한국산업진흥협회(세종) HandySCAN 307 — 시간당 35,000원.
  - 한국화학융합시험연구원(울산) HandySCAN 307 — 건당 300,000원.
  - 창원대 MetraSCAN 750 Elite — 시간당 50,000원 / 한국자동차연구원 MetraSCAN 750 — 시간당 74,000원.
- 비용: 시간당 3.5만 원 × 3시간 = 10.5만 원(추정). BLACK Elite를 가진 공동활용 기관은 확인하지 못해, 사양은 BLACK Elite, 요금은 국내 HandySCAN 계열 값을 씀.

## 원리

여러 줄의 레이저 선을 비추고 카메라 2대가 선의 휘어짐을 삼각측량한다. 시편 주변 반사 마커로 스캐너 위치를 실시간으로 잡아 손으로 움직여도 점군이 한 좌표계에 쌓인다. MetraSCAN은 같은 원리에 외부 광학 추적기(C-Track)로 위치를 잡는 방식.

## 장점과 한계

- 장점: 국내 공동활용 장비가 많고 요금이 쌈. 교정 성적서가 있음. 큰 물체에 강함.
- 한계: 큰 부품용이라 20 × 40 mm 시편의 µm 단위 특징에는 거침. 국내 의뢰 장비는 대부분 구형(307·SILVER·750)이라 BLACK Elite보다 정확도가 낮음.

## 이 과제에서의 쓰임

**부적합(정밀도) / 위치 확인 보조** — 전체 형상과 위치 오차만 볼 수 있음. 같은 의뢰비면 ATOS Q(M73)나 VR-6000(M66)이 훨씬 맞음.

## 감사 (2026-10-08)

- 원문 확인: BLACK Elite 정확도 0.025 mm, 체적 0.020 + 0.040 mm/m, 측정 분해능 0.025 mm, 메시 0.100 mm, 피사계 심도 250 mm, Class 2M.
- **문제**: i-Tube 의뢰처에는 BLACK Elite가 없음. 실제로 의뢰할 수 있는 장비는 아래와 같음.
  - 경북TP SILVER Elite: 정확도 0.030 mm, 체적 0.020 + 0.060 mm/m, 측정 분해능 0.030 mm, 메시 0.2 mm, 시간당 3만 원
  - KAPID HandySCAN 307: 정확도 0.040 mm, 스캔 영역 275 × 250 mm, 시간당 3.5만 원
  - KTR HandySCAN 307: 해상도 0.2 mm, 건당 30만 원
- 그래서 의뢰 장비 기준으로 고침: z_sigma 25 → 30, xy_step 25 → 30, xy_blur 100 → 200, fov 300 → 250. z_sigma는 정확도 값을 σ로 쓰는 기존 보정 논리를 그대로 둠.
- **cal_class calibrated → industrial**: 길이 항 60 ppm이 calibrated(20 ppm)보다 큼.
- config 문구(BLACK Elite)는 감사 대상 칸이 아니라 고치지 않음. 정리할 때 SILVER Elite로 바꿔야 함.
- 307 의뢰면 xy_step 100(측정 분해능 0.1 mm, Aniwaa)이고 z_sigma 40이 됨 → 범위 상한에 반영.
- probe = optical.
