# M44 · Cognex DSMax 3D (DSMax32T)

## 대표 구성

- **DSMax32T** + CoaXPress 프레임 그래버 + VisionPro 라이선스
- CD 51.4~62.3 mm, MR 10.9 mm, 폭 30~31.5 mm, X 14.6~15.4 µm, Z 분해능 2.5~2.8 µm, 최대 18 kHz
- Y 스캔 1회
- 고른 이유: DSMax 계열에서 이번 자료로 확인된 유일한 모델이고 폭이 시편에 맞음

## 원리

레이저 삼각측량 센서지만 Gocator·Keyence와 달리 센서 안에서 측정 도구를 돌리지 않고, 고속 CoaXPress로 PC 프레임 그래버에 데이터를 넘겨 VisionPro에서 처리합니다. 초당 프로파일 수가 많아 고속 라인용입니다.

- 장점: 매우 빠름. 폭이 시편에 맞음.
- 한계: 반복성·파장·가격 공개 자료가 부족. 프레임 그래버·라이선스 비용이 따로 듦. 단종 여부도 확인 필요.

## 감사 (2026-10-08)

- 원문 확인(Cognex 제품 안내 2020): CD 51.4~62.3 mm, MR 10.9 mm, 폭 30/31.5 mm(매뉴얼은 30.2/33.3 mm), XY 14.6~15.4 µm, Z 2.5~2.8 µm, 최대 18 kHz. 매뉴얼은 Class 2M. CSV 값과 맞음.
- 파장: 검색 요약은 520 nm(녹색)라고 함. Cognex 사양 페이지가 429로 막혀 원문으로는 확인하지 못함. surface_dep 4는 감사 대상 열이 아니어서 고치지 않음.
- **가격 불일치 → 수정**: 25,200,000 → 11,600,000원. 기존 값은 출처 없이 $18,000로 추정한 값. 검색 요약에서 eBay 신품 센서 $2,595, DSMAX-DRMO 프레임 그래버 약 $1,700 확인. VisionPro는 추정 $4,000. 합계 $8,295 × 1,400원. 범위 740만~2,520만 원.
- 공통: edge_loss·max_slope는 공개값이 없어 추정(가림 폭 = 단차 0.2 mm × tan(삼각측량 각 15~50°), 경사 30~60°). mode `area`·cal_class `industrial`·measures_z 1 모두 맞음. 새 열 probe = `optical`.
- PLA 보정 근거 재확인: Faes 외 원문 표 2, 405 nm 레이저로 PLA 확산 평균오차 4.43~8.42 µm.
