# M44 · Cognex DSMax 3D (DSMax32T)

## 대표 구성

- **DSMax32T** + CoaXPress 프레임 그래버 + VisionPro 라이선스
- CD 51.4~62.3 mm, MR 10.9 mm, 폭 30~31.5 mm, X 14.6~15.4 µm, Z 분해능 2.5~2.8 µm, 최대 18 kHz
- Y 스캔 1회
- 고른 이유: DSMax 계열에서 이번 자료로 확인된 유일한 모델이고 폭이 시편에 맞음

## 원리

레이저 삼각측량 센서지만 Gocator·Keyence와 달리 센서 안에서 측정 도구를 돌리지 않고, 고속 CoaXPress로 PC 프레임 그래버에 데이터를 넘겨 VisionPro에서 처리합니다. 초당 프로파일 수가 많아 고속 라인용입니다.

## 장점과 한계

- 장점: 매우 빠름. 폭이 시편에 맞음.
- 한계: 반복성·파장·가격 공개 자료가 부족. 프레임 그래버·라이선스 비용이 따로 듦. 단종 여부도 확인 필요.
