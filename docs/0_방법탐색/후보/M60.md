# M60 · Precitec CHRocodile 2 S (공초점 점) + 프린터 축 래스터

## 대표 구성

- **CHRocodile 2 S 컨트롤러 + 3 mm 탐침**: 컨트롤러 최대 70 kHz, LED 광원(공초점·간섭 모드 전환 가능). 3 mm 탐침은 범위 3.0 mm(LED), 작동거리 18 mm, 축 분해능 8 nm, 선형성 400 nm, 가로 분해능 6 µm(스폿 = 2배 = 12 µm), 측정 각 반사면 ±30°·확산면 ±85°
- 프린터 축 래스터, 20 µm 격자
- 고른 이유: 범위 3 mm에 작동거리 18 mm라 헤드 옆에 달기 쉽고, 선형성이 같은 범위 경쟁품(±0.75 µm)보다 좋음

## 원리

크로마틱 공초점입니다(M08 참고). 탐침이 렌즈만 든 수동 부품이라 열 안정성이 좋고, 컨트롤러에서 광섬유로 빛을 보냅니다.
