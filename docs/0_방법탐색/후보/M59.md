# M59 · Omron ZW-8000 (공초점) + 프린터 축 래스터

## 대표 구성

- **ZW-8000T 컨트롤러 + ZW-S8030 헤드**: 중심거리 30 mm, 범위 ±2 mm, 스폿 ø10 µm, 정적 분해능 0.25 µm(거울면 16,384회 평균), 선형성 ±1.3 µm, 측정 주기 60~7,500 µs, 광택면 기울기 ±25°(시리즈 표지)
- 프린터 축 래스터, 20 µm 격자
- 고른 이유: ZW-S8010(±0.5 mm)·S8020(±1 mm)은 범위가 빠듯해 ±2 mm인 S8030을 씀. 대신 선형성이 ±1.3 µm로 커짐

## 원리

크로마틱 공초점입니다(M08 참고). 광원은 LED(Risk Group 1)이고 정렬용 레이저는 Class 1입니다. 헤드가 광섬유로 연결된 수동 광학이라 열·전기 잡음이 헤드에 없습니다.

## 장점과 한계

- 장점: 스폿이 작고 재질 의존이 작음. 공장 라인용이라 튼튼함.
