# M55 · Keyence LK-G5000 + LK-H008 (고정밀 삼각측량 점) + 프린터 축 래스터

## 대표 구성

- **LK-G5001 컨트롤러 + LK-H008 헤드**: 기준거리 8 mm, 범위 ±0.5 mm, 스폿 ø20 µm, 반복성 0.005 µm(65,536회 평균이면 0.001 µm), 선형성 ±0.05 % F.S.(= ±0.5 µm), 샘플링 2.55~1,000 µs 9단, 655 nm 0.3 mW, Class 1
- 프린터 헤드 옆에 달고 20 µm 격자로 지그재그 래스터(선 방향 20 mm/s)
- 고른 이유: LK-G 계열에서 유일하게 Class 1이라 연구실 허가가 필요 없고, 스폿이 20 µm로 작음. 범위가 1 mm뿐이라 시편 윗면 단차 합(약 1 mm)을 겨우 덮음 → 범위 밖이면 프린터 Z를 옮겨 두 번 잼

## 원리

반도체 레이저 한 점을 표면에 쏘고, 비스듬히 놓인 수광 소자(CMOS)에 맺힌 반사점 위치로 높이를 읽는 삼각측량입니다. 기준거리가 8 mm로 짧아 송수광 각이 크고 그만큼 높이 분해능이 높습니다. 한 번에 한 점만 재므로 프린터 축으로 훑어 높이맵을 만들고, XY 위치는 G코드 좌표에서 가져옵니다.

## 장점과 한계

- 장점: 점 삼각측량 중 높이 분해능이 가장 좋고 Class 1. 교정된 상용품이라 센서 자체 신뢰도가 높음.
- 한계: 범위 1 mm로 좁음. 신품은 예산 초과. 적색 레이저라 PLA 침투 치우침이 남아 사양만큼 정밀하지 않음.

## 이 과제에서의 쓰임

**보조**. 단차 몇 줄을 정밀하게 재는 용도. 반투명 PLA에서는 같은 값이면 공초점(M56·M57)이 더 낫다.
