# M45 · Hikrobot (중국산 저가 레이저 라인 프로파일러)

## 대표 구성

- **Hikrobot MV-DP2060-01P**
- 기준거리 64 mm, Z 범위 26 mm, 폭 27~36 mm, X 13.2~18.5 µm, Z 분해능 1.45~2.83 µm, 2,048점/프로파일, 405 nm
- Y 스캔 1회
- 고른 이유: Hikrobot DP2000 계열 중 시야가 시편에 맞는 가장 작은 모델. 3,200점인 DP3060-01P(X 8.5~11.3 µm, 반복성 0.4 µm)가 더 좋지만 값이 더 나갈 것으로 보고 대체안으로 둠

## 원리

일체형 레이저 삼각측량 센서입니다. 센서 안에서 프로파일을 뽑아 GigE로 깊이 영상·단면을 내보내며, 다중 노출·다중 프레임 합성 모드가 있습니다. 전용 3DMVS나 타사 소프트웨어로 씁니다.
