# M47 · Riftek RF627

## 대표 구성

- **RF627BLUE-65/25-20/22** (405 nm 청색)
- 측정 시작 거리 65 mm, Z 범위 25 mm, 폭 20~22 mm, X 1,296점(설정값) → 약 16 µm, Z 분해능 0.01 % = 2.5 µm
- Y 스캔 1회. 폭 20 mm로 시편과 같아 가장자리 여유가 없으면 2회
- 고른 이유: 가장 작은 25/10-8/11(폭 8~11 mm, Z 분해능 1 µm)은 3회 이음이 필요해, 한 번에 덮는 다음 모델을 택함

## 원리

일체형 레이저 삼각측량 센서입니다. 웹 화면과 무료 SDK로 단면을 받습니다. 표준 모드 484 Hz, DS 모드 938 Hz, ROI를 줄이면 최대 6,800 Hz까지 올라갑니다.

## 감사 (2026-10-08)

- 원문 확인(RF627 매뉴얼 7.1·7.2): 65/25-20/22는 MR 25 mm, SMR 65 mm, X 20/22 mm. 점 수 648 또는 1,296, Z 분해능 0.01 %, 선형성 ±0.05 %(표준 모드), 484 프로파일/s, Class 2M, 405/450 nm(BLUE). CSV 값과 맞음.
- xy_step 16 µm는 환산(20~22 mm ÷ 1,296 = 15.4~17 µm)과 맞음.
- 가격은 견적 방식이라 공개가가 없음. eBay UK에 £991.75 게시 1건(구성 모름). 추정 유지, 범위 180만~1,500만 원.
- 공통: edge_loss·max_slope는 공개값이 없어 추정(가림 폭 = 단차 0.2 mm × tan(삼각측량 각 15~50°), 경사 30~60°). mode `area`·cal_class `industrial`·measures_z 1 모두 맞음. 새 열 probe = `optical`.
- PLA 보정 근거 재확인: Faes 외 원문 표 2, 405 nm 레이저로 PLA 확산 평균오차 4.43~8.42 µm.
