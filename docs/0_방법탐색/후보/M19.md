## 원리

카메라를 고정하고 방향이 다른 조명을 하나씩 켜며 3장 이상 찍습니다. 표면이 램버트(고른 확산) 반사를 한다고 가정하면 화소마다 밝기 변화로 면의 기울기(법선)를 구할 수 있습니다. 높이는 이 기울기를 적분해서 얻습니다. 법선은 화소 단위로 정밀하지만 **높이는 적분 결과일 뿐 직접 잰 값이 아니라는 점**이 이 방법의 본질적인 약점입니다.

## 절대 높이 측정의 한계 (핵심)

1. **적분 상수.** 기울기만 알기 때문에 전체 높이에 임의 상수를 더해도 영상이 같습니다. 어떤 기준점의 높이를 따로 주지 않으면 베드 기준 Z를 알 수 없습니다(Quéau 외 2018, Normal Integration 서베이).
2. **저주파 왜곡.** 조명 방향·세기 보정 오차, 평행광 가정 위반, 비램버트 반사가 법선에 작은 치우침을 남깁니다. 이것이 적분되면서 넓은 영역에서 휨·기울어짐으로 쌓입니다(Ackermann·Goesele 2015 서베이). 20–40 mm 시편의 평탄도·치수 같은 낮은 주파수 정보가 가장 나쁘게 나옵니다.
3. **불연속.** 층 단차, 구멍, 수직 벽에선 법선이 정의되지 않거나 위에서 보이지 않습니다. 적분이 단차를 가로지르면 높이 차가 뭉개지거나 엉뚱하게 이어집니다. 이 과제의 핵심 지표인 "0.2 mm 단차의 −20 µm"가 바로 이 불연속에 해당합니다.
4. **반투명·광택.** PLA 내부로 들어간 빛이 퍼지면 법선이 흐려집니다(Inoshita 외 2014, 반투명 물체용 법선 역합성곱). 반투명 정도가 클수록 법선 오차가 커진다는 실험 보고도 있습니다(Visual Computer 2013). 광택 PLA의 정반사는 램버트 가정을 깨므로, 정반사 화소를 빼는 견고한 추정이 필요합니다.

**결론.** 같은 면 안의 국소 높이 변화(층 줄무늬, 비드 모양, 거칠기)는 잘 보지만, 서로 떨어진 면 사이의 절대 높이 차는 보조 정보 없이 믿기 어렵습니다. 보조 정보의 예는 삼각측량이나 초점 적층의 저주파 높이, 또는 기준 높이 마커입니다.

## 장점

- 빠르고(수 분) 가로 해상도가 높음. 2D 경계 측정 장비와 부품을 같이 씀(M21과 비슷한 구성)
- 표면 결 묘사가 뛰어나 표면 오차·결함 판정에 좋음
- 움직이는 부품이 없음

## 한계

- 절대 높이는 원리상 구할 수 없고 적분으로 추정할 뿐임(위 4가지)
- PLA의 광택·반투명은 램버트 가정을 정면으로 깸. 무광 백색 PLA가 아니면 오차가 커짐
- 조명 방향·세기 보정이 결과를 좌우함
- 텔레센트릭 렌즈 값이 비용 대부분

## 이 과제에서의 쓰임

**보조(표면·윤곽용).** 높이·선폭 Z 기준은 통과하지 못할 것으로 봅니다. 표면 결 측정과 2D 윤곽·치수에선 쓸모가 있어, 다른 높이 측정법과 묶는 조합안(예: M05 높이 + M19 표면·윤곽)의 보조 후보로 둡니다.
