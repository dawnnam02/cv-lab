# M01 · CMM (접촉 프로브)

## 대표 구성

- 한국금형기술센터(KITECH) 접촉식 3차원 측정기 **Brown & Sharpe GLOBAL 12.15.10**에 측정 의뢰
- 터치 트리거 프로브, Ø1 mm 루비 볼 스타일러스 (Ø2 mm 구멍까지 들어가는 크기)
- 대표 측정 세트: 약 40점 — 바닥 기준면 3점, 외곽 4면 각 4점, 구멍 Ø2/4/6 각 4점, 계단 윗면 5개 각 2점, 핀 9개 위치
- 연구실 예산(500만 원)으로는 CMM을 살 수 없으므로 의뢰를 기준으로 삼았습니다. 학내에 CMM이 있으면 그쪽이 더 쌉니다.

## 원리

스타일러스 끝의 구가 표면에 닿는 순간 프로브가 신호를 내고, 그때 세 축 스케일 값을 읽어 접촉점 좌표를 얻습니다. 실제 표면은 볼 중심에서 볼 반경만큼 떨어진 곳이므로 소프트웨어가 반경을 보정합니다. 점 여러 개에 평면·원·직선을 맞춰 치수와 위치를 냅니다.

## A1 오차 7종 중 잴 수 있는 것

| 오차 | 가능 | 비고 |
|---|---|---|
| 높이 | ○ | 계단 윗면 단차. 점 몇 개라 면 전체 높이맵은 아님 |
| 윤곽 | △ | 점 수가 적어 윤곽 전체는 못 그림. 스캐닝 프로브가 있으면 가능 |
| 치수 | ◎ | 외곽 길이, 구멍 지름 — CMM의 본업 |
| 위치 | ◎ | 핀·구멍 중심 좌표를 기준면 대비로 바로 냄 |
| 배율 | ◎ | 긴 치수로 X·Y 배율 오차 계산 |
| 선(비드) | × | 선폭 0.40 mm보다 볼이 커서 불가 |
| 표면 | × | 거칠기·층 결은 불가 |

## 장점

- 이 후보군에서 치수·위치의 **소급성(교정 체계)** 이 가장 확실합니다. 다른 방법을 검증하는 기준값으로 씁니다.
- 높이·치수·위치를 한 좌표계에서 동시에 얻어 G코드 좌표계와 정합하기 쉽습니다.

## 한계

- 점 단위라 높이맵·선폭·표면 결을 못 봅니다.
- 의뢰 일정 때문에 반복 실험이 느립니다. 시편이 늘면 비용이 점 수에 비례해 늘어납니다.
- PLA 결 위의 접촉점 하나하나가 표면 거칠기(수 µm)만큼 흔들립니다. 센터 장비는 1990년대 계열로 보이며 실제 상태는 문의가 필요합니다.

## 이 과제에서의 쓰임

**기준값용.** 치수·위치·단차 몇 곳을 CMM으로 재서 주력 방법(광학 높이맵 등)의 정답으로 씁니다. 주력으로는 맞지 않습니다.

## 감사 (2026-10-08)

- 상태(12열, mode·cal_class 포함): 확인 6 · 추정 5 · 불일치 1(z_sigma_um) · 출처 없음 0. probe = contact.
- **z_sigma 1.5 → 2.5 µm**: 센터 페이지에 반복정밀도 2.5 µm가 따로 있음(σ 표기 없음). 1σ로 보수 해석. 범위 1.25–2.5(2σ 해석이 하한).
- cost 250,000원 확인(기본료 50,000 + 5,000원/pt). 범위 200,000–300,000(30–50점).
- xy_step·blur·edge_loss·time은 구성 가정이라 추정. 범위는 감사/사양감사_A.csv.
