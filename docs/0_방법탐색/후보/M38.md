# M38 · Keyence LJ-X8020

## 대표 구성

- **LJ-X8020 헤드 + LJ-X8000 컨트롤러 (신품)**
- 기준거리 20 mm, 폭 7~8 mm(근~원), X 데이터 간격 2.5 µm, Z 범위 ±2.2 mm, 405 nm 청색
- 폭이 7 mm라 20 mm 시편은 엔코더 달린 Y 스테이지로 **3회 스캔(겹침 약 0.5 mm)** 후 이어 붙임
- 고른 이유: Keyence 라인 중 X 간격이 가장 촘촘한 소형 헤드. 2.1절 선폭 목표에 가장 유리함

## 원리

카메라·레이저·렌즈가 한 몸체에 고정된 레이저 삼각측량 센서입니다. 405 nm 선을 비추고 비스듬한 카메라가 선의 위치를 읽어 교정된 단면(x, z)을 바로 내보냅니다. 시편을 Y로 움직이면 단면이 쌓여 높이맵이 됩니다. 시야가 좁아 여러 번 지나가야 하므로, 이음매 정합은 스테이지 정밀도에 달려 있습니다.

## 장점과 한계

- 장점: X 분해능과 선 두께가 이 묶음에서 가장 좋음. Keyence 지원망이 넓음.
- 한계: 폭 7 mm라 3회 이음 필요. 신품 약 1,930만 원으로 예산의 4배. Class 2M.
