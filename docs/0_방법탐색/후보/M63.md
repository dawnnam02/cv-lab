# M63 · Micro-Epsilon interferoMETER (백색광 간섭 점) + 프린터 축 래스터

## 대표 구성

- **IMS5400-DS 컨트롤러 + IMP-DS19 탐침**: 측정 시작 19 mm, 범위 2.1 mm, 스폿 10 µm, 분해능 < 1 nm(2σ, 유리판), 선형성 < ±50 nm, 측정 100 Hz~6 kHz, 840 nm SLED, Class 1, 탐침 허용 기울기 ±2°
- 프린터 축 래스터, 20 µm 격자
- 고른 이유: DS 탐침 중 작동거리가 19 mm로 가장 길어 헤드 옆에 달 수 있음. 5600-DS는 더 정밀하나 이 과제에는 과함

## 원리

SLED의 넓은 파장대 빛으로 탐침 기준면과 표면 사이 간섭 스펙트럼을 만들고, 그 주기로 절대 거리를 냅니다(M62와 같은 분광 간섭). 절대 측정이라 단차를 건너뛰어도 거리를 잃지 않습니다.

## 장점과 한계

- 장점: 나노미터급 분해능. 유리·웨이퍼 같은 매끈한 면에서는 최고 수준.
- 한계: 거칠고 반투명한 FDM PLA 표면과 맞지 않음. 비쌈.

## 이 과제에서의 쓰임

**부적합**. 시편 표면 조건(반투명·거침·경사)이 장비 적용 조건 밖.
