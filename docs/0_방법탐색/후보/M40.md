# M40 · LMI Gocator 2510 (중고)

## 대표 구성

- **Gocator 2510 중고 + 전원·I/O 케이블**(별도 컨트롤러 없음, 센서 안에서 처리)
- CD 17 mm, MR 6 mm, 폭 13~14.5 mm, X 8 µm, 405 nm Class 2, 1,920점/프로파일
- 20 mm 시편은 Y 스테이지로 **2회 스캔(겹침 약 6 mm)** 후 이어 붙임
- 고른 이유: M06에서 "예산 안에 드는 유일한 상용 라인"으로 정리된 구성

## 원리

일체형 레이저 삼각측량 센서로, 영상 처리와 측정 도구가 센서 안에 들어 있습니다. 웹 화면이나 SDK로 교정된 단면을 받고, 엔코더 입력으로 Y 위치를 맞춰 높이맵을 만듭니다.

## 장점과 한계

- 장점: 예산 안. Class 2. 컨트롤러가 따로 없어 구성이 단순. 공정 중 측정 사례가 있는 회사 제품.
- 한계: 중고라 교정·보증 없음. 펌웨어 버전에 따라 소프트웨어 호환 확인 필요. 2회 이음.
