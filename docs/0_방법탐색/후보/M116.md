# M116 · 절단·연마 단면 + 현미경 (파괴)

## 대표 구성

- 시편을 X 방향 3곳(계단·선·구멍을 지나는 단면)에서 저속 다이아몬드 절단기로 자름. PLA 유리전이온도가 약 60 °C라 물로 식히며 천천히 자름
- 상온 경화 에폭시로 마운팅 (발열이 낮은 수지를 골라 PLA 변형을 막음)
- SiC 연마지 #500 → #4000, 마지막 1 µm 연마
- 학내 금속현미경 10× 대물(NA 0.25) + 5 MP 카메라(화소 3.45 µm)로 단면을 이어 촬영, 화소 0.35 µm
- **단면 3줄 기준**

## 원리

시편을 잘라 단면을 평평하게 갈아 내면, 각 층과 선이 단면에서 둥근 띠 모양으로 드러납니다. 현미경 사진에서 층 경계와 선 가장자리를 찾아 층 높이, 선폭, 벽 위치를 직접 잽니다. 결과는 단면 한 줄의 Z–X 윤곽이며, 시편은 다시 쓸 수 없습니다.

| 오차 | 가능 | 비고 |
|---|---|---|
| 높이 | ◎ | 단면에서 층마다 높이 |
| 윤곽 | △ | 단면 한 줄의 벽 위치 |
| 치수 | △ | 단면이 구멍 중심을 정확히 지나야 지름이 됨. 절단 위치 오차 ±0.1 mm 안팎 |
| 위치 | × | 절단 후 기준 좌표가 사라짐 (기준 마커를 함께 넣으면 일부 가능) |
| 배율 | × | — |
| 선(비드) | ◎ | 선 단면 모양, 폭, 높이를 직접 봄 |
| 표면 | ○ | 단면 윤곽의 층 결 |

## 장점

- 층과 선의 실제 단면 모양을 직접 봅니다. 광학 표면 측정이 놓치는 층 사이 공극과 겹침도 보입니다.
- 장비가 흔하고 비용이 낮습니다.

## 한계

- 시편이 부서집니다. 같은 시편을 다른 방법으로 다시 잴 수 없으므로 다른 방법을 먼저 다 끝내고 마지막에 해야 합니다.
- 단면 몇 줄만 봅니다. 면 전체의 분포는 모릅니다.
- 절단 위치와 단면 기울기를 정확히 맞추기 어렵고, 연마로 가장자리가 무너질 수 있습니다.

## 이 과제에서의 쓰임

**기준값용(마지막 단계).** 층 높이와 선폭의 단면 정답을 얻어 비파괴 방법을 검증하는 데 씁니다. 주력은 못 됩니다.
