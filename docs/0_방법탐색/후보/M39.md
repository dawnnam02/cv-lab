# M39 · Keyence LJ-V7020 (구형·중고)

## 대표 구성

- **LJ-V7020 헤드 + LJ-V7001 컨트롤러 + 헤드 케이블, 모두 중고**
- 기준거리 20 mm, 폭 6.5~7.5 mm, X 데이터 간격 10 µm, Z 범위 ±2.6 mm, 405 nm
- 20 mm 시편은 Y 스테이지로 **4회 스캔(겹침 약 1 mm)** 후 이어 붙임
- 고른 이유: LJ-X 이전 세대로 중고 물량이 많고 값이 싸서 예산 안에 드는 몇 안 되는 Keyence 구성

## 원리

M38과 같은 일체형 레이저 삼각측량입니다. 영상 소자와 처리기가 한 세대 앞서 X 간격이 10 µm로 LJ-X8020보다 4배 성깁니다. 단면을 Y로 쌓아 높이맵을 만들고, 좁은 시야는 여러 번 지나가서 메웁니다.

## 장점과 한계

- 장점: 예산 안. 교정된 상용 헤드. 중고 물량이 많아 고장 시 교체가 쉬움.
- 한계: 4회 이음. 중고는 교정 상태·보증이 없음(교정 성적서 확인 필요). 연구비로 중고 구매가 되는지 확인 필요. 구형 소프트웨어.
