## 0. 요약

- **지표 추출이 정답을 몰래 쓰는 곳은 없습니다.** 정답이 들어가는 곳은 측정 창 크기(ROI) 두 군데뿐이고, 설계값으로 바꿔 돌려도 국소 선폭 Q 변화가 1.3 % 이하입니다.
- **결과 재현됨**: HEAD 코드와 같은 시드로 경계 사례 11개를 다시 돌린 값이 CSV 와 소수 14자리까지 같습니다.
- **버그 1건(중)**: 점 측정(point_probe)의 길이40에 seam 항이 들어갑니다. 주석 B4 와 다릅니다. M24 는 16.6 → 5.9 µm 로 등급이 4:1 에서 10:1 로 바뀌고, M120 은 8,734 → 1,131 µm 입니다(어느 쪽이든 탈락).
- **해석식 대조**: 비교 가능한 314건 중 30 % 초과는 **13건**입니다(국소높이 0, 국소선폭 11, 길이40 2). 국소선폭 11건 중 10건은 Q 가 기준의 10배가 넘는 비선형 영역이라 판정에 영향이 없습니다. 나머지 1건은 M40 이고, 판정은 둘 다 4:1 통과입니다.
- **국소 선폭의 주된 항은 잡음이 아닙니다.** edge_loss 결측 틈을 선형 보간으로 건널 때 생기는 치우침(−2 ~ −7 µm, edge_loss 200 µm 이면 +9 µm)과, 그 틈과 표본 간격이 맞물리는 위상 항이 Q 를 정합니다. 잡음만 넣은 순수 해석식(W-a)은 시뮬레이션보다 중앙값 기준 3.1배 작습니다.
- **경계 사례**: 시드 5개(MC 50회씩)로 돌리면 Q 가 ±5~20 % 흔들립니다. 그래도 **최종 통과·탈락이 바뀌는 후보는 없습니다.** M39 만 사양 가정 하나(seam XY σ 5 → 4.5 µm)에 따라 통과로 뒤집힐 수 있습니다.

## 2. 해석식 정의 (v4_analytic.py)

시뮬레이터를 import 하지 않고 numpy 로 다시 세운 식입니다. 사양 숫자 해석과 접촉식 판정만 specs.py 를 빌려 씁니다. 보수-500 시나리오 기준입니다.

**공통 입력**: 백색 σ_w = z/√2, 상관 σ_c = z/√2(필터 σ_f = 500 µm → 상관함수 C(d) = σ_c²·exp(−d²/4σ_f²)), u_s(calibrated 20 / industrial 100 / diy·printer_axis 500 ppm), seam 수 n_s = ⌈40/fov⌉ − 1(fov < 40 mm, 래스터·점 측정은 0), seam σ_z = z/√10, σ_xy = max(step/2, 1).

**H. 국소높이** (칸 0.2 mm, 칸당 점 n = (200/step)²)

- Var = σ_w²/n + σ_c²·ρ_cell + Var_seam
- ρ_cell = 칸 평균의 상관 계수 = 0.987
- Var_seam = ½[Var(W_k − W̄) + Var(W_{k+1} − W̄)], W 는 seam 랜덤워크, k = n_s // 2
- Q_H = 2√Var + E|치우침|, 치우침 = 50회 평균의 MC 요동(패치 평균 분산/50)
- 측정 불가 조건: 2D, depth < 1 mm, step > 283 µm(칸 점유 < 50 %). 점 측정은 Q = 2z(step < 200)

**W. 국소선폭** (구간 0.5 mm, 구간당 단면 n_r = 500/step 줄, 표본당 백색 분산 σ_w²/n_r)

- **W-a (순수 해석)**: 흐린 단면(가우시안 또는 구 프로브 닫힘을 직접 계산)의 반높이 기울기 s 로
  δw = n_L/s_L + n_R/s_R − ½(δbase + δtop)(1/s_L + 1/s_R)
  - 경계값 잡음 n: 백색 ⅔·σ_w²/n_r(두 표본 보간 평균)과 상관 성분
  - δbase: 창 양 끝 15 % 중앙값(백색 π/2·σ²/N), δtop: 95 % 이상 점의 2차 맞춤(9/4·σ²/N)
  - 상관 성분은 다섯 위치(왼·오른 경계, 양 끝 바닥, 꼭대기) 사이 공분산으로 넣음
  - Q_Wa = 2√Var + E|치우침|
- **W-b (반해석)**: W-a 에 결정론적 항을 더합니다.
  - 위상 40개마다 잡음 없는 흐린 단면을 표본화하고, 경사 > max_slope, 벽(실제 경사 > 60°)에서 edge_loss/2 이내를 결측으로 둡니다.
  - 결측 틈을 건너는 선형 보간의 치우침과 위상 분산을 계산합니다.
  - 잡음은 실제 보간 현(두 유효 표본)의 기울기와 가중치로 전파합니다.
  - Q_Wb = E|bias + N(0, Var/50)| + 2√(Var_잡음 + Var_위상 + (440·u_s)²)
- **2D**: 흐린 실루엣의 0.5 문턱 반폭 a′(erf 로 풂), 표본 수 양자화 f = frac(2a′/step)
  - σ = step·√(f(1−f))·√3/2
  - bias = √3(a′ − a)
- 점 측정: 2·√((z√2)² + (400 u_s)²), 볼 지름 > 0.4 mm 면 불가

**L. 길이40**: Q_L = 2√(2σ_e² + (40 mm·u_s)² + n_s·σ_xy²)

- σ_e = step/√12(곧은 경계, 위상 공유)
- 점 측정은 σ_e = z, seam 0
- 래스터 점 센서는 σ_e² 에 5² 를 더함
- 대조표의 `Q_ana_b` 열(길이40)은 시뮬레이터 규칙(점 측정 seam 포함, 래스터 잡음 없음)으로 다시 계산한 값입니다.

**W-a(순수 해석식) 90건 초과의 원인**은 한 가지입니다. 결정론적 표본화 항이 빠졌기 때문입니다.

아래 두 조건은 겹칩니다.

- 75건은 edge_loss > 22 µm 입니다. 반높이(중심에서 220 µm)가 결측 띠(벽 231–254 µm ± edge_loss/2) 안에 들어가, FWHM 이 결측 틈을 건너는 현으로 정해집니다.
- 58건은 max_slope < 55° 입니다. 반높이 기울기 약 54° 가 결측 처리됩니다.

두 조건에 모두 해당하지 않는 3건(M85·M86·M115)은 위상 양자화 때문입니다.

W-b 에 이 항을 넣으면 108건 중 101건이 30 % 안으로 맞습니다. 그래서 **시뮬레이터의 국소선폭 Q 는 맞게 계산된 것이고, 그 값을 정하는 것은 잡음이 아니라 edge_loss 결측 가정**입니다. edge_loss 와 Q 의 관계는 단조롭지 않습니다(120 µm → 치우침 −2 ~ −7, 200 µm → +9). 그래서 V3 에서 '큰 값이 보수적'이라는 범위 처리(specs.to_num 의 max 선택)가 맞지 않을 수 있습니다.

## 5. 시뮬레이터에 고칠 점 (우선순위)

1. **(중) 점 측정 길이40 의 seam 항 제거** — `length_sd` 에서 `m.point` 이면 seam 0(주석 B4 와 맞춤). 스테이지 오차가 필요하면 u_s 로 넣습니다. M24 10:1 등급, M120 값이 바뀝니다. (simulate.py 954–962)
2. **(중) Q 의 MC 불확도 보고** — 시드 여러 개 또는 부트스트랩으로 Q 의 범위를 CSV 에 남깁니다. 기준 ±20 % 안의 후보는 MC 를 200회 이상 돌리거나 국소높이처럼 해석식(6 % 안에서 일치)으로 판정합니다. (simulate.py 1028–1037, screen.py)
3. **(중, 모델) 국소선폭의 결측 틈 처리** — 지금은 반높이가 결측 띠 안에 들어가 FWHM 이 보간 현으로 정해집니다. 그래서 Q 가 edge_loss·max_slope 가정과 결측 경계의 1 µm 정렬에 좌우됩니다(M39·M40 위상 sd 1.42 vs 0.05). 다음 중 하나로 바꿉니다.
   - 유효 점에 단면 형상(반타원·포물선)을 맞춰 반높이 폭을 구합니다.
   - 교차를 직접 못 보면 '측정 불가'로 둡니다.
   - 결측 경계를 격자 아래에서 무작위로 흔들어 평균합니다.
   이 항목은 V2 의 'PLA 경계 치우침'·'한쪽 가림'과 함께 손봐야 합니다. (simulate.py 355–370, 551–591)
4. **(하) 래스터 점 센서 길이40 에 축 위치 잡음 5 µm 추가** (simulate.py 958–961)
5. **(하) 측정 창·ROI 를 설계값 + 공차로** (485–486, 596, 729–731). 효과는 ≤ 1.3 % 지만 '정답 미사용' 원칙을 문자 그대로 맞추기 위해서입니다.
6. **(하) 큰 실패 영역을 '측정 불가'로** — 반높이 교차 양쪽 유효 표본이 모자라면 NaN (M28–M30, M97)
7. **(하) fov < 20 mm 의 2D 타일 seam** — 지금은 40 mm 방향만 셉니다(M14·M80 등 낙관 쪽).
8. **(하) 100만 원 own 조건을 rules 인자로** — 지금 선정(비교-선정 §00)이 코드 밖에서 손으로 거른 것이라 재현이 안 됩니다. 조합 예산에서 lab 이용료와 own 구축비를 더하는 규칙도 정리합니다.
9. **(하) `_safe` 가 NaN 으로 바꾼 건수를 notes 에 기록**
10. **(정보, V2) 국소높이 패치·2D 선폭의 낙관 요소** — 래스터 점 센서의 프린터 Z축 오차와 2D 영상 잡음·문턱 치우침이 없습니다. 지금 선정안(M108·M112)의 윤곽 4:1 은 양자화만 본 값입니다.

## 6. 확인 못 한 것

- 구멍지름·위치·단차는 해석 대조 범위 밖이라 보지 않았습니다(Q 가 기준과 멀어 판정 영향 작음).
- 낙관 시나리오는 대조하지 않았습니다. 보수-100 은 길이40 만 확인했습니다(diy 28개, 해석식과 상대 차 < 10⁻¹⁵).
- 경계 사례 재실행에는 시드 5개만 썼습니다(M14 는 한 번에 16분). MC 횟수를 늘린 수렴 확인은 하지 않았습니다.
- 해석식의 상관 성분은 바닥(창 양 끝) 중앙값을 양 끝 평균으로 근사했습니다. 바닥 위치가 선에서 0.5–0.9 mm 떨어져 있어 이 근사가 국소선폭 잡음 항에 몇 % 영향을 줄 수 있습니다.
