# 측정 실패사례 분석 — 노즐 장착 라인 레이저 + BLTouch 검증

> 작성: 2026-10-27 · 조사 worker (Opus 5.5) · 지시서: [세부청사진 T2](운영/세부청사진_T2_측정실패사례.md) · 상태: **개정판 (R12–R17 반영, 팀장 검증 전)**
> 가상 데이터로 얻는 U와 판정 정확도는 "알고리즘이 시뮬레이터가 넣은 오차를 얼마나 복원하는가"이며 하드웨어 성능의 증거가 아닙니다.
> 2026-10-27 사용자 결정 반영: 측정 시점은 **층마다 측정 (출력 중)** (D-04). T2는 Plane 항목 없이 로컬 문서로만 둡니다.
> **BLTouch 제외 (2026-10-27 사용자 결정)**: 측정은 레이저 삼각측량만 씁니다. 신뢰성 확인은 필러게이지 기준 단차와 반복 측정으로 합니다. MF-BLT 범주와 BLTouch 전용 항목 (MF-PRC-07·08)은 지우지 않고 해당 없음으로 표시했고, 순위·예산·시뮬레이터 반영에서 뺐습니다. 대신 교차검증이 없어서 생기는 위험을 MF-CAL-12로 더했습니다. 제목의 "BLTouch 검증"은 지시서가 정한 제목이라 그대로 둡니다.
> **개정 (2026-10-27): 0.2 mm는 찾을 단차가 아니라 허용 오차 T (D-05)이고, 비교는 G코드 대비 절대 높이입니다.** 단차에서 빠지던 공통 오차가 남으므로 모든 항목의 S를 절대 높이 영향으로 다시 매겼습니다. 판정은 측정 당시 높이 (D-06), 가드밴드 방식 B (D-07), 전체 층 합산 95 % (D-08). G코드 해석 (GCD)·합격 판정 (JDG) 범주와 펌웨어 요구 (7.1절)를 더했습니다. 프린터·펌웨어는 T14가 동시에 고르는 중이라 특정 기종을 가정하지 않았고, 기종에 따라 달라지는 값은 "T14 결과에 따름"으로 적고, T14 1차 결과 (Voron Trident + Klipper, 완성품 1위 Sovol SV08)를 참고로만 덧붙였습니다 (확정 아님).

### 0.2 판정 상태 결정 (D-06 확정)과 측정 시점 (R17 · R10)

**판정 상태.** D-06 확정에 따라 판정은 측정 당시 높이로 하고, 마지막 층은 식힌 뒤 다시 재서 차이를 보고합니다. 식은 높이로 환산하는 안은 한 줄 참고로 둡니다.

|---|---|---|
| S ≥ 4 항목 수 | 42 | 42 (수는 같고 MF-THM-05가 S4 → S5) |
| 판정에 들어가는 열 몫 | 높이에 따른 수축 기울기 14–34 µm (MF-THM-05 ①) | 환산 모델 오차 10–25 µm [추정] + 식는 동안의 휨·광택 변화 |
| 고유 위험 | 식은 높이와 섞어 판정 (MF-JDG-05), 식힌 재측정 전 모터 해제 (MF-SYN-09)·베드 끔 (MF-THM-06·PRC-09) | 열 모델 검증 실측 필요, 층마다 온도장을 알아야 함 |

- 확정안의 S ≥ 4 42개 중 열 상태와 직접 이어진 것: MF-THM-05, MF-JDG-05, MF-OPT-04 (0점 이어 가기).

## 2. 판정 기준

지시서 §5 (개정)를 그대로 씁니다. 바꾼 점은 아래 "변경"뿐입니다.

- 실패 항목표 11칸: ID · 현상 · 원인 · 높이 영향 · 근거 · 병목 · 탐지 · 대책 · 시뮬레이터 · 절대 높이 몫 · 단계.
- 높이 영향 칸은 **G코드 대비 절대 높이 µm를 먼저** 씁니다. 시간 병목은 분, 데이터 병목은 GB·MB/s, 판정 병목은 오판정 방향 (불량 → 합격 또는 합격 → 불합격).
- 근거 태그: `[출처 n]` (9절 번호, 본문·초록에서 수치 확인) · `[계산]` (식 함께) · `[추정]` (이유 함께) · `[미상]`. 검색 요약으로만 본 수치는 `[추정] (출처 n 검색 요약: …)`.
- 시뮬레이터 칸: S-형상 · S-영상 · S-위치 · S-교정 · S-메타 · 미반영(사유).
- 절대 높이 몫: `남음` (G코드 대비 높이에 그대로) · `부분` (베드 기준 스캔·교정·열 모델로 일부를 뺄 수 있음) · `없음` (높이 값에 안 들어감).
- 단계: 층별 · 출력 후 · 교정 · 검증 · 정답 (G코드 해석) · 판정 · 전체.

**S는 G코드 대비 절대 높이 영향 (베드 면 = 0)으로 매깁니다.** 한 스캔 안 두 면에 같이 들어가 단차에서 빠지던 공통 오차도 그대로 셉니다. `부분` 항목의 S는 대책 칸에 적은 대책을 적용한 뒤 남는 크기입니다. 실수형 항목 (교정 누락·혼동 등)은 일어났을 때의 크기로 매깁니다.

| 점수 | S 정확도 (T = 0.2 mm 기준 절대 높이 영향) | S 시간 | S 데이터 | S 신뢰성 (판정 포함) |
|---|---|---|---|---|
| 5 | > 50 µm 또는 측정 불가 (4:1 깨짐) | 시편 1개 측정 > 480분 | 실시간 기록 불가 (전송률 > 링크 용량) | 결과 전체 무효, 불량을 합격으로 판정할 수 있음 |
| 4 | 20–50 µm (10:1 깨짐) | 출력 시간 +100 % 이상 | 시편당 > 100 GB | 해당 스캔 무효, 합격을 불합격으로 판정하거나 보류가 절반 넘음 |
| 3 | 5–20 µm | +25–100 % | 10–100 GB | 일부 영역 무효 |
| 2 | 1–5 µm | +5–25 % | 1–10 GB | 경고 수준 |

- **변경 1**: 시간·데이터·신뢰성 항목처럼 높이에 직접 들어가지 않는 항목과 스캔 자체가 무효가 되는 항목은 절대 높이 몫을 `없음`으로 씁니다.

- [개정] `blt.*` 필드는 MF-BLT 행 (해당 없음)의 탐지 칸에만 남아 있습니다. BLTouch 제외 (2026-10-27)로 T1은 blt 묶음을 보류해도 됩니다. 검증은 `cal.gauge_measured_mm`·`ref.kind`·`rep.repeat_idx` (MF-CAL-12)로 합니다.
- [개정] 판정 설정 (가드밴드 U, 칸 크기, 층별 집계)은 명세가 아니라 T15 출력이라 필드로 요구하지 않았습니다 (MF-JDG-01·04·06 탐지 칸 참조).

### 7.1 펌웨어 요구 [개정]

실패를 막으려면 펌웨어 (와 호스트)에 무엇이 필요한가만 적습니다. 펌웨어·프린터를 고르는 일은 T14입니다. 마지막 칸은 모두 **T14 결과에 따름**입니다. T14 1차 결과 (`docs/프린터-펌웨어-선정.md`, 1순위 Voron Trident + Klipper, 완성품 1위 Sovol SV08 + Klipper)는 팀장 검증 전이라 확정이 아닙니다. 1차 결과로 본 충족 여부를 각 행 끝 괄호에 참고로 적었습니다. BLTouch 프로브 설정 행은 BLTouch 제외로 뺐습니다.
